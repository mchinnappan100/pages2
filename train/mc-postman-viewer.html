Slide 2 of 8 · The Problem

Why mc-postman-viewer?

Postman collections are rich API documentation, but sharing them requires either a Postman account or exporting a raw JSON that's hard to read.

  • Raw JSON is unreadable without Postman Desktop installed
  • No way to quickly mock endpoints without a backend
  • Postman's cloud requires sign-in — not ideal for air-gapped environments
  • No built-in diff or semantic code view for request/response bodies
  • PDF generation from Postman requires paid plan

mc-postman-viewer solves this

One CLI command turns any .json collection file (or URL) into a fully interactive browser app — no account needed, no cloud dependency, works offline.

Slide 5 of 8 · Quick Start

Installation & Usage

# From a local file
postman-viewer -f ./my-api.postman_collection.json

# From a URL
postman-viewer -r https://example.com/collection.json

# Custom port + mock server
postman-viewer -f ./api.json -p 4000 --mock

# Don't open browser automatically
postman-viewer -f ./api.json --no-open

Requires Node.js ≥ 16. Dependencies: express, ws, axios, commander.

Slide 7 of 8 · Mock Server

Built-in Mock Server

  • Started with --mock flag, default port 4001 (override with --mock-port)
  • Reads every response[] example in the collection and registers live HTTP routes
  • Select specific examples via X-Mock-Response-Name header
  • Route index available at /mock-routes
# Start viewer + mock server on custom ports
postman-viewer -f ./api.json -p 3000 --mock --mock-port 4001

# Test mock endpoint with curl
curl http://localhost:4001/your/endpoint

# Select a specific response example
curl -H "X-Mock-Response-Name: Success 200" http://localhost:4001/users
