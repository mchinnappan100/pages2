Slide 2 of 8 · What is MCP?

Model Context Protocol

MCP is an open protocol that lets AI models call external tools and access live data — similar to function calling, but standardized across providers.

AI Model (Claude / OpenAI)
→
MCP Client
→
MCP Server (tools)
→
External System
  • MCP servers expose tools (functions), resources (files/data), and prompts
  • Stdio transport: server runs as a child process — works offline, no network needed
  • HTTP/SSE transport: server runs as a web service — shareable, centralized
  • mc-mcp is the browser-based client that connects you to any MCP server
Slide 3 of 8 · Architecture

How mc-mcp Works

Browser UI
→
Express API (mc-mcp)
→
MCP Bridge
→
MCP Server (stdio / HTTP)

API Routes

  • GET /api/servers — list configured servers
  • POST /api/servers — save server config
  • POST /api/mcp/:id/connect — get tools/resources/prompts
  • POST /api/mcp/:id/call — call a tool
  • POST /api/ai/chat — SSE stream to AI provider

AI Sidekick

  • Streams chat responses via SSE
  • Supports Claude, OpenAI, xAI Grok, Gemini
  • Tools passed to AI automatically from connected server
  • PKCE OAuth for custom HTTP connectors
Slide 4 of 8 · Server Config

Connecting to MCP Servers

Servers are configured via the UI or a JSON file. Each server entry specifies transport type, command or URL, and any environment variables.

// servers.json — stdio server example
{
  "my-sf-server": {
    "transport": "stdio",
    "command": "npx",
    "args": ["@salesforce/mcp-server"],
    "env": { "SF_ORG": "my-org" }
  },
  "remote-server": {
    "transport": "http",
    "url": "https://my-mcp-server.example.com/mcp"
  }
}

Slide 6 of 8 · Plugin System

Extending with Plugins

mc-mcp includes a plugin system — drop a JS file in plugins/ to add custom Express routes and UI functionality without modifying core code.

// plugins/my-plugin.js
module.exports = {
  name: 'my-plugin',
  routes: (app, { loadServers, call }) => {
    app.get('/api/my-feature', async (req, res) => {
      // Custom logic using mc-mcp internals
      res.json({ ok: true });
    });
  }
};
  • Plugins auto-discovered from the plugins/ directory on startup
  • Plugin list exposed at GET /api/plugins
  • Each plugin can include client-side scripts for UI integration

Slide 8 of 8 · Summary

Key Takeaways

  • mc-mcp is a full browser-based MCP client — works with any stdio or HTTP MCP server
  • Built-in AI Sidekick supports Claude, OpenAI, Grok, Gemini, and local Ollama
  • Plugin system lets you extend functionality without modifying core files
  • PKCE OAuth support for secure HTTP MCP server connections
  • API-first design — all browser UI features are also available as REST endpoints
  • Express + SSE streaming for real-time AI responses in the browser
