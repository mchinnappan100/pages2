Slide 2 of 10 · Installation & Quick Start

Installation & Quick Start

# Install globally
npm install -g sf-utils-cli

# Launch (default port 3456)
sf-utils-v8

# Custom port
sf-utils-v8 -p 4000

# With AI Chat enabled
sf-utils-v8 --enable-AI

# With ERD generation enabled
sf-utils-v8 --enable-erd

# All features on a custom port
sf-utils-v8 -p 8080 --enable-AI --enable-erd

Prerequisites: Node.js ≥ 14, Salesforce CLI (sf), authenticated org. ERD requires sf plugins install sfdx-mohanc-plugins.

Slide 4 of 10 · SOQL Examples

SOQL Examples

-- Relationship traversal + sub-query
SELECT Id, Name, Owner.Name,
       (SELECT Id, Subject FROM Tasks)
FROM Account WHERE CreatedDate = THIS_MONTH

-- Aggregate with GROUP BY
SELECT Industry, COUNT(Id) Total, AVG(AnnualRevenue) Avg
FROM Account GROUP BY Industry HAVING COUNT(Id) > 5

-- Tooling API (enable checkbox)
SELECT Id, Name, Body, ApiVersion
FROM ApexClass WHERE Name LIKE 'Test%'
Slide 5 of 10 · Explore, History & ERD

Explore, History & ERD Panels

🔭 Explore Panel

  • Enter any SObject API name — get all fields, types, and attributes
  • Auto-generated SELECT scaffold covering every field
  • One-click: Load into Editor · View ERD · Ask AI
  • Uses REST /sobjects/{Obj}/describe — works for all users

🗺️ ERD Panel

  • Enter comma-separated SObject names
  • SVG renders inline; full-screen drawer with zoom (20–200%)
  • Download SVG for docs or presentations
  • Requires sf plugins install sfdx-mohanc-plugins

📚 History Panel

Every successful query auto-saved with timestamp, record count, and org username. Click to reload. Persists up to 50 entries in localStorage.

Slide 7 of 10 · Bulk API 2.0

Bulk API 2.0 (--bulkapi2)

Three Operations

  • Insert — Upload CSV; first row must be Salesforce field API names
  • Delete — Load IDs from last query results or paste manually. Type DELETE to confirm batches > 10 records
  • Upsert — CSV with external ID column; column selector auto-populates after file parsing

Job Lifecycle

  • Job created → CSV uploaded → job closed
  • Polls every 2.5s until JobComplete / Failed / Aborted
  • Live progress bar with succeeded/failed counts
  • Failed records shown in table with error messages
  • Download full results CSV (successful + failed + unprocessed)

Slide 10 of 10 · Summary

Key Takeaways

  • Single tool covers the full Salesforce developer workflow: SOQL → Apex → DML → Explore → ERD → Bulk API
  • Monaco Editor provides VS Code-grade editing — syntax highlighting, autocomplete, format-on-demand
  • AI Chat with context chips sends actual query results to the AI for accurate analysis
  • Bulk API 2.0 with live progress bar handles large-scale insert/update/upsert/delete jobs
  • 5 themes (Dark, Light, Cyberpunk, Nord, Solarized) — all persisted across sessions
  • ERD generation from comma-separated object names — SVG rendered inline, downloadable
  • Runs entirely locally — no cloud account, no credentials stored, no data leaves your machine
