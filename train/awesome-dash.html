awesome-dash

Generic CSV analytics dashboard — plug in any CSV, specify filter columns, and get instant KPI cards, doughnut charts, a timeline, numeric summaries, and a sortable table. Zero hardcoding required.

CSV Analytics Zero Config KPI Cards Charts v2.0.2 MIT

AutoFilter column detection
PipeStdin piping from any CLI
Slide 2 of 8 · Install & Quick Start

Installation & Quick Start

# Install globally
npm install -g awesome-dash

# Serve any CSV instantly
awesome-dash serve -d data/cars.csv

# With explicit filters and a title
awesome-dash serve -d cars.csv -f "origin,year,cylinders" -t "Cars Dashboard"

# Pipe directly from Salesforce CLI
sf data query -o myorg -q "SELECT Id,Name,Industry FROM Account" -r csv \
  | awesome-dash serve -t "Accounts"

Prerequisites: Node.js ≥ 18. No other dependencies to install — pure npm package.

Slide 3 of 8 · CLI Flags

All CLI Flags

FlagDefaultDescription
-d, --data <file>requiredPath to your CSV file (or omit to use stdin)
-f, --filters <fields>auto-detectedComma-separated filter columns (categorical)
--charts <fields>same as filtersColumns to render as doughnut charts
-p, --port <port>3000Port to listen on (auto-retries p+1, p+2… if in use)
-t, --title <title>Awesome DashboardUI title shown in the header
--id <field>—Primary identifier column
--date <field>auto-detectedDate column for the timeline chart
--page-size <n>25Default rows per page (10/25/50/100/500)
Slide 4 of 8 · Dashboard Widgets

Dashboard Widgets

📊KPI Cards
🍩Doughnut Charts
📈Timeline Chart
🔢Numeric Summaries
  • KPI Cards — total rows, unique values per filter column, computed aggregates
  • Doughnut Charts — one per --charts column; shows distribution of categorical values
  • Timeline Chart — record counts over time using the --date column
  • Numeric Summaries — min, max, avg for numeric columns
  • Sortable Table — click any column header, search across all fields, paginate
  • Dynamic Filters — add/remove filter columns at runtime via the Filters control
  • Measure Filters — numeric columns support >, >=, <, <=, = operators
Slide 5 of 8 · Zero Config & Auto-Detection

Zero Config & Smart Auto-Detection

What Gets Auto-Detected

  • Filter columns — low-cardinality string columns become filters automatically
  • Date column — first column that parses as dates drives the timeline
  • Numeric columns — auto-summarized with min/max/avg

Just point it at any CSV and get a working dashboard — no schema file, no config YAML, no code.

Extra Resilience

  • Port auto-retry — if 3000 is taken, tries 3001, 3002… automatically
  • Stdin piping — omit -d and pipe CSV from any tool
  • Hot-reload — dashboard refreshes when the source CSV changes
  • Light/Dark theme — toggle in the UI, persisted across sessions
Slide 6 of 8 · Real-World Examples

Real-World Usage Examples

# HR dataset with date tracking
awesome-dash serve \
  -d employees.csv \
  -f "Department,Location,Level,Status" \
  --charts "Department,Level" \ # only 2 of 4 filters get doughnut charts
  --date "HireDate" \
  -t "HR Dashboard" --page-size 50

# Sales pipeline from Salesforce query
awesome-dash serve \
  -d orders.csv \
  -f "Region,Product,SalesRep,Stage" \
  --date "CloseDate" --id "OpportunityId" \
  -t "Sales Pipeline"

# Live Salesforce data via stdin pipe
sf data query -o myorg -q "SELECT Id,Name,Industry,Type FROM Account" -r csv \
  | awesome-dash serve -f "Industry,Type" -t "Account Dashboard"

Slide 8 of 8 · Summary

Key Takeaways

  • Works with any CSV schema — zero hardcoding, no config files, no code changes required
  • Auto-detects filter columns (low-cardinality strings) and date columns — minimum flags needed
  • Stdin piping turns any CLI that outputs CSV into an instant dashboard (e.g. Salesforce CLI, jq, awk)
  • Port auto-retry means it never fails to start even if the default port is busy
  • Measure filters (>, <, =) allow numeric column filtering alongside categorical dropdowns
  • CSV export downloads the current filtered view — great for sharing a sliced snapshot
  • Hot-reload keeps the dashboard live as the source file updates
  • Light/Dark theme toggle — persistent across browser sessions
