Call Center Simulator

Agentforce-powered voice interaction platform for call center simulation, testing, and development — voice input (STT), Agentforce integration, async webhooks, and text-to-speech playback.

Agentforce Voice / STT Socket.IO JWT Auth Node.js ≥ 18 PostgreSQL MIT License
# Quick start
npm install
npm run migrate # create DB tables
npm start # http://localhost:5000
Slide 2 of 10 · Call Flow

End-to-End Call Flow

1
Customer speaks into the browser micWeb Speech API captures voice input continuously
2
Voice-to-Text transcriptionInterim results shown in real time; language auto-detected or user-selected
3
CCS sends REST POST to AgentforcePayload: { prompt, language, webhookUrl } + OAuth2 bearer token
4
Agentforce detects intent, queries Salesforce backendBusiness logic executed; response generated
5
Agentforce POSTs response to CCS webhookPOST /api/webhook receives responseText
6
Socket.IO pushes response to the agent's browserChat bubble appears; SpeechSynthesis reads it aloud (if TTS enabled)
Slide 3 of 10 · Features

Key Features

Voice & Real-time

  • Web Speech API mic — continuous recording, 10 languages
  • TTS playback — SpeechSynthesis reads responses aloud, toggle on/off
  • Socket.IO — responses appear instantly without polling
  • Typing indicator while awaiting Agentforce

Call Sessions & Auth

  • Create, list, view, and end call sessions per agent
  • JWT bearer tokens + bcrypt passwords
  • Role-based access: agent / supervisor / admin
  • Register or login with email or username
Batch CSV/JSON runner AI Sidekick Simulation mode Settings UI Heroku / Docker ready

Slide 5 of 10 · Quick Start

Getting Started

# 1. Install dependencies
npm install

# 2. Configure environment
cp .env.example .env # set JWT_SECRET + DATABASE_URL + Agentforce vars

# 3. Create DB and run migrations
psql -U postgres -c "CREATE DATABASE ccsdb;"
npm run migrate

# 4. Start (production)
npm start # → http://localhost:5000

# 4b. Start (dev, with auto-reload)
npm run dev
Slide 6 of 10 · CLI Reference

CLI Commands (ccs)

# Start server
node bin/ccs.js start --port 5000

# Register & login
node bin/ccs.js auth register -u alice -e alice@example.com -p MyPass1!
node bin/ccs.js auth login -e alice@example.com -p MyPass1!

# Sessions
node bin/ccs.js sessions list
node bin/ccs.js sessions create --lang en-US
node bin/ccs.js sessions end <session-id>

# Send a message
node bin/ccs.js msg send <session-id> "What is my order status?"

# Health check
node bin/ccs.js health
Slide 7 of 10 · Agentforce Integration

Agentforce Payload & Webhook

Request to Agentforce

{
  "prompt": "Order status?",
  "language": "en-US",
  "webhookUrl": "https://app/api/webhook",
  "sessionId": "019e…" // 2nd+ turns
}

Webhook Response

{
  "success": true,
  "sessionId": "019e…",
  "responseText": "No order found.",
  "sequenceId": 1
}
  • OAuth2 client_credentials token fetched once and cached in memory
  • Simulation mode — returns a local stub without hitting Salesforce; toggle in Settings UI
  • Response field priority: responseText → text → response

Slide 10 of 10 · Docker & Summary

Docker & Key Takeaways

# Start app + Postgres together
docker compose up --build # → http://localhost:3000
docker compose down # stop (keep data)
docker compose down -v # stop + delete volume
  • Full voice call simulation — STT mic input, Agentforce, TTS playback in one app
  • Real-time Socket.IO — no polling; responses appear the moment the webhook fires
  • Simulation mode lets you build and test UI flows without a live Salesforce org
  • Batch runner accelerates regression testing across many questions at once
  • AI Sidekick with ⚡ context injection helps agents draft replies and summaries
  • Heroku-ready Procfile + Docker Compose — one-command deploy to either platform
