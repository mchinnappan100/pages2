py-viz Studio

Local data visualization studio — Python does the rendering, Node.js serves the UI. Pick a chart type, edit the JSON spec in Monaco, hit Render, and see the result instantly via WebSocket. Ask the AI Sidekick to generate charts from plain English, CSV, or JSON.

Slide 2 of 8 · Installation & Quick Start

Installation & Quick Start

# Install globally (Node.js ≥ 18 required)
npm install -g py-viz

# Start the studio (auto-opens browser)
py-viz serve

# Custom port
py-viz serve --port 3567

# With AI Sidekick
py-viz serve --enable-ai

# No auto-open
py-viz serve --port 3567 --no-open

On first run, py-viz creates .py-viz-venv/ and installs all Python dependencies (~1 min). Subsequent starts are instant. Python ≥ 3.9 required.

Slide 4 of 8 · JSON Spec Format

JSON Spec Format

Every chart is driven by a column-oriented JSON spec sent over WebSocket — edit in Monaco, hit Render.

// Plotly bar chart
{
  "type": "plotly/bar",
  "title": "Sales by Region",
  "x": "region",
  "y": "sales",
  "data": {
    "region": ["North", "South", "East", "West"],
    "sales": [420, 380, 510, 290]
  }
}

The data field is always column-oriented. Click ? Help for a full field reference per chart type, including the Python source code that renders it.

Slide 5 of 8 · AI Sidekick

AI Sidekick (--enable-ai)

Supported Providers

  • Ollama — Local, free, models auto-discovered
  • Claude — ANTHROPIC_API_KEY
  • OpenAI — OPENAI_API_KEY
  • xAI Grok — XAI_API_KEY
  • Gemini — GEMINI_API_KEY

Keys saved in localStorage; never leave your browser except as local loopback requests.

Example Prompts

Bar chart: Jan 120, Feb 95, Mar 140

Scatter from CSV:
name,height,weight

Bob,180,80

Choropleth world map of GDP:

Slide 6 of 8 · Architecture

Architecture

Browser ──WS──► Node.js (Express + ws) ──stdin──► Python subprocess
                 ├── /api/render (REST) ◄──stdout── (renderer.py)
                 ├── /api/ai/* (LLM proxy)
                 │    ├── Ollama · Claude · OpenAI · xAI · Gemini
                 └── /api/config (feature flags)
  • Monaco editor sends JSON spec over WebSocket — no page reload needed
  • Node.js passes spec to a persistent Python subprocess via stdin
  • Python renders the chart using the appropriate library and returns HTML/SVG via stdout
  • Graceful shutdown on Ctrl+C — Python subprocess exits cleanly
  • REST endpoint POST /api/render also available for programmatic use

Slide 8 of 8 · Summary

Key Takeaways

  • 25+ chart types across Plotly, Matplotlib, Seaborn, Altair, and Bokeh — all from a single JSON spec format
  • Python venv auto-created on first run — zero manual setup beyond npm install -g py-viz
  • Live WebSocket preview — change the spec, click Render, see the chart instantly
  • AI Sidekick generates specs from plain English, raw CSV, or JSON — with clickable example pills
  • Help drawer shows both field reference and the actual Python handler code for every chart type
  • REST API (POST /api/render) enables programmatic chart generation from scripts or CI
  • Runs entirely locally — no cloud, no data leaves your machine
