sf-permset-assignor

Bulk-assign one or more Salesforce Permission Sets to users from a CSV file — with a real-time web UI showing live logs, progress bar, per-user stats, and timestamped log downloads.

Salesforce Permission Sets Bulk Assignment Node.js ≥ 18 v1.0.0 MIT License
# Install globally
npm install -g sf-permset-assignor

# Launch the web UI
assign-permset -p 3131
Slide 2 of 8 · The Problem

Why sf-permset-assignor?

Assigning permission sets to many users in Salesforce requires either clicking through Setup one user at a time, or writing custom Apex / data loader scripts with no visibility into progress.

  • No built-in tool to bulk-assign a permission set from a CSV of usernames
  • Salesforce Setup UI requires navigating per user — impractical for dozens or hundreds
  • Data Loader can only load data, not assign permission sets
  • No real-time feedback on which assignments succeeded, were skipped, or failed
  • Handling duplicates (already-assigned) gracefully requires custom scripting

sf-permset-assignor solves this

One command opens a browser UI — upload a CSV, pick your org and permission sets, and watch live colored logs as each assignment happens. Works headlessly from the CLI too.

Slide 3 of 8 · Key Features

What You Get

UI Features

  • Searchable org dropdown — all authenticated orgs via sf org login
  • Searchable permission set multi-select with tag-based selection
  • CSV drag-and-drop with user preview table
  • Real-time live log — color-coded per permission set
  • Progress bar with Total / Assigned / Skipped / Failed stats

Workflow Features

  • Timestamped log file download after each run
  • New Run button — restart without restarting the server
  • Splash screen and context help modal
  • Dark / light theme, persisted to localStorage
  • Graceful handling of duplicate (already-assigned) permsets
Slide 4 of 8 · Two Ways to Use It

UI Mode vs CLI Mode

UI Mode (Recommended)

assign-permset -p 3131
  • Browser opens automatically at http://localhost:3131
  • Select org from dropdown (all authenticated orgs listed)
  • Search & tag-select one or more permission sets
  • Drag-and-drop your CSV and preview users before running
  • Watch live color-coded log as each assignment happens

CLI Mode (Automated)

assign-permset \
 -o my-org \
 --ps MyPermSet \
 -f users.csv
  • Fully headless — no browser interaction needed
  • Auto-starts assignment when -o, --ps, and -f all provided
  • Ideal for CI/CD pipelines and scripted org setup
Slide 5 of 8 · CSV Format

Input CSV Format

The CSV must contain a Username column (case-insensitive). Any additional columns are silently ignored.

# Minimal — Username column only
Username
john.doe@myorg.com
jane.doe@myorg.com
admin@myorg.com

# Extra columns OK — they are ignored
Username,Role,Department
john.doe@myorg.com,Sales Rep,EMEA
jane.doe@myorg.com,Manager,APAC
  • Header is matched case-insensitively — username, USERNAME, and Username all work
  • Preview table in the UI shows all users before you start
  • Supports drag-and-drop onto the UI or -f <path> in CLI mode
Slide 6 of 8 · Stats & Per-User Behavior

Progress Stats Explained

Total
All users in the CSV attempted
Assigned
At least one permset newly assigned
Skipped
All permsets already assigned, or user not found
Failed
At least one permset returned an error
  • Multi-permset: each user is processed through all selected permission sets
  • Duplicate assignments are handled gracefully — not counted as failures
  • Live log is color-coded per permission set, making multi-set runs easy to read
  • Download the full timestamped log after the run: permset-log-YYYY-MM-DDTHH-mm-ss.txt
Slide 7 of 8 · CLI Options

All CLI Flags

FlagDescriptionDefault
-o, --org <alias> Target org username or alias — pre-selects the org in the UI —
--ps <name> Permission Set API name — pre-fills in UI; triggers auto-start in CLI mode —
-f, --file <csv> CSV file path — auto-starts assignment when combined with -o and --ps —
-p, --port <n> Web UI server port 3131

Prerequisites

  • Node.js v18 or higher
  • Salesforce CLI (sf) installed and at least one org authenticated via sf org login web
Slide 8 of 8 · Summary

Key Takeaways

  • Bulk-assign permission sets to any number of users from a simple CSV — no Apex, no Data Loader
  • Multi-select permission sets and assign all of them in a single run
  • Live color-coded log makes it immediately clear which assignments succeeded, were skipped, or failed
  • Duplicate assignments handled gracefully — already-assigned users are skipped, not errored
  • CLI mode (-o + --ps + -f) enables fully automated, scriptable bulk assignment
  • New Run button resets state without restarting the server — fast for repeated runs
  • Timestamped log download provides an audit trail of every operation
