01 / The journey

A movement built
around user freedom.

In an era when software was increasingly distributed as a product users could not inspect or change, Stallman argued for a different foundation: users should control their computing.

1953

A curious mind begins

Born in New York City on March 16.

1971

MIT beginnings

Began working at the MIT Artificial Intelligence Laboratory as a programmer.

1983

GNU announced

Announced the GNU Project: a free Unix-like operating system.

1984

GNU development

Started full-time work on GNU after leaving MIT.

1985

Movement organized

Published the GNU Manifesto and founded the Free Software Foundation.

1989

GNU GPL

The first version of the GNU General Public License was published.

1990s

A growing ecosystem

GNU tools and the GPL became important building blocks across free-software projects.

Today

An ongoing conversation

Software freedom remains a live question in operating systems, cloud services and AI.

02 / The four freedoms

Users deserve control
over their software.

The free-software definition describes four essential freedoms. They are about what users are allowed to do—not whether software costs money.

0

Run

Run the program as you wish, for any purpose.

1

Study & change

Study how the program works and change it to suit your needs. Access to source code is essential.

2

Redistribute

Redistribute copies so you can help your neighbor.

3

Share improvements

Distribute copies of your modified versions so the community can benefit.

03 / The work

Tools, licenses and ideas
that changed computing.

The movement was not only a philosophy. It produced practical tools and a legal framework that enabled people to collaborate and share.

01 · OPERATING SYSTEM

The GNU Project

An effort to create a complete Unix-like operating system composed entirely of free software.

02 · EDITOR

GNU Emacs

An extensible, programmable text editor that became a platform for building customized workflows.

03 · COMPILERS

GCC

The GNU Compiler Collection: a widely used suite of compilers for multiple programming languages.

04 · DEBUGGING

GDB

The GNU Debugger helps developers inspect program execution and diagnose problems.

05 · LICENSE

GNU GPL & copyleft

Copyleft uses copyright law to preserve the freedoms to use, study, share and modify covered software.

06 · COMMUNITY

Free Software Foundation

Founded in 1985 to promote computer users' rights to use, study, copy, modify and redistribute software.

04 / A key distinction

Free as in freedom.
Not just free of charge.

Free software is defined by the freedoms it grants users. It may be sold or given away; the essential point is that users retain the freedom to run, study, modify and share it.

# The GNU philosophy, in brief

use(software)
study(source_code)
modify(software)
share(copies)

# Keep users in control.
05 / The enduring legacy

A computer should serve its user—not place the user under the control of its software.

A dedication inspired by Stallman's work: question who controls the tools we depend on, keep knowledge shareable, and protect the freedom to learn and build.
