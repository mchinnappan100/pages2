A dedication to the author of C · 1941—2011

Dennis Ritchie.

Quiet work. Foundations everywhere.

Programmer, creator of the C language and co-creator of Unix. Ritchie's exact, unshowy work at Bell Labs became the base layer of modern software, from operating systems to the languages written after it.

01 / The journey

A language built to
get out of the way.

Ritchie spent his career at Bell Labs. He shaped a language and an operating system together, so each could carry the other.

1941

Born in Bronxville

Dennis MacAlistair Ritchie is born in New York on September 9.

1967

Bell Labs

After studying physics and applied mathematics at Harvard, he joins Bell Labs and works on Multics.

1969

Unix begins

Works with Ken Thompson and colleagues on a small new operating system.

1972–73

C, and Unix in C

C takes shape in 1972. In 1973 the Unix kernel is rewritten in it, which makes Unix portable.

1978

The C book

Ritchie and Brian Kernighan publish The C Programming Language. Readers call it "K&R".

1983

Turing Award

Shares ACM's Turing Award with Ken Thompson for their work on Unix.

1998

National Medal

Receives the US National Medal of Technology together with Thompson.

2011

Japan Prize

Is named a Japan Prize laureate with Thompson. He dies on October 12, aged 70.

02 / The four ideas

What C taught
a whole industry.

Ritchie described C as a language efficient enough to displace assembly, yet abstract enough to express algorithms across many environments. Four ideas sit inside that description.

1

Economy

A small language with a few sharp concepts. The K&R book that described it was famously slim.

2

Closeness

Pointers and direct memory access let programmers write system software without dropping to assembly.

3

Portability

Rewriting Unix in C let one operating system move between very different computers.

4

Teaching

A clear book and a clear language trained generations of programmers. Its first example is still the world's favorite.

03 / The work

A language, a system
and the ideas between them.

Ritchie's best-known pieces are two sides of one design: a language that could describe an operating system, and an operating system worth describing.

01 · LANGUAGE

C

Developed at Bell Labs around 1972, growing out of Thompson's B. It became a lingua franca for systems software.

02 · OPERATING SYSTEM

Unix

Co-created with Ken Thompson from 1969. Its ideas live on in Linux, macOS and the BSDs.

03 · BOOK

The C Programming Language

Written with Brian Kernighan and published in 1978. For many programmers it was the first book that made systems code feel readable.

04 · INPUT / OUTPUT

Streams

Ritchie's stream system gave the Unix kernel a modular way to connect devices and protocols.

05 · SUCCESSORS

Plan 9 and Inferno

He kept working at Bell Labs on new systems that carried Unix's ideas into networked computing.

06 · DESCENDANTS

The C family

C++, Java, C# and many other languages borrow its syntax. Go's designers also came from the Unix tradition.

04 / Hello, world

A few lines that
taught a generation.

The first edition of The C Programming Language opened with a tiny program that prints a greeting. Millions of programmers have typed some version of it as their first line of real code.

/* the K&R opening program */

#include <stdio.h>

main()
{
    printf("hello, world\n");
}
05 / The enduring legacy

C is quirky, flawed, and an enormous success.

A dedication inspired by Ritchie's work: build tools that disappear into the work, keep them small enough to learn, and let others build on them.

Dennis Ritchie · The Development of the C Language · 1993
