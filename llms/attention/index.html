Transformer — PyTorch Implementation

Cell 2 — Scaled Dot-Product Attention (§3.2.1)

Attention(Q, K, V) = softmax( QKᵀ / √d_k ) · V

This is the fundamental operation of the Transformer. Three matrices — Query, Key, and Value — are derived from the input. The dot product of Q and K measures compatibility between positions; dividing by √d_k prevents the values from growing so large that softmax gradients vanish.

  • Scaling by √d_k — without it, large d_k pushes dot products into softmax saturation regions
  • mask — fills positions with −1e9 before softmax so they receive ~0 attention weight (used for padding and causal masking)
  • Returns weights too — handy for attention visualisation without a second forward pass
[2] code · §3.2.1 Scaled Dot-Product Attention 
def scaled_dot_product_attention(
    query: Tensor, key: Tensor, value: Tensor,
    mask: Tensor = None, dropout_p: float = 0.0
) -> tuple[Tensor, Tensor]:
    """
    Paper §3.2.1 — Attention(Q, K, V) = softmax(QK^T / sqrt(d_k)) V

    Args:
        query:  (batch, heads, seq_q, d_k)
        key:    (batch, heads, seq_k, d_k)
        value:  (batch, heads, seq_k, d_v)
        mask:   optional boolean mask; True positions are IGNORED
    Returns:
        output: (batch, heads, seq_q, d_v)
        weights:(batch, heads, seq_q, seq_k)  — useful for visualisation
    """
    d_k = query.size(-1)

    # QK^T / sqrt(d_k) — scale prevents vanishing gradients in softmax
    scores = torch.matmul(query, key.transpose(-2, -1)) / math.sqrt(d_k)

    # Apply mask (e.g. causal mask in decoder, padding mask in encoder)
    if mask is not None:
        scores = scores.masked_fill(mask == 0, -1e9)

    # Softmax over key dimension to get attention weights
    weights = F.softmax(scores, dim=-1)

    if dropout_p > 0.0:
        weights = F.dropout(weights, p=dropout_p)

    # Weighted sum of values
    output = torch.matmul(weights, value)
    return output, weights

§3.2.2 Multi-Head Attention

MultiHead(Q,K,V) = Concat(head₁,…,headₕ) W^O
where headᵢ = Attention(QWᵢQ, KWᵢK, VWᵢV)

Each head attends to different representation subspaces, allowing the model to jointly attend to information from different positions.

Paper uses h = 8 heads, d_model = 512, so each head has d_k = d_v = 64.

Cell 4 — MultiHeadAttention class (§3.2.2)

Rather than one big attention over d_model dimensions, the paper runs h = 8 parallel attention heads, each operating in a d_k = 64 dimensional subspace. Each head can learn to attend to different types of relationships simultaneously (syntax, coreference, proximity, …).

  • W_q, W_k, W_v — learned projection matrices that map d_model → d_model (split across heads)
  • _split_heads — reshapes (B, T, d_model) → (B, H, T, d_k) so all heads run in one batched matmul
  • W_o — output projection recombines the concatenated heads back to d_model
  • No bias on projections — matching the paper's formulation
[4] code · §3.2.2 Multi-Head Attention 
class MultiHeadAttention(nn.Module):
    """Multi-head attention as described in §3.2.2."""

    def __init__(self, d_model: int, num_heads: int, dropout: float = 0.1):
        super().__init__()
        assert d_model % num_heads == 0, "d_model must be divisible by num_heads"

        self.d_model   = d_model
        self.num_heads = num_heads
        self.d_k       = d_model // num_heads  # dimension per head
        self.dropout_p = dropout

        # Projection matrices W^Q, W^K, W^V, W^O  (all learned)
        self.W_q = nn.Linear(d_model, d_model, bias=False)
        self.W_k = nn.Linear(d_model, d_model, bias=False)
        self.W_v = nn.Linear(d_model, d_model, bias=False)
        self.W_o = nn.Linear(d_model, d_model, bias=False)

    def _split_heads(self, x: Tensor) -> Tensor:
        """(batch, seq, d_model) → (batch, heads, seq, d_k)"""
        B, T, _ = x.shape
        x = x.view(B, T, self.num_heads, self.d_k)
        return x.transpose(1, 2)  # (B, H, T, d_k)

    def forward(
        self,
        query: Tensor, key: Tensor, value: Tensor,
        mask: Tensor = None
    ) -> tuple[Tensor, Tensor]:
        B = query.size(0)

        # Project and split into H heads
        Q = self._split_heads(self.W_q(query))
        K = self._split_heads(self.W_k(key))
        V = self._split_heads(self.W_v(value))

        # Scaled dot-product attention for all heads in parallel
        attn_out, attn_weights = scaled_dot_product_attention(
            Q, K, V, mask=mask, dropout_p=self.dropout_p if self.training else 0.0
        )

        # Concatenate heads: (B, H, T, d_k) → (B, T, d_model)
        attn_out = attn_out.transpose(1, 2).contiguous().view(B, -1, self.d_model)

        # Final linear projection W^O
        output = self.W_o(attn_out)
        return output, attn_weights

Cell 5 — Position-wise Feed-Forward Network (§3.3)

FFN(x) = max(0, xW₁ + b₁) W₂ + b₂

After attention mixes information across positions, the FFN processes each position independently — the same two-layer MLP applied to every token separately. Think of it as the "thinking" step after the "attending" step.

  • d_ff = 2048 — the inner layer is 4× wider than d_model = 512, giving the network capacity to store factual associations
  • ReLU activation — the paper uses ReLU; later variants (GPT, BERT) swap in GeLU for smoother gradients
  • Dropout is applied between the two linear layers during training
[5] code · §3.3 Position-wise Feed-Forward Network 
class PositionwiseFeedForward(nn.Module):
    """
    §3.3  FFN(x) = max(0, xW₁ + b₁)W₂ + b₂

    Paper: d_model = 512, d_ff = 2048 (inner layer 4× wider).
    ReLU activation between the two linear transforms.
    """

    def __init__(self, d_model: int, d_ff: int, dropout: float = 0.1):
        super().__init__()
        self.linear1  = nn.Linear(d_model, d_ff)
        self.linear2  = nn.Linear(d_ff, d_model)
        self.dropout  = nn.Dropout(dropout)
        self.act      = nn.ReLU()

    def forward(self, x: Tensor) -> Tensor:
        # Expand → ReLU → Dropout → Project back
        return self.linear2(self.dropout(self.act(self.linear1(x))))

Cell 6 — Positional Encoding (§3.5)

PE(pos, 2i) = sin(pos / 10000^(2i/d_model))  ·  PE(pos, 2i+1) = cos(pos / 10000^(2i/d_model))

Self-attention is permutation-invariant — it has no notion of word order by itself. Positional encodings inject position information by adding a fixed vector to each token embedding before the first layer.

  • Sin/cos at different frequencies — each dimension oscillates at a different rate, so the model can learn to attend by relative offset: PE(pos+k) is a linear function of PE(pos)
  • Fixed (not learned) — the paper found fixed and learned encodings performed similarly; fixed ones generalise better to longer sequences
  • register_buffer — the PE matrix is saved with the model's state_dict but excluded from gradient updates
[6] code · §3.5 Positional Encoding 
class PositionalEncoding(nn.Module):
    """
    §3.5  Injects position information using fixed sin/cos encodings:
        PE(pos, 2i)   = sin(pos / 10000^(2i/d_model))
        PE(pos, 2i+1) = cos(pos / 10000^(2i/d_model))

    These are added to the token embeddings before the first layer.
    Allows the model to learn to attend by relative position.
    """

    def __init__(self, d_model: int, max_len: int = 5000, dropout: float = 0.1):
        super().__init__()
        self.dropout = nn.Dropout(p=dropout)

        # Build PE matrix once, register as non-learnable buffer
        pe  = torch.zeros(max_len, d_model)
        pos = torch.arange(0, max_len, dtype=torch.float).unsqueeze(1)
        div = torch.exp(
            torch.arange(0, d_model, 2, dtype=torch.float)
            * (-math.log(10000.0) / d_model)
        )
        pe[:, 0::2] = torch.sin(pos * div)
        pe[:, 1::2] = torch.cos(pos * div)

        # (1, max_len, d_model) so it broadcasts over batch dimension
        self.register_buffer("pe", pe.unsqueeze(0))

    def forward(self, x: Tensor) -> Tensor:
        # x: (batch, seq_len, d_model)
        x = x + self.pe[:, :x.size(1)]
        return self.dropout(x)

Cell 7 — Encoder Layer (§3.1)

One encoder layer applies two sub-layers in sequence, each wrapped with a residual connection and Layer Normalization:

  • Sub-layer 1 — Multi-head self-attention: every token attends to every other token in the source sequence
  • Sub-layer 2 — Position-wise FFN: each token is processed independently

The residual connection x + sublayer(x) ensures gradients flow cleanly through N=6 stacked layers. LayerNorm (Post-LN, as in the original paper) stabilises the activations after each residual addition.

[7] code · §3.1 Encoder Layer 
class EncoderLayer(nn.Module):
    """
    §3.1  One encoder layer = self-attention + FFN, each with:
        • Residual connection (x + sublayer(x))
        • Layer Normalisation  (Post-LN as in original paper)
    """

    def __init__(self, d_model: int, num_heads: int, d_ff: int, dropout: float = 0.1):
        super().__init__()
        self.self_attn = MultiHeadAttention(d_model, num_heads, dropout)
        self.ffn       = PositionwiseFeedForward(d_model, d_ff, dropout)
        self.norm1     = nn.LayerNorm(d_model)
        self.norm2     = nn.LayerNorm(d_model)
        self.dropout   = nn.Dropout(dropout)

    def forward(self, x: Tensor, src_mask: Tensor = None) -> Tensor:
        # Sub-layer 1: Multi-head self-attention with residual + LayerNorm
        attn_out, _ = self.self_attn(x, x, x, mask=src_mask)
        x = self.norm1(x + self.dropout(attn_out))

        # Sub-layer 2: Position-wise FFN with residual + LayerNorm
        ffn_out = self.ffn(x)
        x = self.norm2(x + self.dropout(ffn_out))
        return x

Cell 8 — Decoder Layer (§3.1)

The decoder layer has three sub-layers compared to the encoder's two:

  • Sub-layer 1 — Masked self-attention: tokens in the target sequence attend to each other, but a causal mask prevents position i from seeing positions i+1 … T. This enforces auto-regressive generation during training.
  • Sub-layer 2 — Cross-attention: decoder queries attend to encoder keys and values. This is where the decoder "reads" the encoded source representation.
  • Sub-layer 3 — FFN: same position-wise network as the encoder.

Each sub-layer is wrapped with residual + LayerNorm, just as in the encoder.

[8] code · §3.1 Decoder Layer 
class DecoderLayer(nn.Module):
    """
    §3.1  One decoder layer = masked self-attention + cross-attention + FFN.
        • Masked self-attention prevents positions from attending to future tokens.
        • Cross-attention queries from decoder, keys & values from encoder output.
    """

    def __init__(self, d_model: int, num_heads: int, d_ff: int, dropout: float = 0.1):
        super().__init__()
        self.self_attn  = MultiHeadAttention(d_model, num_heads, dropout)
        self.cross_attn = MultiHeadAttention(d_model, num_heads, dropout)
        self.ffn        = PositionwiseFeedForward(d_model, d_ff, dropout)
        self.norm1      = nn.LayerNorm(d_model)
        self.norm2      = nn.LayerNorm(d_model)
        self.norm3      = nn.LayerNorm(d_model)
        self.dropout    = nn.Dropout(dropout)

    def forward(
        self, x: Tensor, enc_out: Tensor,
        tgt_mask: Tensor = None, src_mask: Tensor = None
    ) -> Tensor:
        # Sub-layer 1: Masked multi-head self-attention
        sa_out, _ = self.self_attn(x, x, x, mask=tgt_mask)
        x = self.norm1(x + self.dropout(sa_out))

        # Sub-layer 2: Cross-attention — Q from decoder, K/V from encoder
        ca_out, _ = self.cross_attn(x, enc_out, enc_out, mask=src_mask)
        x = self.norm2(x + self.dropout(ca_out))

        # Sub-layer 3: Position-wise FFN
        x = self.norm3(x + self.dropout(self.ffn(x)))
        return x

Cell 9 — Encoder Stack

The full encoder is N=6 identical EncoderLayer instances stacked sequentially, followed by a final LayerNorm. The source token embeddings enter the bottom and a rich contextual representation exits the top — this becomes the memory the decoder attends to.

Each layer is deep-copied so weights are independent across layers, even though the architecture is identical. The final LayerNorm stabilises the output scale before it enters cross-attention in the decoder.

[9] code · Encoder Stack (N=6 layers) 
class Encoder(nn.Module):
    """Stack of N identical encoder layers followed by final LayerNorm."""

    def __init__(self, layer: EncoderLayer, N: int):
        super().__init__()
        # Deep-copy so each layer has independent weights
        self.layers = nn.ModuleList([copy.deepcopy(layer) for _ in range(N)])
        self.norm   = nn.LayerNorm(layer.self_attn.d_model)

    def forward(self, x: Tensor, src_mask: Tensor = None) -> Tensor:
        for layer in self.layers:
            x = layer(x, src_mask)
        return self.norm(x)

Cell 10 — Decoder Stack

Mirrors the encoder stack: N=6 identical DecoderLayer instances plus a final LayerNorm. The decoder receives two inputs on every forward pass:

  • tgt — the target tokens seen so far (shifted right, teacher-forced during training)
  • enc_out — the encoder's output, passed unchanged to every decoder layer's cross-attention

Both tgt_mask (causal) and src_mask (padding) thread through all layers so each layer applies appropriate masking.

[10] code · Decoder Stack (N=6 layers) 
class Decoder(nn.Module):
    """Stack of N identical decoder layers followed by final LayerNorm."""

    def __init__(self, layer: DecoderLayer, N: int):
        super().__init__()
        self.layers = nn.ModuleList([copy.deepcopy(layer) for _ in range(N)])
        self.norm   = nn.LayerNorm(layer.self_attn.d_model)

    def forward(
        self, x: Tensor, enc_out: Tensor,
        tgt_mask: Tensor = None, src_mask: Tensor = None
    ) -> Tensor:
        for layer in self.layers:
            x = layer(x, enc_out, tgt_mask, src_mask)
        return self.norm(x)

Cell 11 — Full Transformer Model

This class assembles everything into the complete encoder-decoder Transformer. The base config from Table 3 of the paper: d_model=512, N=6, h=8, d_ff=2048, dropout=0.1.

  • Embedding scaling — embeddings are multiplied by √d_model (§3.4) so they sit in the same magnitude range as the positional encodings
  • Separate src/tgt embeddings — the paper shares weights between the two embedding tables and the final projection in some experiments; here kept separate for clarity
  • Xavier uniform init — applied to all weight matrices at construction for stable initial gradient flow
  • log_softmax output — pairs with NLLLoss in the training loop (equivalent to CrossEntropyLoss on logits)
[11] code · Full Transformer Model 
class Transformer(nn.Module):
    """
    Full encoder-decoder Transformer as in §3.
    Paper base config: d_model=512, N=6, h=8, d_ff=2048, dropout=0.1.
    """

    def __init__(
        self,
        src_vocab_size: int, tgt_vocab_size: int,
        d_model: int = 512, N: int = 6,
        num_heads: int = 8, d_ff: int = 2048,
        max_len: int = 512, dropout: float = 0.1
    ):
        super().__init__()

        # Embeddings + positional encoding for source and target
        self.src_embed = nn.Embedding(src_vocab_size, d_model)
        self.tgt_embed = nn.Embedding(tgt_vocab_size, d_model)
        self.src_pe    = PositionalEncoding(d_model, max_len, dropout)
        self.tgt_pe    = PositionalEncoding(d_model, max_len, dropout)

        # Encoder / Decoder stacks
        enc_layer = EncoderLayer(d_model, num_heads, d_ff, dropout)
        dec_layer = DecoderLayer(d_model, num_heads, d_ff, dropout)
        self.encoder = Encoder(enc_layer, N)
        self.decoder = Decoder(dec_layer, N)

        # Linear projection to vocabulary + log-softmax
        self.proj = nn.Linear(d_model, tgt_vocab_size)

        self.d_model = d_model
        self._init_weights()

    def _init_weights(self):
        """Xavier uniform initialisation for all linear layers."""
        for p in self.parameters():
            if p.dim() > 1:
                nn.init.xavier_uniform_(p)

    def encode(self, src: Tensor, src_mask: Tensor = None) -> Tensor:
        # Scale embeddings by sqrt(d_model) as in §3.4
        src_emb = self.src_pe(self.src_embed(src) * math.sqrt(self.d_model))
        return self.encoder(src_emb, src_mask)

    def decode(
        self, tgt: Tensor, enc_out: Tensor,
        tgt_mask: Tensor = None, src_mask: Tensor = None
    ) -> Tensor:
        tgt_emb = self.tgt_pe(self.tgt_embed(tgt) * math.sqrt(self.d_model))
        return self.decoder(tgt_emb, enc_out, tgt_mask, src_mask)

    def forward(
        self, src: Tensor, tgt: Tensor,
        src_mask: Tensor = None, tgt_mask: Tensor = None
    ) -> Tensor:
        enc_out = self.encode(src, src_mask)
        dec_out = self.decode(tgt, enc_out, tgt_mask, src_mask)
        return F.log_softmax(self.proj(dec_out), dim=-1)

Cell 12 — Mask Utilities

Two masks are needed to train correctly:

  • Source (padding) mask — marks PAD tokens in the source so the encoder and cross-attention don't waste attention weight on them. Shape (B, 1, 1, src_len) broadcasts over all heads.
  • Target (causal) mask — combines a padding mask with a lower-triangular matrix so each decoder position can only attend to itself and earlier positions. This is what makes the decoder auto-regressive: during training it sees all target tokens at once but the mask prevents future peeking.
[12] code · Mask utilities 
def make_src_mask(src: Tensor, pad_idx: int = 0) -> Tensor:
    """Mask out PAD tokens in the source sequence.
    Returns shape (batch, 1, 1, src_len) for broadcasting over heads."""
    return (src != pad_idx).unsqueeze(1).unsqueeze(2)


def make_tgt_mask(tgt: Tensor, pad_idx: int = 0) -> Tensor:
    """Combine padding mask and causal (no-look-ahead) mask for the target.
    A position may only attend to itself and earlier positions."""
    T = tgt.size(1)
    pad_mask  = (tgt != pad_idx).unsqueeze(1).unsqueeze(2)  # (B,1,1,T)
    causal    = torch.tril(torch.ones(T, T, device=tgt.device)).bool()  # (T,T)
    return pad_mask & causal  # broadcast to (B,1,T,T)

Cell 14 — Training Loop & Noam Scheduler (§5.3)

The paper uses a custom learning rate schedule that warms up linearly for 4000 steps, then decays as the inverse square root of the step number. A flat or too-high LR in the early steps destabilises the randomly-initialised attention weights.

lr = d_model⁻⁰·⁵ · min(step⁻⁰·⁵, step · warmup_steps⁻¹·⁵)

Key training decisions:

  • Teacher forcing — during training the decoder receives the ground-truth previous tokens (tgt[:-1]), not its own predictions. This gives stable gradients but creates an exposure bias gap at inference time.
  • Gradient clipping at max_norm=1.0 — prevents occasional large gradient spikes from destabilising training
  • NLLLoss with ignore_index — PAD tokens don't contribute to the loss
[14] code · Training loop skeleton 
class NoamScheduler:
    """
    §5.3 Learning rate schedule from the paper:
        lr = d_model^(-0.5) * min(step^(-0.5), step * warmup_steps^(-1.5))
    Increases linearly for warmup_steps, then decays as inverse sqrt of step.
    """

    def __init__(self, d_model: int, warmup_steps: int = 4000):
        self.d_model       = d_model
        self.warmup_steps  = warmup_steps
        self.step_num      = 0

    def rate(self, step: int) -> float:
        step = max(step, 1)
        return (self.d_model ** -0.5) * min(step ** -0.5, step * self.warmup_steps ** -1.5)


def train_epoch(model, loader, optimizer, scheduler, pad_idx=0):
    model.train()
    total_loss = 0.0
    criterion  = nn.NLLLoss(ignore_index=pad_idx)

    for batch in loader:
        src, tgt = batch  # (B, src_len), (B, tgt_len)
        src, tgt = src.to(DEVICE), tgt.to(DEVICE)

        # Teacher forcing: decoder input is tgt[:-1], label is tgt[1:]
        tgt_in  = tgt[:, :-1]
        tgt_out = tgt[:, 1:]

        src_mask = make_src_mask(src, pad_idx)
        tgt_mask = make_tgt_mask(tgt_in, pad_idx)

        # Forward pass
        logits = model(src, tgt_in, src_mask, tgt_mask)

        # Reshape for NLL: (B * T, vocab) vs (B * T)
        loss = criterion(
            logits.reshape(-1, logits.size(-1)),
            tgt_out.reshape(-1)
        )

        # Backward + update
        optimizer.zero_grad()
        loss.backward()
        nn.utils.clip_grad_norm_(model.parameters(), max_norm=1.0)

        # Apply Noam schedule before the optimiser step
        scheduler.step_num += 1
        for pg in optimizer.param_groups:
            pg["lr"] = scheduler.rate(scheduler.step_num)

        optimizer.step()
        total_loss += loss.item()

    return total_loss / len(loader)

Cell 15 — Greedy Decode (Inference)

At inference time the decoder runs auto-regressively — it generates one token at a time, appending each prediction to the sequence before generating the next. The source is encoded once and the same enc_out is reused at every step.

Greedy decoding always picks the single highest-probability token. It's fast but suboptimal — production systems use beam search (the paper uses beam width 4) which keeps the top-k partial sequences alive and finds better global solutions.

  • Stops early when all items in the batch produce the EOS token
  • @torch.no_grad() disables gradient tracking — essential for memory efficiency during inference
  • The smoke test at the bottom runs two random sequences through the untrained model to verify shapes are correct
[15] code · Greedy decode (inference) 
@torch.no_grad()
def greedy_decode(
    model: Transformer,
    src: Tensor,
    bos_idx: int, eos_idx: int,
    max_len: int = 50,
    pad_idx: int = 0
) -> Tensor:
    """
    Auto-regressive greedy decoding.
    At each step pick the highest-probability next token until EOS or max_len.
    """
    model.eval()
    src = src.to(DEVICE)
    src_mask = make_src_mask(src, pad_idx)

    # Encode source once
    enc_out = model.encode(src, src_mask)

    # Start with BOS token
    B = src.size(0)
    ys = torch.full((B, 1), bos_idx, dtype=torch.long, device=DEVICE)

    for _ in range(max_len - 1):
        tgt_mask = make_tgt_mask(ys, pad_idx)
        out      = model.decode(ys, enc_out, tgt_mask, src_mask)
        # Greedy: take argmax over vocab at the last position
        next_tok = model.proj(out[:, -1]).argmax(dim=-1, keepdim=True)
        ys = torch.cat([ys, next_tok], dim=1)

        # Stop when all batch items have produced EOS
        if (next_tok == eos_idx).all():
            break

    return ys  # (batch, decoded_len)

Architecture Summary

  • d_model = 512 — embedding & hidden dimension throughout
  • N = 6 — identical layers in both encoder and decoder stacks
  • h = 8 — attention heads (each d_k = d_v = 64)
  • d_ff = 2048 — inner FFN dimension (4× d_model)
  • Dropout = 0.1 — applied after each sub-layer
  • ~65M params — base model; "big" model uses d_model=1024, d_ff=4096, h=16
