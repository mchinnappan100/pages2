Section 1

Transformer Data Flow

End-to-End Forward Pass

Token IDs are mapped to dense vectors by the Embedding table ($\mathbf{E}\in\mathbb{R}^{V\times d}$). Each of the $L$ identical transformer layers applies: Layer Norm (stabilises activations), Multi-Head Attention (mixes information across positions), a residual Add, then Layer Norm again, a position-wise FFN, and another residual Add. A final Layer Norm feeds a shared Linear (the unembedding/lm-head) that projects each position's $d$-dimensional hidden state to vocabulary logits of dimension $V$.

Section 2

Token Embeddings & Positional Encoding

Each token at position $t$ is looked up from an embedding matrix:

$$\mathbf{x}_t = \mathbf{E}[id_t] \in \mathbb{R}^d$$

The input to the first transformer layer is token embedding plus positional encoding. For the classic sinusoidal scheme:

$$\text{PE}(pos,2i)=\sin\!\left(\frac{pos}{10000^{2i/d}}\right), \quad \text{PE}(pos,2i{+}1)=\cos\!\left(\frac{pos}{10000^{2i/d}}\right)$$

The embedding lookup is a simple integer-indexed table read — no computation, just a memory fetch. Sinusoidal PE encodes position using frequencies that span many scales: low-frequency sinusoids capture coarse order while high-frequency ones capture fine-grained offsets. The model can attend to relative positions because $\text{PE}(pos+k)$ can be expressed as a linear function of $\text{PE}(pos)$. 

import torch, math
import torch.nn as nn

class TokenEmbedWithSinPE(nn.Module):
    def __init__(self, vocab_size, d_model, max_len=4096):
        super().__init__()
        self.embed = nn.Embedding(vocab_size, d_model)
        pe = torch.zeros(max_len, d_model)
        pos = torch.arange(max_len).unsqueeze(1).float()
        div = torch.exp(torch.arange(0, d_model, 2).float() * (-math.log(10000.0) / d_model))
        pe[:, 0::2] = torch.sin(pos * div)
        pe[:, 1::2] = torch.cos(pos * div)
        self.register_buffer('pe', pe.unsqueeze(0))   # (1, max_len, d)

    def forward(self, ids):                           # ids: (B, T)
        x = self.embed(ids)                           # (B, T, d)
        return x + self.pe[:, :x.size(1)]            # broadcast add PE

Scaled Dot-Product Attention

$$\mathbf{Q}=\mathbf{X}\mathbf{W}^Q,\; \mathbf{K}=\mathbf{X}\mathbf{W}^K,\; \mathbf{V}=\mathbf{X}\mathbf{W}^V \quad(\mathbf{W}^{Q,K,V}\in\mathbb{R}^{d\times d_k})$$ $$\text{Attention}(\mathbf{Q},\mathbf{K},\mathbf{V})=\text{softmax}\!\left(\frac{\mathbf{Q}\mathbf{K}^\top}{\sqrt{d_k}}\right)\mathbf{V}$$

Attention Scores (T×T) — Example Heatmap

When $\mathbf{q}$ and $\mathbf{k}$ are independent unit-variance vectors of dimension $d_k$, their dot product has variance $d_k$. Dividing by $\sqrt{d_k}$ restores unit variance, keeping softmax inputs in a well-behaved range where gradients do not vanish. For autoregressive (decoder) models, a causal mask adds $-\infty$ to all positions in the upper triangle of the score matrix, forcing each position to attend only to past tokens. 

import torch, math
import torch.nn.functional as F

def scaled_dot_product_attention(Q, K, V, causal=False):
    # Q, K, V: (B, T, d_k)
    d_k = Q.size(-1)
    scores = Q @ K.transpose(-2, -1) / math.sqrt(d_k)   # (B, T, T)
    if causal:
        T = scores.size(-1)
        mask = torch.triu(torch.ones(T, T, device=Q.device), diagonal=1).bool()
        scores = scores.masked_fill(mask, float('-inf'))
    attn = F.softmax(scores, dim=-1)                     # (B, T, T)
    return attn @ V                                      # (B, T, d_k)

# quick test
B, T, d_k = 2, 8, 64
Q = torch.randn(B, T, d_k)
K = torch.randn(B, T, d_k)
V = torch.randn(B, T, d_k)
out = scaled_dot_product_attention(Q, K, V, causal=True)
print(out.shape)   # torch.Size([2, 8, 64])

Multi-Head Attention

$$\text{MHA}(\mathbf{X}) = \text{Concat}(\text{head}_1,\ldots,\text{head}_h)\,\mathbf{W}^O$$ $$\text{where} \quad \text{head}_i = \text{Attention}\!\left(\mathbf{X}\mathbf{W}_i^Q,\;\mathbf{X}\mathbf{W}_i^K,\;\mathbf{X}\mathbf{W}_i^V\right)$$

Each of the $h$ heads uses $d_k = d/h$ dimensions so the total computation is the same as a single head. With $h$ heads the three input projections contribute $3d^2$ parameters ($\mathbf{W}^Q, \mathbf{W}^K, \mathbf{W}^V \in \mathbb{R}^{d\times d}$) and the output projection $\mathbf{W}^O \in \mathbb{R}^{d\times d}$ adds another $d^2$, giving $\mathbf{4d^2}$ parameters per MHA layer. 

import torch, math
import torch.nn as nn, torch.nn.functional as F

class MultiHeadAttention(nn.Module):
    def __init__(self, d_model, n_heads):
        super().__init__()
        assert d_model % n_heads == 0
        self.h, self.d_k = n_heads, d_model // n_heads
        self.W_qkv = nn.Linear(d_model, 3 * d_model, bias=False)
        self.W_o   = nn.Linear(d_model, d_model, bias=False)

    def forward(self, x, causal=False):
        B, T, d = x.shape
        qkv = self.W_qkv(x).chunk(3, dim=-1)            # 3 × (B, T, d)
        Q, K, V = [t.view(B, T, self.h, self.d_k).transpose(1,2) for t in qkv]
        # Q, K, V: (B, h, T, d_k)
        scores = Q @ K.transpose(-2,-1) / math.sqrt(self.d_k)
        if causal:
            mask = torch.triu(torch.ones(T, T, device=x.device), diagonal=1).bool()
            scores = scores.masked_fill(mask, float('-inf'))
        attn = F.softmax(scores, dim=-1)
        out  = (attn @ V).transpose(1,2).contiguous().view(B, T, d)
        return self.W_o(out)
Section 5

Rotary Position Encoding (RoPE)

For each pair of dimensions $(x_{2i}, x_{2i+1})$ at sequence position $m$, apply a 2D rotation:

$$\begin{pmatrix}x_{2i}'\\x_{2i+1}'\end{pmatrix}=\begin{pmatrix}\cos m\theta_i & -\sin m\theta_i\\ \sin m\theta_i & \cos m\theta_i\end{pmatrix}\begin{pmatrix}x_{2i}\\x_{2i+1}\end{pmatrix}, \quad \theta_i=10000^{-2i/d}$$

After rotating both $\mathbf{q}$ and $\mathbf{k}$, their dot product $\mathbf{q}_m^\top \mathbf{k}_n$ depends only on the relative offset $m - n$ — the model learns to use positional information without requiring absolute position embeddings to be added to the input. RoPE is used in LLaMA, Mistral, GPT-NeoX, PaLM 2, and most recent open-weight models. 

import torch

def precompute_rope(seq_len, d_head, base=10000):
    i    = torch.arange(0, d_head, 2).float()
    theta = 1.0 / (base ** (i / d_head))           # (d_head/2,)
    pos  = torch.arange(seq_len).float()
    freqs = torch.outer(pos, theta)                 # (T, d_head/2)
    return torch.polar(torch.ones_like(freqs), freqs)  # complex

def apply_rope(x, freqs_cis):
    # x: (B, T, n_heads, d_head)
    B, T, H, D = x.shape
    xc = torch.view_as_complex(x.float().reshape(B, T, H, D//2, 2))
    xr = xc * freqs_cis[None, :T, None, :]
    return torch.view_as_real(xr).reshape(B, T, H, D).type_as(x)

Layer Normalization

$$\text{LayerNorm}(\mathbf{x})=\gamma\cdot\frac{\mathbf{x}-\mu}{\sqrt{\sigma^2+\epsilon}}+\beta$$

RMSNorm (used in LLaMA, removing the mean-centering step):

$$\text{RMSNorm}(\mathbf{x})=\frac{\mathbf{x}}{\sqrt{\frac{1}{d}\|\mathbf{x}\|^2+\epsilon}}\cdot\gamma$$

Both $\mu$ and $\sigma^2$ are computed over the feature dimension independently for each token position, so the statistics are sequence-length independent. RMSNorm drops the mean-subtraction and the bias $\beta$, halving the normalisation cost while preserving training stability. Learnable parameters $\gamma$ (scale) and $\beta$ (shift) each have $d$ elements. 

import torch, torch.nn as nn

class LayerNormScratch(nn.Module):
    def __init__(self, d, eps=1e-5):
        super().__init__()
        self.gamma, self.beta = nn.Parameter(torch.ones(d)), nn.Parameter(torch.zeros(d))
        self.eps = eps
    def forward(self, x):
        mu = x.mean(-1, keepdim=True)
        var = x.var(-1, unbiased=False, keepdim=True)
        return self.gamma * (x - mu) / (var + self.eps).sqrt() + self.beta

class RMSNorm(nn.Module):
    def __init__(self, d, eps=1e-6):
        super().__init__()
        self.gamma = nn.Parameter(torch.ones(d))
        self.eps = eps
    def forward(self, x):
        rms = x.pow(2).mean(-1, keepdim=True).add(self.eps).sqrt()
        return self.gamma * x / rms
Section 7

Feed-Forward Network

Classic ReLU FFN (dimension $d \to 4d \to d$):

$$\text{FFN}(\mathbf{x})=\max(0,\,\mathbf{x}\mathbf{W}_1+\mathbf{b}_1)\,\mathbf{W}_2+\mathbf{b}_2$$

SwiGLU (LLaMA, PaLM) — gated with $\text{SiLU}(x)=x\cdot\sigma(x)$:

$$\text{SwiGLU}(\mathbf{x})=\bigl(\text{SiLU}(\mathbf{x}\mathbf{W}_1)\odot\mathbf{x}\mathbf{W}_2\bigr)\mathbf{W}_3$$

The FFN is applied independently to every token position and contributes $2 \times 4d^2 = 8d^2$ parameters (two weight matrices, no bias in modern variants). SwiGLU uses three weight matrices but the hidden dimension is typically reduced to $\approx\tfrac{8}{3}d$ to keep the total parameter count comparable to the ReLU FFN. The pointwise gating mechanism significantly improves training dynamics. 

import torch.nn as nn, torch.nn.functional as F

class FFN(nn.Module):
    def __init__(self, d):
        super().__init__()
        self.fc1 = nn.Linear(d, 4*d); self.fc2 = nn.Linear(4*d, d)
    def forward(self, x):
        return self.fc2(F.relu(self.fc1(x)))

class SwiGLUFFN(nn.Module):
    def __init__(self, d, d_ff=None):
        super().__init__()
        d_ff = d_ff or int(d * 8/3)
        self.W1 = nn.Linear(d, d_ff, bias=False)
        self.W2 = nn.Linear(d, d_ff, bias=False)
        self.W3 = nn.Linear(d_ff, d, bias=False)
    def forward(self, x):
        return self.W3(F.silu(self.W1(x)) * self.W2(x))
Section 8

Residual Connections & Pre-Norm

Pre-norm transformer block (modern default):

$$\mathbf{H} = \mathbf{x} + \text{Sublayer}\!\bigl(\text{LayerNorm}(\mathbf{x})\bigr)$$

Gradient through the residual stream:

$$\frac{\partial \mathcal{L}}{\partial \mathbf{x}} = \frac{\partial \mathcal{L}}{\partial \mathbf{H}} \cdot \left(1 + \frac{\partial\,\text{Sublayer}}{\partial\mathbf{x}}\right)$$

The additive skip connection creates a "gradient highway" — the constant $1$ in the chain rule ensures that even if the sublayer has a vanishing Jacobian, loss gradients flow directly from deep layers to shallow layers without attenuation. Pre-norm (normalise input before the sublayer) is more stable than the original post-norm formulation, especially at the large scales typical of modern LLMs. 

import torch.nn as nn

class TransformerBlock(nn.Module):
    def __init__(self, d_model, n_heads, ffn_cls=None):
        super().__init__()
        from typing import Optional
        self.norm1 = nn.LayerNorm(d_model)
        self.norm2 = nn.LayerNorm(d_model)
        self.attn  = MultiHeadAttention(d_model, n_heads)   # from s4
        self.ffn   = SwiGLUFFN(d_model)                     # from s7

    def forward(self, x, causal=True):
        # MHA sub-layer with pre-norm + residual
        x = x + self.attn(self.norm1(x), causal=causal)
        # FFN sub-layer with pre-norm + residual
        x = x + self.ffn(self.norm2(x))
        return x

# Stack L layers
class GPTModel(nn.Module):
    def __init__(self, vocab, d, n_heads, n_layers, max_len=2048):
        super().__init__()
        self.embed   = nn.Embedding(vocab, d)
        self.blocks  = nn.ModuleList([TransformerBlock(d, n_heads) for _ in range(n_layers)])
        self.norm    = nn.LayerNorm(d)
        self.lm_head = nn.Linear(d, vocab, bias=False)
    def forward(self, ids):
        x = self.embed(ids)
        for blk in self.blocks: x = blk(x)
        return self.lm_head(self.norm(x))
Section 9

KV Cache & Grouped-Query Attention

Standard MHA KV cache memory (across all layers, in elements):

$$\text{KV cache size} = 2 \cdot L \cdot T \cdot d$$

GQA with $g$ key/value head groups (vs $h$ query heads, $g \ll h$):

$$\text{GQA KV cache} = 2 \cdot L \cdot T \cdot \frac{d}{h} \cdot g \quad \Longrightarrow \quad \text{reduces by factor } \frac{h}{g}$$

During autoregressive decoding each new token only needs to run the new $\mathbf{Q}$ projection against the cached $\mathbf{K}$ and $\mathbf{V}$ tensors — recomputing past keys/values would waste $O(T)$ work per step. GQA (used in LLaMA 3, Mistral, Gemma) reduces KV cache VRAM by grouping multiple query heads to share a single set of key/value heads, cutting the cache by $h/g$ without significantly degrading quality. 

import torch

class KVCache:
    """Minimal per-layer KV cache for autoregressive decoding."""
    def __init__(self):
        self.cache = {}          # layer_id -> (K_accumulated, V_accumulated)

    def update(self, layer_id, new_k, new_v):
        # new_k, new_v: (B, h, 1, d_k) — single new token
        if layer_id not in self.cache:
            self.cache[layer_id] = (new_k, new_v)
        else:
            k_past, v_past = self.cache[layer_id]
            self.cache[layer_id] = (
                torch.cat([k_past, new_k], dim=2),
                torch.cat([v_past, new_v], dim=2),
            )
        return self.cache[layer_id]   # (B, h, T_so_far, d_k)

Parameter Count & Scaling

$$\text{Total params} \approx 12 L d^2 + V d$$

Per-layer breakdown (dominant terms, bias-free):

Component Parameters Notes
Embedding table $Vd$ often tied with lm_head
MHA (per layer) $4d^2$ $W^Q, W^K, W^V, W^O$
FFN (per layer) $8d^2$ $d{\to}4d{\to}d$, two matrices
LayerNorm (per layer) $4d$ 2 LN × $(\gamma,\beta)$, negligible
Total ($L$ layers) $\approx 12Ld^2 + Vd$ $(4+8)d^2 \times L$ 
def count_params(model):
    total = sum(p.numel() for p in model.parameters())
    trainable = sum(p.numel() for p in model.parameters() if p.requires_grad)
    print(f"Total params   : {total:,}")
    print(f"Trainable      : {trainable:,}")
    return total
