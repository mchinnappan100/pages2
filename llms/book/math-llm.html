Key Equations at a Glance

The central formulas running through every chapter

Scaled Dot-Product Attention

Attention(Q,K,V) = softmax(QKᵀ / √dₖ) · V

The core attention equation — dividing by √dₖ prevents vanishing gradients in softmax

Cross-Entropy Loss

L = − Σ yᵢ log(ŷᵢ)

Derived directly from MLE — maximising log-likelihood is equivalent to minimising cross-entropy

KL Divergence

D_KL(P||Q) = Σ P(x) log(P(x)/Q(x))

Measures how much distribution Q differs from reference P; used in RLHF reward shaping

Adam Update Rule

θₜ = θₜ₋₁ − α · m̂ₜ / (√v̂ₜ + ε)

Bias-corrected first and second moment estimates; effectively adaptive per-parameter learning rates

Chinchilla Scaling Law

N_opt ≈ 0.5 · C / 6 ; D_opt ≈ 0.5 · C / 6

Optimal model and data size grow equally with compute budget C — the Chinchilla result

RoPE Rotation

f(x, m) = x · e^(imθ)

Rotates query/key by position-dependent angle in complex plane; relative positions appear in dot product naturally
