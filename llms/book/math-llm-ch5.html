Section 1

The Training Objective

LLMs are trained with next-token prediction — maximum likelihood estimation (MLE) over a corpus $\mathcal{D}$. Each forward pass predicts the probability of every token given its left context; the negative log-likelihood is minimised. Perplexity (PPL) is the exponentiated average loss and is the canonical evaluation metric: lower is better, and PPL = 1 would mean perfect predictions.

$$\mathcal{L}(\theta)=-\frac{1}{|\mathcal{D}|}\sum_{x\in\mathcal{D}}\sum_{t=1}^T\log P_\theta(x_t|x_{
$$\text{PPL}=\exp(\mathcal{L})$$ 
import torch, torch.nn as nn

model = MyTransformer().cuda()
optimizer = torch.optim.AdamW(model.parameters(), lr=3e-4)
criterion = nn.CrossEntropyLoss()

for batch in dataloader:
    input_ids = batch["input_ids"].cuda()        # (B, T)
    targets   = input_ids[:, 1:].contiguous()    # shift right
    logits    = model(input_ids[:, :-1])         # (B, T-1, V)
    loss = criterion(logits.view(-1, logits.size(-1)), targets.view(-1))
    optimizer.zero_grad()
    loss.backward()
    optimizer.step()
    print(f"loss={loss.item():.4f}  ppl={loss.exp().item():.2f}")
Section 2

Loss Functions & Label Smoothing

Standard cross-entropy targets a hard one-hot distribution, which can cause over-confident predictions and poor calibration. Label smoothing with coefficient $\varepsilon$ mixes the hard target with a uniform distribution, acting as a regulariser that prevents the logits from growing without bound. The uniform entropy term is $H_{\text{uniform}}=-\log(1/V)=\log V$.

$$\mathcal{L}_{CE} = -\sum_c y_c \log \hat{y}_c$$
$$\mathcal{L}_{LS}=(1-\varepsilon)\,\mathcal{L}_{CE}+\varepsilon\, H_{\text{uniform}}$$ 
import torch, torch.nn as nn

# Standard cross-entropy
ce = nn.CrossEntropyLoss()

# Label-smoothed cross-entropy (epsilon=0.1)
ls_ce = nn.CrossEntropyLoss(label_smoothing=0.1)

logits  = torch.randn(4, 32000)   # batch=4, vocab=32000
targets = torch.randint(0, 32000, (4,))

print("CE loss :", ce(logits, targets).item())
print("LS loss :", ls_ce(logits, targets).item())
Section 3

Weight Initialization

Poor initialisation causes vanishing or exploding gradients before training begins. Xavier (Glorot) balances variance across layers for tanh/sigmoid activations; Kaiming (He) is preferred for ReLU. GPT-2 scales residual-branch weights down by the number of residual layers $N_L$ to keep the residual stream variance stable at initialisation.

$$\sigma_{\text{Xavier}}=\sqrt{\frac{2}{n_{in}+n_{out}}}, \qquad \sigma_{\text{He}}=\sqrt{\frac{2}{n_{in}}}$$
$$\text{GPT-2 residual scaling:}\quad W \leftarrow \frac{W}{\sqrt{N_L}}$$ 
import torch.nn as nn

def init_weights(module, n_layers=12):
    if isinstance(module, nn.Linear):
        nn.init.xavier_uniform_(module.weight)
        if module.bias is not None:
            nn.init.zeros_(module.bias)
    if isinstance(module, nn.Embedding):
        nn.init.normal_(module.weight, mean=0.0, std=0.02)

def init_weights_kaiming(module):
    if isinstance(module, nn.Linear):
        nn.init.kaiming_normal_(module.weight, nonlinearity='relu')

def scale_residual(module, n_layers):
    # GPT-2 style: scale down output projections of attn & MLP
    for name, p in module.named_parameters():
        if 'out_proj.weight' in name or 'fc2.weight' in name:
            p.data *= (1.0 / (n_layers ** 0.5))
Section 4

Regularization: Weight Decay & Dropout

Standard L2 regularisation adds $\lambda\mathbf{w}$ to the gradient, but with Adam this is absorbed into the adaptive scaling — making it nearly ineffective. AdamW decouples the weight-decay step from the gradient update, applying it directly to the parameters. Dropout zeroes activations randomly at rate $p$ during training; the $\frac{1}{1-p}$ scale keeps the expected value unchanged.

$$\mathbf{w}_t=\mathbf{w}_{t-1}-\eta\!\left(\frac{\hat{m}_t}{\sqrt{\hat{v}_t}+\epsilon}+\lambda\mathbf{w}_{t-1}\right)$$
$$\tilde{h}_i = h_i \cdot \text{Bernoulli}(1-p) \cdot \frac{1}{1-p}$$ 
import torch.nn as nn, torch.optim as optim

model = MyTransformer()

# Separate weight-decayed vs non-decayed params
decay     = [p for n,p in model.named_parameters() if p.dim() >= 2]
no_decay  = [p for n,p in model.named_parameters() if p.dim() < 2]
optimizer = optim.AdamW([
    {"params": decay,    "weight_decay": 0.1},
    {"params": no_decay, "weight_decay": 0.0},
], lr=3e-4)

dropout = nn.Dropout(p=0.1)   # applied inside transformer blocks
Section 5

Gradient Flow & Clipping

Residual connections preserve gradient magnitude through depth: each layer contributes an additive gradient path, keeping the overall signal $O(1)$ rather than exponentially decaying. Gradient clipping caps the global $\ell_2$ norm at threshold $\tau$, preventing occasional large batches from destabilising the optimiser.

$$\frac{\partial \mathcal{L}}{\partial x_\ell} = \frac{\partial \mathcal{L}}{\partial x_L}\prod_{k=\ell}^{L-1}\left(I + \frac{\partial F_k}{\partial x_k}\right) \approx O(1)$$
$$\mathbf{g} \leftarrow \mathbf{g}\cdot\frac{\tau}{\max\!\left(\tau,\,\|\mathbf{g}\|_2\right)}$$ 
import torch, torch.nn as nn

model     = MyTransformer().cuda()
optimizer = torch.optim.AdamW(model.parameters(), lr=3e-4)

for batch in dataloader:
    input_ids = batch["input_ids"].cuda()
    targets   = input_ids[:, 1:].contiguous()
    logits    = model(input_ids[:, :-1])
    loss = nn.functional.cross_entropy(
               logits.view(-1, logits.size(-1)), targets.view(-1))
    optimizer.zero_grad()
    loss.backward()
    # Clip global gradient norm to 1.0
    grad_norm = torch.nn.utils.clip_grad_norm_(model.parameters(), 1.0)
    optimizer.step()
Section 6

Mixed Precision (BF16 / FP16)

Reducing numerical precision halves memory and doubles throughput on modern tensor cores. FP16 has a limited exponent range and requires loss scaling to prevent underflow in gradients. BF16 shares FP32's 8-bit exponent, giving the same dynamic range — no scaling needed — at the cost of less mantissa precision.

$$\tilde{\mathbf{g}}_{\text{FP16}} = \frac{1}{s}\,\mathbf{g}_{\text{scaled}}, \qquad s \text{ auto-tuned by GradScaler}$$
FormatExp bitsMantissa bitsMax valueNotes
FP32823~3.4×10³⁸Full precision baseline
FP1651065504Needs loss scaling
BF1687~3.4×10³⁸Preferred for LLMs
 
import torch
from torch.cuda.amp import GradScaler, autocast

model     = MyTransformer().cuda()
optimizer = torch.optim.AdamW(model.parameters(), lr=3e-4)
scaler    = GradScaler()   # only needed for FP16

# --- BF16 (recommended, no scaler needed) ---
with torch.autocast('cuda', dtype=torch.bfloat16):
    logits = model(input_ids)
    loss   = criterion(logits.view(-1, V), targets.view(-1))
loss.backward(); optimizer.step(); optimizer.zero_grad()

# --- FP16 with loss scaling ---
with autocast(dtype=torch.float16):
    logits = model(input_ids)
    loss   = criterion(logits.view(-1, V), targets.view(-1))
scaler.scale(loss).backward()
scaler.step(optimizer); scaler.update(); optimizer.zero_grad()
Section 7

Gradient Checkpointing

Standard backpropagation caches all $L$ layer activations: memory $O(L\cdot T\cdot d)$. Gradient checkpointing stores only every $\sqrt{L}$-th activation and recomputes the rest during the backward pass, reducing memory to $O(\sqrt{L}\cdot T\cdot d)$ at the cost of ~33% extra compute.

$$\text{Standard:}\ O(L\cdot T\cdot d) \qquad \text{Checkpointing:}\ O\!\left(\sqrt{L}\cdot T\cdot d\right)$$ 
from torch.utils.checkpoint import checkpoint
import torch.nn as nn

class CheckpointedTransformer(nn.Module):
    def __init__(self, layers):
        super().__init__()
        self.layers = nn.ModuleList(layers)

    def forward(self, x):
        for layer in self.layers:
            # Recompute activations during backward; saves memory
            x = checkpoint(layer, x, use_reentrant=False)
        return x
Section 8

Distributed Training Overview

Data-parallel training replicates the model on $N$ GPUs; each rank processes a micro-batch and gradients are averaged via AllReduce. ZeRO Stage 3 (Zero Redundancy Optimiser) shards parameters, gradients, and optimiser states across all ranks, reducing per-GPU memory from $16\Psi$ bytes to $\approx\frac{16\Psi}{N}$ (mixed precision).

$$\mathbf{g} = \frac{1}{N}\sum_{i=1}^{N}\mathbf{g}_i \quad \text{(AllReduce)}$$
$$\text{ZeRO-3 memory per GPU} \approx \frac{16\Psi}{N}\ \text{bytes}$$

Section 9

LoRA Fine-Tuning

Low-Rank Adaptation (Hu et al. 2021) freezes the pretrained weight $\mathbf{W}_0$ and learns a low-rank update $\Delta\mathbf{W}=\frac{\alpha}{r}\mathbf{B}\mathbf{A}$. For $r=16$, $d=4096$, $k=4096$: trainable params drop from $16.7\text{M}$ to $131\text{K}$ — a 128× reduction. $\mathbf{B}$ is initialised to zero so the adapter contributes nothing at the start of fine-tuning.

$$\mathbf{W}'=\mathbf{W}_0+\frac{\alpha}{r}\mathbf{B}\mathbf{A}, \quad \mathbf{B}\in\mathbb{R}^{d\times r},\ \mathbf{A}\in\mathbb{R}^{r\times k},\ r\ll\min(d,k)$$
$$\text{Trainable params:}\ r(d+k) \ll dk \qquad \mathbf{A}\sim\mathcal{N}(0,\sigma^2),\ \mathbf{B}=\mathbf{0}$$ 
import torch, torch.nn as nn, math

class LoRALinear(nn.Module):
    def __init__(self, in_f, out_f, r=16, alpha=32):
        super().__init__()
        self.weight = nn.Parameter(torch.empty(out_f, in_f), requires_grad=False)
        nn.init.kaiming_uniform_(self.weight, a=math.sqrt(5))
        self.A = nn.Parameter(torch.empty(r, in_f))
        self.B = nn.Parameter(torch.zeros(out_f, r))
        nn.init.kaiming_uniform_(self.A, a=math.sqrt(5))
        self.scale = alpha / r

    def forward(self, x):
        base = nn.functional.linear(x, self.weight)
        lora = nn.functional.linear(nn.functional.linear(x, self.A), self.B)
        return base + self.scale * lora
Section 10

Scaling Laws (Chinchilla)

Hoffmann et al. (2022) fit a parametric loss surface over hundreds of training runs, showing that for a fixed compute budget $C \approx 6ND$ the optimal strategy is to scale model size $N$ and data $D$ equally. The Chinchilla result: use ~20 tokens per parameter. GPT-3 (175B params, 300B tokens) was significantly undertrained; LLaMA-2 (7B, 2T tokens) is overtrained for inference efficiency.

$$\mathcal{L}(N,D)=\frac{A}{N^\alpha}+\frac{B}{D^\beta}+E, \qquad C\approx 6ND$$
$$N^*=\left(\frac{AC\alpha}{6B\beta}\right)^{\!\frac{\beta}{\alpha+\beta}},\quad D^*=\frac{C}{6N^*}, \quad \frac{D^*}{N^*}\approx 20$$ 
def estimate_flops(N, D):
    """
    Chinchilla FLOP estimate for transformer LLM training.
    N: number of non-embedding parameters
    D: number of training tokens
    Returns approximate FLOPs (forward + backward ≈ 6*N*D).
    """
    flops = 6 * N * D
    print(f"Params : {N/1e9:.1f}B")
    print(f"Tokens : {D/1e9:.1f}B")
    print(f"FLOPs  : {flops/1e24:.2f} × 10²⁴  ({flops:.2e})")
    return flops

# Chinchilla-optimal for 1e23 FLOP budget
estimate_flops(N=int(4e9), D=int(80e9))
