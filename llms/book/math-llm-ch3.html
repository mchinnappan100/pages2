Section 1

LLMs as Probability Distributions

A large language model defines a probability distribution over sequences of tokens. Given a vocabulary $V$, the model factorises the joint probability of a sequence $(x_1, \ldots, x_T)$ using the chain rule of probability:

$$P(x_1,\ldots,x_T)=\prod_{t=1}^T P(x_t \mid x_{ At each step $t$, the model outputs a probability distribution over all $|V|$ vocabulary tokens conditioned on the tokens seen so far. Generation is sampling from this distribution autoregressively.

LLM Output Interpretation
logits (shape: vocab_size) Raw unnormalised scores before softmax
softmax(logits) Probability distribution over vocabulary $P(x_t \mid x_{<t})$
argmax(logits) Greedy decoding — most probable next token
sample(softmax(logits)) Stochastic generation — draw from the distribution

Conditional Probability & Bayes

Conditional probability formalises the idea of "probability of $A$ given $B$ has occurred":

$$P(A \mid B) = \frac{P(A \cap B)}{P(B)}$$

Bayes' theorem inverts conditioning — it lets us update beliefs about parameters $\theta$ given observed data $X$:

$$P(\theta \mid X) = \frac{P(X \mid \theta)\,P(\theta)}{P(X)}$$

Here $P(\theta)$ is the prior, $P(X|\theta)$ is the likelihood, and $P(\theta|X)$ is the posterior. LLM pretraining maximises the likelihood; fine-tuning can be viewed as updating a prior with new data. 

import torch

# 2x2 joint count table: rows = A, cols = B
counts = torch.tensor([[30., 20.], [10., 40.]])
joint  = counts / counts.sum()          # joint P(A,B)

p_b    = joint.sum(dim=0)               # marginal P(B)
p_a    = joint.sum(dim=1)               # marginal P(A)

# Conditional P(A|B) for each value of B
p_a_given_b = joint / p_b.unsqueeze(0)  # shape [2,2]

print("P(A|B=0):", p_a_given_b[:, 0].tolist())  # [0.75, 0.25]
print("P(A|B=1):", p_a_given_b[:, 1].tolist())  # [0.33, 0.67]

# Bayes: P(B=1|A=0) via Bayes theorem
likelihood = p_a_given_b[0, 1]         # P(A=0|B=1)
prior      = p_b[1]                     # P(B=1)
evidence   = p_a[0]                     # P(A=0)
posterior  = (likelihood * prior) / evidence
print(f"Posterior P(B=1|A=0) = {posterior:.4f}")
Section 3

Maximum Likelihood Estimation

MLE finds parameters $\hat\theta$ that make the observed data most probable. Summing log-probabilities avoids numerical underflow from multiplying many small values:

$$\hat\theta = \arg\max_\theta \sum_i \log p(x_i;\theta)$$

LLM pretraining is MLE over a massive token corpus — the model maximises $\sum_t \log P(x_t | x_{<t}; \theta)$. Minimising cross-entropy loss is exactly equivalent to maximising the log-likelihood. 

import torch

torch.manual_seed(0)
# Observed data from a Gaussian with true mu=2.0, sigma=0.5
data = torch.randn(1000) * 0.5 + 2.0

# MLE closed-form estimates
mu_mle    = data.mean()
sigma_mle = data.std(unbiased=False)   # MLE uses N not N-1

# Log-likelihood at MLE solution
log_lik = -0.5 * torch.log(2 * torch.tensor(torch.pi)) \
          - torch.log(sigma_mle) \
          - 0.5 * ((data - mu_mle) / sigma_mle) ** 2
print(f"MLE mu={mu_mle:.4f}, sigma={sigma_mle:.4f}")
print(f"Total log-likelihood: {log_lik.sum():.2f}")
Section 4

Shannon Entropy

Entropy measures the average uncertainty (or information content) of a distribution. A uniform distribution has maximum entropy; a distribution concentrated on one outcome has minimum entropy:

$$H(X) = -\sum_i p_i \log_2 p_i \quad \text{(bits)}$$

Using $\log_2$ gives entropy in bits; using the natural log ($\ln$) gives nats. PyTorch and deep-learning frameworks typically work in nats. High entropy at a model's output step means uncertainty; low entropy means the model is confident.

Entropy: Uniform (max) vs Peaked (low)

import torch

def entropy_bits(p: torch.Tensor) -> torch.Tensor:
    """Shannon entropy in bits. p must sum to 1."""
    p = p.clamp(min=1e-9)
    return -(p * torch.log2(p)).sum()

uniform = torch.ones(5) / 5
peaked  = torch.tensor([0.70, 0.15, 0.08, 0.04, 0.03])

print(f"Uniform entropy : {entropy_bits(uniform):.4f} bits")  # 2.3219
print(f"Peaked  entropy : {entropy_bits(peaked):.4f} bits")   # ~0.47
Section 5

Cross-Entropy Loss

Cross-entropy measures how well the predicted distribution $\hat{p}$ matches the true distribution $y$:

$$\mathcal{L}_{CE} = -\sum_i y_i \log \hat{p}_i$$

For language modelling, $y$ is a one-hot token, so the loss reduces to the negative log-probability of the correct token. Averaged over a sequence of $T$ tokens:

$$\mathcal{L} = -\frac{1}{T}\sum_{t=1}^T \log P(x_t \mid x_{<t})$$

Perplexity exponentiates the average loss, giving an interpretable "effective vocabulary size" the model is uncertain over: $\text{PPL} = \exp(\mathcal{L}_{CE})$. Lower is better. 

import torch
import torch.nn as nn

ce_loss = nn.CrossEntropyLoss()

# Batch of 3 tokens, vocab size 5
logits = torch.tensor([[2.0, 0.5, 0.1, -1.0, -0.5],
                        [0.1, 3.0, 0.2,  0.3, -1.0],
                        [0.3, 0.4, 2.5,  0.1,  0.0]])
targets = torch.tensor([0, 1, 2])       # ground-truth token ids

loss = ce_loss(logits, targets)
ppl  = torch.exp(loss)

print(f"Cross-entropy loss : {loss.item():.4f}")
print(f"Perplexity         : {ppl.item():.4f}")
# Good model: loss ~0, PPL ~1. Random 5-way: loss ~1.6, PPL ~5.
Section 6

KL Divergence

KL divergence measures how much distribution $P$ differs from a reference $Q$. It is always non-negative and zero only when $P = Q$:

$$D_{KL}(P \| Q) = \sum_i P(i) \log \frac{P(i)}{Q(i)} \geq 0$$

In RLHF (Reinforcement Learning from Human Feedback), a KL penalty keeps the policy $\pi_\theta$ from drifting too far from the reference model $\pi_\text{ref}$:

$$\mathcal{L}_{RLHF} = r(x, y) - \beta\, D_{KL}(\pi_\theta \| \pi_\text{ref})$$

The coefficient $\beta$ controls the trade-off: large $\beta$ preserves safety properties of the reference model; small $\beta$ allows more reward optimisation but risks reward hacking or degeneration.

KL Divergence — P vs Q (shaded region indicates KL)

import torch
import torch.nn.functional as F

# P = policy distribution, Q = reference distribution (log form needed for F.kl_div)
P = torch.tensor([0.05, 0.10, 0.60, 0.20, 0.05])
Q = torch.tensor([0.10, 0.15, 0.40, 0.25, 0.10])

# F.kl_div expects log(Q) as input, P as target; reduction='sum' gives KL in nats
kl = F.kl_div(Q.log(), P, reduction='sum')
print(f"D_KL(P||Q) = {kl.item():.6f} nats")
# Verify: manual calculation
kl_manual = (P * (P / Q).log()).sum()
print(f"Manual KL  = {kl_manual.item():.6f} nats")
Section 7

Softmax & Temperature

Softmax converts raw logits $\mathbf{z}$ into a valid probability distribution:

$$\text{softmax}(\mathbf{z})_i = \frac{e^{z_i}}{\sum_j e^{z_j}}$$

Direct exponentiation overflows for large logits. The log-sum-exp trick subtracts the maximum first: $\log\sum_j e^{z_j} = m + \log\sum_j e^{z_j - m}$, where $m = \max_j z_j$. Temperature $\tau$ scales the distribution: high $\tau \to$ uniform (creative), low $\tau \to$ peaked (deterministic).

$$\text{softmax}(\mathbf{z}/\tau)_i = \frac{e^{z_i/\tau}}{\sum_j e^{z_j/\tau}}$$ 
import torch

def stable_softmax(z: torch.Tensor, tau: float = 1.0) -> torch.Tensor:
    z = z / tau
    z = z - z.max()           # log-sum-exp stability shift
    exp_z = z.exp()
    return exp_z / exp_z.sum()

logits = torch.tensor([2.0, 1.0, 0.1, -1.0, 3.5])

for tau in [0.5, 1.0, 2.0]:
    probs = stable_softmax(logits, tau)
    print(f"tau={tau:.1f}: {probs.numpy().round(3)}")
# tau=0.5 -> very peaked at index 4
# tau=2.0 -> flatter distribution (more uniform)

# Sample a token using temperature
tau   = 0.8
probs = stable_softmax(logits, tau)
token = torch.multinomial(probs, num_samples=1)
print(f"Sampled token index: {token.item()}")
Section 8

Sampling Strategies

After obtaining a probability distribution from softmax, there are several strategies to pick the next token. Greedy always takes the argmax — deterministic but repetitive. Top-k restricts sampling to the $k$ most probable tokens, zeroing others. Top-p (nucleus) keeps the smallest set of tokens whose cumulative probability exceeds $p$, adapting the candidate set to the shape of each distribution at every step. 

import torch

def top_k_sample(logits: torch.Tensor, k: int) -> int:
    topk_vals, _ = torch.topk(logits, k)
    threshold = topk_vals[-1]
    masked = logits.clone()
    masked[logits < threshold] = float('-inf')
    probs = torch.softmax(masked, dim=-1)
    return torch.multinomial(probs, 1).item()

def top_p_sample(logits: torch.Tensor, p: float) -> int:
    probs = torch.softmax(logits, dim=-1)
    sorted_probs, sorted_idx = torch.sort(probs, descending=True)
    cumulative = torch.cumsum(sorted_probs, dim=0)
    # Remove tokens once cumulative prob exceeds p
    remove = cumulative - sorted_probs > p
    sorted_probs[remove] = 0.0
    sorted_probs /= sorted_probs.sum()
    chosen = torch.multinomial(sorted_probs, 1).item()
    return sorted_idx[chosen].item()

logits = torch.tensor([1.0, 2.5, 0.3, -0.5, 3.2, 1.8, 0.1])
print("Top-k (k=3):", top_k_sample(logits, k=3))
print("Top-p (p=0.9):", top_p_sample(logits, p=0.9))
Section 9

Mutual Information

Mutual information $I(X;Y)$ quantifies how much knowing $Y$ reduces uncertainty about $X$:

$$I(X;Y) = H(X) - H(X \mid Y) = D_{KL}\!\bigl(P(X,Y) \,\|\, P(X)P(Y)\bigr)$$

Attention scores in Transformers can be loosely interpreted through an MI lens: a high attention weight from token $t$ to token $s$ indicates that $s$ carries high mutual information with the prediction at $t$. MI also motivates probing classifiers — if a representation $Z$ has high $I(Z; Y)$ with label $Y$, the representation encodes task-relevant structure. 

import torch

def mutual_information(joint: torch.Tensor) -> torch.Tensor:
    """Compute I(X;Y) from a joint distribution table."""
    joint = joint / joint.sum()             # normalise
    p_x   = joint.sum(dim=1, keepdim=True)  # marginal P(X)
    p_y   = joint.sum(dim=0, keepdim=True)  # marginal P(Y)
    outer = p_x * p_y                       # product of marginals
    # MI = sum P(x,y) log P(x,y) / (P(x)P(y))
    mask  = joint > 0
    mi    = (joint[mask] * (joint[mask] / outer[mask]).log()).sum()
    return mi

joint = torch.tensor([[0.3, 0.05], [0.05, 0.4], [0.1, 0.1]])
print(f"I(X;Y) = {mutual_information(joint).item():.4f} nats")
Section 10

Bayesian View & Uncertainty

The MAP (maximum a posteriori) estimate combines the data likelihood with a prior over parameters. Taking the log turns it into a regularised loss:

$$\hat\theta_{MAP} = \arg\max_\theta \bigl[\log p(X \mid \theta) + \log p(\theta)\bigr]$$

A Gaussian prior $p(\theta) \propto e^{-\|\theta\|^2 / 2\sigma^2}$ is equivalent to L2 weight decay. Full Bayesian inference is intractable for LLMs, but MC Dropout approximates a posterior by running $T$ stochastic forward passes with dropout active at inference time and measuring the variance of predictions across samples. 

import torch
import torch.nn as nn

class BayesianMLP(nn.Module):
    def __init__(self):
        super().__init__()
        self.net = nn.Sequential(
            nn.Linear(10, 64), nn.ReLU(),
            nn.Dropout(0.3),
            nn.Linear(64, 1))
    def forward(self, x): return self.net(x)

model = BayesianMLP()
x     = torch.randn(1, 10)
model.train()                        # keep dropout active at inference

# MC Dropout: T stochastic forward passes
T = 50
preds = torch.stack([model(x) for _ in range(T)])  # shape [T, 1, 1]
mean_pred    = preds.mean(0)
epistemic_unc = preds.var(0)
print(f"Mean prediction : {mean_pred.item():.4f}")
print(f"Uncertainty (var): {epistemic_unc.item():.6f}")
