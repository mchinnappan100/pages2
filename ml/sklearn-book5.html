Multi-Output Prediction

Predicting multiple targets simultaneously · MultiOutputRegressor · chained

🌦️ Real-World — Weather Station Multi-Target Forecast

A meteorology company predicts temperature, humidity, wind speed, and precipitation simultaneously from historical sensor readings. MultiOutputRegressor wraps any single-output estimator to produce multiple predictions, while chained prediction captures inter-target correlations.

python — multi-target weather forecasting
from sklearn.multioutput import MultiOutputRegressor, RegressorChain
from sklearn.ensemble import GradientBoostingRegressor
from sklearn.metrics import mean_absolute_error
import numpy as np

targets = ['temp_max', 'humidity', 'wind_speed', 'precipitation']
X_train, X_test = weather_features_train, weather_features_test
Y_train, Y_test = weather_df_train[targets], weather_df_test[targets]

# Independent prediction (no target correlation)
mor = MultiOutputRegressor(
    GradientBoostingRegressor(n_estimators=200, max_depth=4), n_jobs=-1)
mor.fit(X_train, Y_train)

# Chained: temp_max predicted first, then used as input for humidity, etc.
chain = RegressorChain(
    GradientBoostingRegressor(n_estimators=200, max_depth=4),
    order=[0, 1, 2, 3])  # prediction order
chain.fit(X_train, Y_train)

for name, model in [('Independent', mor), ('Chained', chain)]:
    Y_pred = model.predict(X_test)
    maes = [mean_absolute_error(Y_test.iloc[:,i], Y_pred[:,i])
            for i in range(len(targets))]
    print(f"{name}: {dict(zip(targets, [round(m,2) for m in maes]))}")

Time-Series Forecasting with Sklearn

Lag features · rolling windows · TimeSeriesSplit · walk-forward validation

⚡ Real-World — Electricity Demand Forecasting (Grid Operator)

A national grid operator forecasts 24-hour-ahead electricity demand using lag features (demand at t-1h, t-24h, t-168h), calendar features (hour, weekday, holiday flag), and weather inputs (temperature, humidity). Walk-forward validation mirrors the actual deployment scenario — never training on the future.

python — electricity demand forecasting with lag features
import pandas as pd
import numpy as np
from sklearn.ensemble import HistGradientBoostingRegressor
from sklearn.model_selection import TimeSeriesSplit, cross_val_score

def build_lag_features(df, target_col, lags=[1, 24, 48, 168], windows=[24, 168]):
    out = df.copy()
    for lag in lags:
        out[f'lag_{lag}h'] = out[target_col].shift(lag)
    for w in windows:
        out[f'roll_mean_{w}h'] = out[target_col].shift(1).rolling(w).mean()
        out[f'roll_std_{w}h']  = out[target_col].shift(1).rolling(w).std()
    # Calendar features
    out['hour']      = out.index.hour
    out['dayofweek'] = out.index.dayofweek
    out['month']     = out.index.month
    out['is_weekend'] = (out.index.dayofweek >= 5).astype(int)
    return out.dropna()

df_feat = build_lag_features(df, target_col='demand_mw')
X = df_feat.drop(columns=['demand_mw'])
y = df_feat['demand_mw']

# TimeSeriesSplit: gap prevents data leakage between folds
tscv = TimeSeriesSplit(n_splits=5, gap=24)   # 24h gap = no look-ahead
model = HistGradientBoostingRegressor(max_iter=400, learning_rate=0.03, random_state=42)
scores = cross_val_score(model, X, y, cv=tscv, scoring='neg_mean_absolute_percentage_error')
print(f"Walk-forward MAPE: {-scores.mean()*100:.1f}% ± {scores.std()*100:.1f}%")
⚠️ Never use standard KFold for time series

Standard cross-validation shuffles data, creating temporal leakage — future data trains models evaluated on the past. Always use TimeSeriesSplit with an appropriate gap equal to your forecast horizon.

Custom Transformers & Estimators

BaseEstimator · TransformerMixin · FunctionTransformer · domain encoders

🚗 Real-World — Used Car Pricing: Custom Age Encoder

A used-car marketplace needs domain-specific transformations: vehicle age (log-transformed), mileage per year (computed from registration year + mileage), and brand prestige score (from a lookup table). These are implemented as custom sklearn transformers so they slot into Pipelines seamlessly.

python — domain-specific custom transformer
import numpy as np
import pandas as pd
from sklearn.base import BaseEstimator, TransformerMixin

class VehicleFeatureEngineer(BaseEstimator, TransformerMixin):
    def __init__(self, current_year=2024):
        self.current_year = current_year

    def fit(self, X, y=None):
        return self   # stateless transformer

    def transform(self, X):
        X = X.copy()
        X['age']         = self.current_year - X['registration_year']
        X['log_age']     = np.log1p(X['age'])
        X['mileage_pa']  = X['odometer_km'] / X['age'].clip(1)
        X['log_mileage'] = np.log1p(X['odometer_km'])
        return X.drop(columns=['registration_year'])

class BrandPrestigeEncoder(BaseEstimator, TransformerMixin):
    PRESTIGE = {
        'bmw':5,'mercedes':5,'audi':4,'volkswagen':3,'ford':2,'renault':2}

    def fit(self, X, y=None): return self
    def transform(self, X):
        X = X.copy()
        X['prestige'] = X['brand'].str.lower().map(self.PRESTIGE).fillna(2)
        return X

# Use in a full pipeline — fits and transforms identically in train and serve
from sklearn.pipeline import Pipeline
from sklearn.ensemble import GradientBoostingRegressor

car_pipeline = Pipeline([
    ('fe',      VehicleFeatureEngineer()),
    ('prestige', BrandPrestigeEncoder()),
    ('prep',    preprocessor),
    ('model',   GradientBoostingRegressor(n_estimators=300, learning_rate=0.05)),
])

Advanced Feature Selection

RFE · RFECV · SelectFromModel · Boruta-style · correlation pruning

🧬 Real-World — Clinical Trial Feature Selection (500 → 30 biomarkers)

A pharmaceutical company has 500 candidate biomarkers from blood tests to predict drug response. RFECV with cross-validation automatically selects the minimal set of biomarkers that maximises predictive performance, dramatically reducing testing cost for future patients.

python — RFECV for biomarker selection
from sklearn.feature_selection import RFECV, SelectFromModel
from sklearn.ensemble import RandomForestClassifier
from sklearn.model_selection import StratifiedKFold

# RFECV: recursive elimination with CV to find optimal feature count
rfecv = RFECV(
    estimator=RandomForestClassifier(n_estimators=100, n_jobs=-1),
    step=10,         # remove 10 features per round
    cv=StratifiedKFold(n_splits=5),
    scoring='roc_auc',
    min_features_to_select=10,
    n_jobs=-1,
)
rfecv.fit(X_train, y_train)
print(f"Optimal features: {rfecv.n_features_} (from {X_train.shape[1]})")

selected_biomarkers = X_train.columns[rfecv.support_].tolist()
print(f"Selected: {selected_biomarkers}")

# SelectFromModel: tree-based, fast, single-fit
selector = SelectFromModel(
    RandomForestClassifier(n_estimators=200), threshold='median')
X_reduced = selector.fit_transform(X_train, y_train)

📱 Real-World — SaaS Customer Lifetime Value Prediction

A SaaS company wants to predict not just whether a customer will churn, but when. Instead of binary classification, frame it as: "predict the number of months until cancellation" using quantile regression and survival-inspired features like hazard at each tenure milestone.

from sklearn.ensemble import GradientBoostingRegressor

Multi-Modal Pipelines

Text + tabular · image features + metadata · FeatureUnion

🏠 Real-World — Property Valuation: Text + Structured

An estate agency predicts property prices from both structured data (bedrooms, area, postcode) and free-text property descriptions ("south-facing garden", "recently renovated kitchen"). FeatureUnion combines TF-IDF features from text with numeric features from structured data in one Pipeline.

python — text + tabular FeatureUnion for property valuation
from sklearn.pipeline import Pipeline, FeatureUnion
from sklearn.feature_extraction.text import TfidfVectorizer
from sklearn.preprocessing import StandardScaler
from sklearn.ensemble import GradientBoostingRegressor
from sklearn.base import BaseEstimator, TransformerMixin

class ColumnSelector(BaseEstimator, TransformerMixin):
    def __init__(self, column): self.column = column
    def fit(self, X, y=None): return self
    def transform(self, X): return X[self.column]

class NumericSelector(BaseEstimator, TransformerMixin):
    def __init__(self, columns): self.columns = columns
    def fit(self, X, y=None): return self
    def transform(self, X): return X[self.columns]

numeric_cols = ['bedrooms', 'bathrooms', 'floor_area_m2', 'garden_m2']

property_pipeline = Pipeline([
    ('features', FeatureUnion([
        ('text', Pipeline([
            ('select', ColumnSelector('description')),
            ('tfidf',  TfidfVectorizer(max_features=1000, ngram_range=(1,2),
                                         sublinear_tf=True)),
        ])),
        ('numeric', Pipeline([
            ('select', NumericSelector(numeric_cols)),
            ('scale',  StandardScaler()),
        ])),
    ])),
    ('model', GradientBoostingRegressor(n_estimators=300, learning_rate=0.04)),
])

property_pipeline.fit(df_train, y_train_price)
print(f"R²: {property_pipeline.score(df_test, y_test_price):.3f}")

📌 Key Takeaways from Book 5 (and the Full Series)
  • Multi-output models — use RegressorChain when targets are correlated
  • Time series — always use TimeSeriesSplit with a gap equal to your forecast horizon
  • Custom transformers — implement BaseEstimator + TransformerMixin to integrate cleanly with Pipeline and GridSearch
  • Feature selection — RFECV is the most principled method; use it when interpretability or cost matters
  • FeatureUnion lets you combine any feature modality (text, image features, tabular) in one deployable Pipeline
  • A system that predicts, explains, monitors, and retrains is a complete Predictive AI product — not just a model
