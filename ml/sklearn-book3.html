K-Means Clustering

Centroid-based partitioning · elbow method · customer segmentation

🛍️ Real-World — Retail Customer Segmentation (RFM)

An e-commerce company segments 500k customers using Recency (days since last purchase), Frequency (number of purchases), and Monetary (total spend). K-Means produces 5 segments: Champions, Loyal, At-Risk, Hibernating, and New Customers — enabling targeted marketing campaigns.

python — customer segmentation with K-Means + elbow method
from sklearn.cluster import KMeans
from sklearn.preprocessing import RobustScaler
import pandas as pd
import numpy as np

# RFM features
rfm = df.groupby('customer_id').agg(
    recency  =('order_date', lambda x: (pd.Timestamp.now() - x.max()).days),
    frequency=('order_id',   'count'),
    monetary =('order_value', 'sum'),
)

scaler = RobustScaler()
X_scaled = scaler.fit_transform(rfm)

# Elbow method: find optimal k
inertias = []
for k in range(2, 11):
    km = KMeans(n_clusters=k, n_init=10, random_state=42)
    km.fit(X_scaled)
    inertias.append(km.inertia_)
# plot inertias vs k, pick the elbow

# Fit final model with k=5
km5 = KMeans(n_clusters=5, n_init=20, max_iter=500, random_state=42)
rfm['segment'] = km5.fit_predict(X_scaled)

# Profile each segment
print(rfm.groupby('segment')[
    ['recency','frequency','monetary']].mean().round(1))
📏

Choosing K

There's no single "right" K — use multiple signals.

  • Elbow method — plot inertia vs k, find the kink
  • Silhouette score — measures cluster compactness
  • Domain knowledge — "we want 4 marketing segments"
  • Gap statistic — compare to random reference
⚠️

K-Means Limitations

Understanding where K-Means fails prevents misapplication.

  • Assumes spherical, equal-size clusters
  • Sensitive to outliers → use RobustScaler or clip first
  • Must specify K in advance
  • Non-convex shapes → use DBSCAN instead

DBSCAN & Hierarchical Clustering

Density-based · arbitrary shapes · geospatial clustering

🗺️ Real-World — Urban Hotspot Detection (Ride-Sharing)

A ride-sharing company uses DBSCAN on GPS coordinates of trip pickups to find high-demand hotspots automatically. DBSCAN doesn't require specifying K in advance and naturally handles noise (isolated pickups that don't form clusters), perfect for geographic point data.

python — geospatial hotspot detection with DBSCAN
from sklearn.cluster import DBSCAN
import numpy as np

# GPS coords in radians for haversine metric
coords = df[['lat', 'lng']].values
coords_rad = np.radians(coords)

# eps in radians: 0.5km / Earth radius (6371km)
eps_km = 0.5
eps_rad = eps_km / 6371.0

db = DBSCAN(eps=eps_rad, min_samples=50, algorithm='ball_tree', metric='haversine')
df['cluster'] = db.fit_predict(coords_rad)

n_clusters = len(set(df['cluster'])) - (1 if -1 in df['cluster'].values else 0)
noise    = (df['cluster'] == -1).sum()
print(f"Hotspots found: {n_clusters}, noise points: {noise}")

Gaussian Mixture Models

Soft cluster assignments · BIC for model selection · overlapping clusters

📊 Real-World — User Behaviour Profiling (SaaS)

A SaaS company models user engagement as a GMM — users don't belong to exactly one behaviour profile; they're mixtures (mostly "power user" but occasionally "casual"). Soft assignments enable personalised feature rollout and targeted onboarding flows.

python — GMM with BIC-based model selection
from sklearn.mixture import GaussianMixture
import numpy as np

# Select n_components via BIC (lower=better)
bics = []
for n in range(1, 10):
    gmm = GaussianMixture(n_components=n, covariance_type='full', random_state=42)
    gmm.fit(X_scaled)
    bics.append((n, gmm.bic(X_scaled)))

best_n = min(bics, key=lambda x: x[1])[0]
print(f"Best n_components: {best_n}")

gmm = GaussianMixture(n_components=best_n, covariance_type='full', random_state=42)
gmm.fit(X_scaled)

# Soft probabilities: each user's membership in each profile
probs = gmm.predict_proba(X_scaled)   # shape (n_users, best_n)
labels = gmm.predict(X_scaled)         # hard assignment

Anomaly Detection

Isolation Forest · One-Class SVM · Local Outlier Factor · network intrusion

🔐 Real-World — Network Intrusion Detection

A security team uses Isolation Forest to score every HTTP request in real time. Anomalous requests (SQL injection attempts, unusually large payloads, off-hours access from new IPs) are flagged for analyst review. No labelled attack data is needed — the model learns the distribution of normal traffic.

Real-World: End-to-End Unsupervised Pipeline

Insurance claims — segment + detect anomalies + enrich supervised model

🏦 Scenario — Insurance Claim Processing

An insurer runs three unsupervised steps before any supervised fraud detection: (1) cluster policyholders into risk profiles, (2) reduce claim feature space with PCA, (3) flag statistically anomalous claims with Isolation Forest. The cluster label and anomaly score are then added as features to the supervised fraud model — boosting AUC by 4 points.

python — unsupervised feature enrichment pipeline
from sklearn.pipeline import Pipeline
from sklearn.decomposition import PCA
from sklearn.cluster import KMeans
from sklearn.ensemble import IsolationForest, GradientBoostingClassifier
from sklearn.preprocessing import StandardScaler
import numpy as np

# Unsupervised enrichment (fit on training data only)
scaler = StandardScaler()
X_tr_s = scaler.fit_transform(X_train)
X_te_s = scaler.transform(X_test)

# 1. PCA: keep 95% variance
pca = PCA(n_components=0.95, random_state=42)
X_tr_pca = pca.fit_transform(X_tr_s)
X_te_pca = pca.transform(X_te_s)

# 2. K-Means cluster label as feature
km = KMeans(n_clusters=8, n_init=10, random_state=42)
tr_cluster = km.fit_predict(X_tr_pca).reshape(-1, 1)
te_cluster = km.predict(X_te_pca).reshape(-1, 1)

# 3. Isolation Forest anomaly score as feature
iso = IsolationForest(n_estimators=200, contamination=0.05, random_state=42)
tr_score = iso.fit(X_tr_pca).score_samples(X_tr_pca).reshape(-1, 1)
te_score = iso.score_samples(X_te_pca).reshape(-1, 1)

# 4. Concatenate enriched features
X_tr_rich = np.hstack([X_tr_s, X_tr_pca, tr_cluster, tr_score])
X_te_rich = np.hstack([X_te_s, X_te_pca, te_cluster, te_score])

# 5. Supervised fraud model on enriched features
gbm = GradientBoostingClassifier(n_estimators=300, learning_rate=0.05, random_state=42)
gbm.fit(X_tr_rich, y_train)
print(f"AUC with enrichment: {roc_auc_score(y_test, gbm.predict_proba(X_te_rich)[:,1]):.3f}")
📌 Key Takeaways from Book 3
  • Use RobustScaler before K-Means — outliers heavily distort centroids
  • DBSCAN is best for geographic or density-based data where K is unknown
  • Always run PCA before t-SNE on high-dimensional data to speed up computation
  • Isolation Forest is the fastest anomaly detector for tabular data at scale
  • Unsupervised-derived features (cluster label, anomaly score) consistently improve supervised models
