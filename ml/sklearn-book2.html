Bagging & Random Forests

Bootstrap aggregation · variance reduction · feature importance

🛒 Real-World — E-Commerce Product Return Prediction

An online retailer wants to predict which orders will be returned before shipping to optimise logistics. Features include product category, price, customer return history, and review sentiment. Random Forest handles mixed feature types and provides interpretable feature importances.

🌳

Decision Trees

Base learner for all ensemble methods. Understands non-linear boundaries, handles mixed types.

  • Splits on information gain (Gini / entropy)
  • max_depth controls variance vs bias
  • min_samples_leaf prevents overfitting
  • Interpretable via plot_tree()
🌲

Random Forest

Averages many decorrelated trees — dramatically reduces variance without increasing bias.

  • n_estimators: more = better, diminishing returns after ~200
  • max_features: sqrt(p) for classifiers, p/3 for regression
  • bootstrap=True (default) — each tree on 63% of data
  • oob_score=True — free validation estimate
📊

Feature Importance

Random Forest gives reliable feature importances — invaluable for business understanding.

  • Mean Decrease in Impurity (MDI) — built in
  • Permutation importance — more reliable for correlated features
  • Partial Dependence Plots — marginal effect of a feature
  • Drives feature selection and business insight
python — product return prediction with random forest
from sklearn.ensemble import RandomForestClassifier
from sklearn.inspection import permutation_importance
import pandas as pd

rf = RandomForestClassifier(
    n_estimators=500,
    max_depth=None,
    max_features='sqrt',
    min_samples_leaf=5,
    oob_score=True,
    n_jobs=-1,
    random_state=42,
)
rf.fit(X_train, y_train)
print(f"OOB score: {rf.oob_score_:.3f}")   # free CV estimate

# Permutation importance (more reliable than MDI)
result = permutation_importance(rf, X_test, y_test, n_repeats=10, random_state=42)
imp_df = pd.DataFrame({
    'feature': feature_names,
    'importance': result.importances_mean,
}).sort_values('importance', ascending=False)
print(imp_df.head(10))

💰 Real-World — Real-Time Credit Scoring

A fintech lender scores loan applications in under 50ms. HistGradientBoostingClassifier handles missing income data natively (no imputation step needed), trains in minutes on 2M rows, and produces well-calibrated risk scores. Model is retrained weekly on new repayment data.

python — credit scoring with HistGradientBoosting
from sklearn.ensemble import HistGradientBoostingClassifier
from sklearn.calibration import CalibratedClassifierCV
from sklearn.metrics import roc_auc_score, brier_score_loss

# Native missing value support — no imputer needed
hgb = HistGradientBoostingClassifier(
    max_iter=400,
    learning_rate=0.05,
    max_leaf_nodes=31,
    l2_regularization=0.1,
    early_stopping=True,
    validation_fraction=0.1,
    random_state=42,
)

# Isotonic calibration for well-calibrated probabilities
calibrated = CalibratedClassifierCV(hgb, method='isotonic', cv=5)
calibrated.fit(X_train, y_train)

probs = calibrated.predict_proba(X_test)[:, 1]
print(f"AUC:         {roc_auc_score(y_test, probs):.3f}")
print(f"Brier score: {brier_score_loss(y_test, probs):.4f}")  # lower=better calibration
python — early stopping to prevent overfitting
from sklearn.ensemble import GradientBoostingClassifier
import numpy as np

gbm = GradientBoostingClassifier(
    n_estimators=1000,
    learning_rate=0.02,
    max_depth=4,
    subsample=0.8,
    random_state=42,
    n_iter_no_change=20,   # stop if no improvement for 20 rounds
    tol=1e-4,
    validation_fraction=0.1,
)
gbm.fit(X_train, y_train)
print(f"Actual trees used: {gbm.n_estimators_}")  # often much less than 1000

Stacking & Voting Ensembles

Blending diverse models · meta-learners · VotingClassifier

🏥 Real-World — ICU Readmission Risk Score

A hospital combines three diverse models — logistic regression (interpretable), random forest (non-linear), and gradient boosting (high-accuracy) — into a stacking ensemble. The meta-learner (logistic regression) learns how to weight each model's predictions, achieving better calibration than any single model.

python — stacking ensemble for ICU readmission
from sklearn.ensemble import StackingClassifier, RandomForestClassifier, GradientBoostingClassifier
from sklearn.linear_model import LogisticRegression
from sklearn.svm import SVC
from sklearn.metrics import roc_auc_score

base_estimators = [
    ('lr',  LogisticRegression(C=1.0, max_iter=500)),
    ('rf',  RandomForestClassifier(n_estimators=200, n_jobs=-1)),
    ('gbm', GradientBoostingClassifier(n_estimators=200, learning_rate=0.05)),
    ('svc', SVC(probability=True, kernel='rbf', C=2.0)),
]

stacker = StackingClassifier(
    estimators=base_estimators,
    final_estimator=LogisticRegression(C=0.5),   # meta-learner
    cv=5,                                         # cross-val for out-of-fold preds
    stack_method='predict_proba',
    n_jobs=-1,
)
stacker.fit(X_train, y_train)
auc = roc_auc_score(y_test, stacker.predict_proba(X_test)[:, 1])
print(f"Stacking AUC: {auc:.3f}")  # typically beats any single model
python — soft voting for sentiment analysis
from sklearn.ensemble import VotingClassifier
from sklearn.naive_bayes import MultinomialNB
from sklearn.linear_model import LogisticRegression, SGDClassifier

# Soft voting: average probabilities from each classifier
voter = VotingClassifier(
    estimators=[
        ('nb',  MultinomialNB(alpha=0.5)),
        ('lr',  LogisticRegression(C=5.0, max_iter=500)),
        ('sgd', SGDClassifier(loss='modified_huber')),
    ],
    voting='soft',
    weights=[1, 2, 2],   # higher weight to stronger models
)
voter.fit(X_train, y_train)
print(f"Voting accuracy: {voter.score(X_test, y_test):.3f}")

Support Vector Machines

Kernel trick · margin maximisation · SVR · multi-class

🌾 Real-World — Crop Disease Classification from Leaf Images

An agricultural startup classifies crop diseases from extracted leaf features (colour histograms, texture descriptors). SVM with RBF kernel achieves high accuracy on this small-to-medium dataset where the classes are well-separated in feature space.

python — SVM for multi-class crop disease classification
from sklearn.svm import SVC
from sklearn.preprocessing import StandardScaler
from sklearn.pipeline import Pipeline
from sklearn.model_selection import GridSearchCV

svm_pipe = Pipeline([
    ('scale', StandardScaler()),         # SVM is NOT scale-invariant
    ('svm',   SVC(probability=True, kernel='rbf')),
])

param_grid = {
    'svm__C':     [0.1, 1, 10, 100],
    'svm__gamma': ['scale', 'auto', 0.001, 0.01],
}

grid = GridSearchCV(svm_pipe, param_grid, cv=5, scoring='f1_macro', n_jobs=-1)
grid.fit(X_train, y_train)
print(f"Best macro-F1: {grid.best_score_:.3f}")
print(f"Best params: {grid.best_params_}")

Probability Calibration

Why raw scores aren't probabilities · Platt scaling · isotonic regression

⚠️ When Calibration Matters

If a model outputs "0.9" for a loan application, business users expect 90% of those applicants to repay. Uncalibrated models (especially Random Forests and SVMs) can output 0.9 when the true probability is only 0.65. Always calibrate when the score magnitude matters downstream.

python — calibration curve comparison
from sklearn.calibration import CalibratedClassifierCV, calibration_curve
from sklearn.ensemble import RandomForestClassifier
import matplotlib.pyplot as plt

rf_raw = RandomForestClassifier(n_estimators=200, random_state=42)
rf_platt = CalibratedClassifierCV(
    RandomForestClassifier(n_estimators=200, random_state=42),
    method='sigmoid', cv=5)   # Platt scaling
rf_isotonic = CalibratedClassifierCV(
    RandomForestClassifier(n_estimators=200, random_state=42),
    method='isotonic', cv=5)   # isotonic: better with enough data

for name, clf in [('raw',rf_raw),('platt',rf_platt),('isotonic',rf_isotonic)]:
    clf.fit(X_train, y_train)
    prob_pos = clf.predict_proba(X_test)[:, 1]
    frac, mean_pred = calibration_curve(y_test, prob_pos, n_bins=10)
    plt.plot(mean_pred, frac, label=name)

plt.plot([0,1],[0,1], 'k--', label='perfect')
plt.legend(); plt.xlabel('Mean predicted probability'); plt.show()

Real-World: Predictive Maintenance

Manufacturing sensor data · multi-class failure prediction · cost-sensitive learning

🏭 Scenario — CNC Machine Failure Prediction

A factory operates 200 CNC machines. Sensors record vibration, temperature, spindle speed, and torque every second. The goal: predict which machines will fail in the next 24 hours so maintenance can be scheduled — preventing $50k/hr downtime. Classes are highly imbalanced (99% normal, 1% failure).

python — predictive maintenance ensemble
import pandas as pd
import numpy as np
from sklearn.ensemble import HistGradientBoostingClassifier, StackingClassifier
from sklearn.linear_model import LogisticRegression
from sklearn.metrics import classification_report, confusion_matrix

# Rolling statistics over 1-minute windows
for col in ['vibration', 'temperature', 'torque']:
    df[f'{col}_mean60'] = df[col].rolling(60).mean()
    df[f'{col}_std60']  = df[col].rolling(60).std()
    df[f'{col}_max60']  = df[col].rolling(60).max()

# Cost-sensitive: false negatives (missed failures) cost 100x false positives
sample_weights = np.where(y_train == 1, 100, 1)

hgb = HistGradientBoostingClassifier(
    max_iter=500, learning_rate=0.03, early_stopping=True, random_state=42)
hgb.fit(X_train, y_train, sample_weight=sample_weights)

# Tune threshold: prioritise recall for the failure class
probs = hgb.predict_proba(X_test)[:, 1]
threshold = 0.3   # lower threshold → catch more failures, more false alarms
y_pred = (probs >= threshold).astype(int)
print(classification_report(y_test, y_pred, target_names=['normal', 'failure']))
📌 Key Takeaways from Book 2
  • HistGradientBoosting is the go-to for large tabular data — fast and handles missing values natively
  • Stacking often outperforms any single model when base learners are diverse
  • Always calibrate probabilities when the score magnitude drives business decisions
  • Cost-sensitive learning (sample weights) is more principled than post-hoc threshold tuning
  • Permutation importance is more reliable than MDI for correlated features
