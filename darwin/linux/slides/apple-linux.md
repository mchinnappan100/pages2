## One Beautiful Machine. Two Powerful Worlds.

I love Apple laptops, iPhones and Mac mini computers.
I also love Linux — its philosophy, its engineering, its community and the freedom it gives developers.

Today, using virtual machines to run Linux on a Mac is useful, but it is not the same as running Linux directly on the hardware.

> Why should customers who love Apple's hardware have to compromise on their operating system preferences?

Apple's hardware engineering is exceptional. Linux's flexibility and openness are exceptional. Bringing these worlds together would create an exciting new category of computing.

## Apple Does Not Need to Change macOS

The proposal is not to replace macOS or abandon Apple's ecosystem. It is to officially support another operating system on the same hardware.

**Apple Silicon → Boot Support → Linux**

Darwin is the open-source foundation of macOS, but macOS also includes substantial proprietary components. Apple could continue developing macOS independently while enabling supported Linux distributions to run natively.

**A possible Apple Linux support program:**

1. Publish official hardware documentation and developer specifications where practical
2. Provide stable Linux drivers — GPU, Wi-Fi, Bluetooth, audio, storage, power management
3. Offer documented boot and installation support for selected Linux distributions
4. Collaborate with upstream Linux kernel developers and the Asahi Linux community
5. Establish a Linux-certified Mac product configuration with regular compatibility testing
6. Let customers dual-boot macOS and Linux, or choose Linux as their primary OS

## Engineering Challenges — All Solvable

There are real engineering concerns. Each one has a practical answer.

| Challenge | Answer |
|---|---|
| **Driver Maintenance** | Work with upstream maintainers and define supported hardware configurations to reduce long-term cost |
| **Security** | Secure Boot, firmware signing and customer-controlled boot policies can coexist with a carefully designed Linux support model |
| **Support Costs** | Begin with a limited set of certified devices and distributions rather than supporting every Linux variant |

Apple has solved harder problems. This is an engineering challenge worthy of Apple's talent.
