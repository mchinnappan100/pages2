01 — The vision

One beautiful machine.
Two powerful worlds.

I love Apple laptops, iPhones and Mac mini computers. I also love Linux — its philosophy, its engineering, its community and the freedom it gives developers.

Today, I use virtual machines to run Linux on my Mac. Virtualization is useful, but it is not the same as running Linux directly on the hardware.

Why should customers who love Apple's hardware have to compromise on their operating system preferences?

Apple's hardware engineering is exceptional. Linux's flexibility and openness are exceptional. Bringing these worlds together would create an exciting new category of computing.

Apple's transition to its own Apple Silicon architecture created a new opportunity — and a new challenge — for Linux enthusiasts.

💻

Apple Silicon

🐧

The community is doing the pioneering work. Imagine what could happen if Apple joined them.

06 — A practical path

Apple does not need to change macOS.

The proposal is not to replace macOS or abandon Apple's ecosystem. It is to officially support another operating system on the same hardware.

Apple Silicon Hardware platform
→
Boot Support Firmware and drivers
→
Linux Native operating system

Darwin is the open-source foundation of macOS, but macOS also includes substantial proprietary components. Apple could continue developing macOS independently while enabling supported Linux distributions to run natively.

A possible Apple Linux support program

  1. Publish official hardware documentation and developer specifications where practical.
  2. Provide stable Linux drivers for Apple Silicon hardware, including GPU, Wi-Fi, Bluetooth, audio, storage and power management.
  3. Offer documented boot and installation support for selected Linux distributions.
  4. Collaborate with upstream Linux kernel developers and the Asahi Linux community.
  5. Establish a Linux-certified Mac product configuration with regular compatibility testing.
  6. Let customers dual-boot macOS and Linux, or choose Linux as their primary operating system.
07 — Addressing the concerns

There are engineering challenges.
They are solvable.

Driver Maintenance

Apple could work with upstream maintainers and define supported hardware configurations to reduce long-term maintenance costs.

Security

Secure Boot, firmware signing, hardware security and customer-controlled boot policies can coexist with a carefully designed Linux support model.

Support Costs

Apple could begin with a limited set of certified devices and distributions rather than promising support for every Linux variant.
