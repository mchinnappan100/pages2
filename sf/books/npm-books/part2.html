Salesforce Data & Migration

End-to-end data migration and management tooling — from bulk operations and load plan orchestration to metadata comparison, ERD generation, and realistic test data creation.

Reading time: ~40 min
Packages: 15
Key theme: Data migration lifecycle

Data migration is one of the most risk-laden phases of any Salesforce implementation. A single misconfigured load order can cascade into thousands of broken relationship lookups; an unvalidated query in a load plan can silently migrate the wrong records. The packages in Part 2 address the full data migration lifecycle — from planning and extraction through transformation, loading, and validation — with a consistent emphasis on visual tooling that makes complex operations transparent and auditable.

The toolkit spans both the Salesforce Bulk API 2.0 for high-volume operations and purpose-built planning tools that understand Salesforce's object relationship model. The addition of SQLite export, ERD generation, and data dictionary tools means this part also serves architects who need to document and analyze data models as part of implementation work.

The Packages

mc-sf-meta-compare

1427 downloads/mo Most Popular

npx mc-sf-meta-compare

mc-sf-meta-compare is the standout tool of this ecosystem with 1,427 downloads per month — the highest of any package in this entire collection. It compares Salesforce metadata between orgs or git repos using Monaco diff, semantic comparison, file-level detailed diff, cron scheduling, and email and Slack notifications. It is a comprehensive metadata governance platform in a single CLI tool.

The semantic comparison engine goes beyond raw text diff to understand Salesforce metadata structure — detecting added fields, changed field types, reordered picklist values, and modified validation rule logic in a meaningful way. Cron scheduling enables daily or weekly automated comparison reports that land in your inbox or Slack channel, making environment drift an observable metric rather than a surprise during deployment.

Productivity Gain

Schedule npx mc-sf-meta-compare --source prod --target staging --notify slack as a nightly cron. When a developer accidentally promotes a change to staging that wasn't in the approved backlog, the team receives a Slack notification the next morning — catching drift before it reaches the next release cycle. Saves hours of pre-release environment synchronization reviews.

smt-studio

119 downloads/mo

npx smt-studio

smt-studio is the Salesforce Data Migration Studio — a comprehensive tool to simplify Salesforce data migration tasks through a unified web UI. It provides a guided workflow for planning, executing, and monitoring data migrations, combining multiple migration concerns (extraction, transformation, loading, validation) into a single integrated studio experience.

The studio approach means migration engineers don't need to juggle multiple separate tools and configuration files. The visual interface tracks migration progress across objects, highlights errors with contextual information, and maintains a migration log that serves as both an audit trail and a debugging tool.

Productivity Gain

During a complex org-to-org migration involving 20+ related objects, npx smt-studio provides a single dashboard that tracks which objects have been migrated, which have errors, and what the dependency loading order is. Replaces a manually maintained migration spreadsheet and eliminates the confusion of running multiple separate Bulk API jobs simultaneously.

sfbatch

60 downloads/mo

npx sfbatch

sfbatch is a Salesforce Bulk API 2.0 CLI with a Web UI supporting Insert, Update, Upsert, and Delete operations. It wraps the Salesforce Bulk API 2.0 in a developer-friendly interface that handles job creation, CSV chunking, status polling, and error reporting automatically. The Web UI lets you monitor job progress in real time with progress bars and per-batch status indicators.

The Bulk API 2.0 is the right tool for any data operation exceeding 200 records, but its raw API is complex to work with. sfbatch abstracts that complexity, letting developers focus on the data rather than API mechanics. Error records are extracted with clear descriptions, making it straightforward to identify and fix records that failed to load.

Productivity Gain

Loading 500,000 Account records with a raw Bulk API implementation requires managing job IDs, polling for completion, and parsing results manually — 4+ hours of custom scripting. With npx sfbatch, the same operation is a single command with a live progress UI. Error records are automatically saved to a separate CSV for review. Total setup time: 10 minutes.

sf-bulk-delete

64 downloads/mo

npx sf-bulk-delete

sf-bulk-delete is a Salesforce Bulk Delete Tool with a Web UI. Bulk deletion is one of the riskier data operations in Salesforce — deleting the wrong records can cause data loss that is difficult or impossible to reverse. This tool provides a safety-conscious interface with confirmation steps, SOQL query preview, record count display, and detailed result logging before executing bulk deletes.

The Web UI shows you exactly what records will be deleted (based on your SOQL query) before you commit the operation, reducing the chance of catastrophic mistakes. Post-deletion reports include record IDs, making it possible to restore data from backup if needed.

Productivity Gain

Cleaning up 200,000 test Contact records from a sandbox after a data load test traditionally requires careful scripting with extensive safeguards. With npx sf-bulk-delete, the SOQL preview step confirms you're deleting the right records before execution. The built-in safety workflow replaces 2 hours of custom scripting with a 5-minute interactive session.

sf-bulk-upsert

32 downloads/mo

npx sf-bulk-upsert

sf-bulk-upsert is a Salesforce Bulk Upsert Tool with a Web UI. Upsert — the combination of insert and update based on an external ID match — is the workhorse operation of ongoing data synchronization between Salesforce and external systems. This tool manages the Bulk API 2.0 upsert lifecycle with a clear Web UI that tracks matched vs. inserted vs. failed records.

The distinction between "records matched and updated" versus "records inserted as new" is reported separately, making it easy to validate that the upsert behaved as expected. This transparency is critical for data integrity during system integrations.

Productivity Gain

During a nightly sync of 50,000 customer records from an ERP system, npx sf-bulk-upsert processes the batch and generates a summary showing 45,000 updated, 4,800 inserted, and 200 failed — with the 200 failed records exported for investigation. Data quality issues are caught and remediated in the next cycle rather than silently accumulating.

sf-bulk-upsert-uuid

34 downloads/mo

npx sf-bulk-upsert-uuid

sf-bulk-upsert-uuid is a Salesforce Bulk Upsert tool with auto-generated UUID CLI and beautiful HTML Reports. It extends standard bulk upsert with automatic UUID generation for external ID fields — a critical capability when migrating records from source systems that lack a suitable natural key. The tool generates UUIDs per record, injects them into the CSV, and performs the upsert with full HTML reporting of results.

The automatic UUID strategy ensures that each migrated record gets a stable, globally unique external ID that can be used for future re-migrations or system integrations. The HTML reports provide a human-readable audit trail of the migration operation.

Productivity Gain

Migrating legacy records from a system without natural keys typically requires a custom pre-processing step to generate and assign UUIDs before loading. npx sf-bulk-upsert-uuid handles this automatically in the same operation, cutting pre-migration data preparation time by 1–2 hours per object.

sf-load-sequencer-ui

63 downloads/mo

npx sf-load-sequencer-ui

sf-load-sequencer-ui is the Salesforce Data Loading Sequencer — a visual tool for managing the complex loading order requirements of Salesforce data migrations. When migrating data with parent-child relationships, records must be loaded in the correct order: parent objects before child objects, lookup targets before lookup sources. This tool visualizes the dependency graph and orchestrates the loading sequence.

The sequencer UI shows the loading order as a visual pipeline, highlights which loads are complete, in progress, or pending, and prevents out-of-order execution that would result in lookup failures. For migrations with 20+ related objects, this orchestration is essential.

Productivity Gain

On a migration involving Account, Contact, Opportunity, OpportunityLineItem, and 15 other related objects, manually managing the load sequence across multiple CSV files takes a full day. npx sf-load-sequencer-ui visualizes and enforces the correct order, reducing orchestration overhead from a day to under an hour.

sf-load-plan-generator

59 downloads/mo

npx sf-load-plan-generator

sf-load-plan-generator generates load plans and exports data from Salesforce objects. A load plan is a structured JSON definition of which objects to load, in what order, using which SOQL queries and external ID fields. Generating this plan manually requires deep knowledge of the org's data model. This tool analyzes the org's object relationships and proposes an optimal load plan automatically.

The generated load plan can be customized and then used with other tools in this ecosystem — including sf-load-sequencer-ui and sf-data-extractor — creating a complete, end-to-end migration pipeline driven by a single configuration file.

Productivity Gain

Rather than spending 3 days manually analyzing object relationships and writing a load plan JSON from scratch, npx sf-load-plan-generator produces an 80%-complete draft in minutes. The team reviews and refines the generated plan, cutting load plan development from days to hours for complex data models.

sf-data-util

42 downloads/mo

npx sf-data-util

sf-data-util is a Salesforce data comparison tool that compares orgs using a load-plan.json or any SOQL query. It connects to two orgs and performs record-level comparisons, identifying records present in one org but missing in another, records with differing field values, and summary statistics about data distribution. This is invaluable for validating migrations and keeping orgs in sync.

The comparison output is presented as an HTML report with filters and search, making it easy for migration engineers to drill into specific discrepancies. Using a load plan as the comparison specification means the same configuration that drives the migration also drives validation — maintaining consistency across the migration lifecycle.

Productivity Gain

After migrating 300,000 accounts to a new org, npx sf-data-util --plan load-plan.json --source legacy --target new generates a reconciliation report showing exact match counts per object and flagging discrepancies. Replaces a manual, error-prone record counting exercise with an automated, documented validation step.

sf-data-extractor

36 downloads/mo

npx sf-data-extractor

sf-data-extractor extracts Salesforce data based on a load plan and generates beautiful HTML reports. It is the extraction phase counterpart to the loading tools — given a load plan JSON, it executes all the specified SOQL queries and extracts the results to structured CSV files, maintaining the correct file naming and structure expected by the loading tools.

The HTML reports provide a summary of what was extracted: record counts per object, extraction timestamps, and any SOQL errors encountered. This documentation is valuable for migration audit trails and for debugging data quality issues before loading begins.

Productivity Gain

Extracting data for 25 objects from a legacy org, with consistent naming conventions and extraction logging, takes half a day manually. npx sf-data-extractor --plan load-plan.json handles all 25 objects in a single command and produces a timestamped extraction report. Reduces extraction setup time by 80%.

load-plan-query-validator

24 downloads/mo

npx load-plan-query-validator

load-plan-query-validator validates load plan queries against a predefined schema. Before running a large extraction or migration, this validator checks every SOQL query in the load plan for structural correctness, missing field references, and schema compliance. Catching errors at this stage prevents costly failed migrations that waste hours waiting for a bulk job to fail halfway through.

The validator provides clear, actionable error messages pointing to the exact query and field that failed validation. This makes load plan development faster by catching configuration mistakes in seconds rather than waiting for runtime failures.

Productivity Gain

Running npx load-plan-query-validator --plan load-plan.json as a pre-migration check catches a typo in a SOQL query (a non-existent field name) that would have caused the entire extraction run to fail after 2 hours. Validation takes 30 seconds and saves hours of failed job investigation.

salesforce-to-sqlite

17 downloads/mo

npx salesforce-to-sqlite

salesforce-to-sqlite is a CLI tool to extract Salesforce data and load it into SQLite. SQLite is the universal format for local data analysis — every major data tool from Python pandas to DBeaver can read a SQLite file. This tool creates a local SQLite database with Salesforce data, enabling powerful offline analysis, reporting, and data exploration without repeated API calls.

For architects and analysts who need to perform complex multi-table joins and aggregations on Salesforce data that Salesforce's own SOQL cannot express (due to join limitations), a local SQLite copy is transformative. Complex analytical queries that would require multiple API calls become single SQL statements.

Productivity Gain

An analyst needing to join Account, Contact, Opportunity, and OpportunityLineItem data with 5-way JOINs and complex aggregations would hit SOQL relationship limits repeatedly. npx salesforce-to-sqlite loads all four objects into SQLite in minutes, enabling unconstrained SQL analysis with zero API governor concerns.

datagen-cli

80 downloads/mo

npx datagen-cli

datagen-cli generates realistic fake data from a simple JSON/JSON5 spec. Before loading real production data into sandboxes, developers often need large volumes of realistic test data that respects field types, relationship constraints, and data patterns. datagen-cli generates this data from a concise specification rather than requiring complex custom scripts.

The JSON5 spec format supports field type hints, cardinality for relationships, value patterns (email addresses, phone numbers, picklist values), and realistic name/address generation. The output is CSV files ready for use with the bulk loading tools in this part.

Productivity Gain

Instead of writing a custom Python script to generate 10,000 realistic Account records with valid email addresses, phone numbers, and industry picklist values, define a 20-line JSON5 spec and run npx datagen-cli --spec account-spec.json5 --count 10000. Generates migration-ready CSV in seconds instead of hours of custom scripting.

sf-datadictionary

29 downloads/mo

npx sf-datadictionary

sf-datadictionary is a Salesforce Org Data Dictionary Generator — a Node.js CLI with a Web UI that produces comprehensive, navigable documentation of an org's data model. It documents every object, every field (with type, length, required flag, and picklist values), and every relationship in a browsable HTML format that serves as the authoritative data reference for the implementation team.

Data dictionaries are required deliverables on virtually every enterprise Salesforce project but are tedious to produce manually. sf-datadictionary generates them automatically from the live org, ensuring accuracy and eliminating the documentation lag that afflicts manually maintained references.

Productivity Gain

Generating a data dictionary for 150 custom objects with an average of 50 fields each would require weeks of manual documentation. npx sf-datadictionary generates the complete, searchable HTML dictionary in under an hour — accurate, professional, and ready to share with the client immediately.

salesforce-erd-generator

20 downloads/mo

npx salesforce-erd-generator

salesforce-erd-generator generates interactive Entity Relationship Diagrams and comprehensive metadata documentation for Salesforce objects. It creates visual ERDs showing object relationships, field cardinality, and lookup/master-detail relationship types — rendered as interactive HTML that can be zoomed, panned, and filtered.

Visual ERDs are essential for communicating data model complexity to business stakeholders and for onboarding new developers to an unfamiliar org. The interactive format means stakeholders can explore the diagram themselves rather than waiting for an architect to explain each relationship.

Productivity Gain

For a client kickoff meeting, npx salesforce-erd-generator --objects Account,Contact,Opportunity,Case generates a polished interactive ERD of the core CRM objects in minutes. Presenting this interactive diagram takes the conversation from "what fields exist" to strategic data model discussions immediately, saving an entire requirements discovery session.
