Security, Governance & Org Health

Comprehensive security auditing, permission management, org health assessment, JWT/DKIM configuration, code quality analysis, and user lifecycle tooling for Salesforce orgs.

Reading time: ~55 min
Packages: 23
Key theme: Security & governance

Security and governance are non-negotiable concerns in enterprise Salesforce deployments. Yet the tools provided natively by Salesforce for auditing permissions, reviewing sharing models, and assessing org health are scattered across Setup menus and require significant manual effort to consolidate into a coherent security posture assessment. The packages in Part 3 solve this by bringing automated, visual, and reportable tooling to every layer of Salesforce security.

From permission set management and profile analysis to JWT/DKIM configuration wizards, PMD code analysis, and org health KPI dashboards, this is the most comprehensive part of the toolkit. Security architects, release managers, and compliance teams will find these tools indispensable for audit preparation, access reviews, and continuous governance.

The Packages

salesforce-org-health

29 downloads/mo

npx salesforce-org-health

salesforce-org-health is a Salesforce Org Health Assessment Tool that generates HTML reports with KPIs, charts, and risk analysis. It performs a comprehensive health check of your org across key dimensions: API usage, limits consumption, active users, code coverage, recent deployments, and technical debt indicators. The output is a polished HTML dashboard suitable for executive briefings and governance reviews.

Risk analysis flags areas that require attention — such as high governor limit consumption, low code coverage percentages, or a large number of inactive users with system permissions — with color-coded severity indicators that help prioritize remediation work.

Productivity Gain

For a quarterly governance review, npx salesforce-org-health generates a complete org health report in minutes that previously took an admin 2 days to compile manually from multiple Setup reports. The KPI charts and risk flags give stakeholders an immediate understanding of org status without requiring Salesforce expertise.

sf-org-dashboard

18 downloads/mo

npx sf-org-dashboard

sf-org-dashboard is a Unified Salesforce Org Dashboard combining health metrics, KPIs, and visualization in a single interface. It provides a real-time view of the org's operational status — active users, API call volumes, storage consumption, and deployment history — updated on demand. The unified view prevents the need to navigate multiple Setup pages to get a complete picture.

Development teams use the org dashboard as a persistent monitoring interface during development sprints, quickly identifying when API limits are approaching or when storage is becoming constrained before these issues impact development velocity.

Productivity Gain

During a UAT phase, a release manager keeps npx sf-org-dashboard running as a tab to monitor the org's health in real time. When API limits approach 80% during a data load test, the team can pause and reschedule rather than discovering the limit breach when integrations start failing.

sf-kpi-dashboard

12 downloads/mo

npx sf-kpi-dashboard

sf-kpi-dashboard is a Salesforce KPI Dashboard Generator focused on custom metric visualization. Where sf-org-dashboard covers operational metrics, sf-kpi-dashboard focuses on business and implementation KPIs — configuration completeness, test coverage trends, technical debt accumulation, and deployment frequency. It generates charts and trend lines from historical data.

This tool is valuable for implementation project tracking, enabling project managers to demonstrate progress against technical benchmarks and for architecture teams to track technical health metrics over time.

Productivity Gain

At project milestones, npx sf-kpi-dashboard generates a visual KPI report showing code coverage trends, deployment cadence, and configuration completeness percentages. What previously required manual data collection across multiple tools becomes a 2-minute automated report generation.

sf-limits-viewer

19 downloads/mo

npx sf-limits-viewer

sf-limits-viewer is a beautiful Salesforce Org Limits Viewer with dark theme UI. It queries the Salesforce Limits API and presents all limit consumption values — API calls, Bulk API batches, email sends, file storage, data storage, and dozens of others — in a sortable, filterable dashboard with color-coded consumption indicators.

Limits management is a constant concern in high-volume Salesforce implementations. Having a single visual interface for all limits makes it trivial to spot approaching ceilings before they become blocking issues. The tool is particularly valuable before and during go-live periods when limit consumption spikes.

Productivity Gain

Before a Black Friday campaign that will drive heavy Salesforce API usage, npx sf-limits-viewer gives a clear picture of current limit headroom. Identifies that email send limits are at 70% capacity — prompting the team to optimize batch sizes before the campaign rather than discovering limit exhaustion during it.

sf-sharing-cli

38 downloads/mo

npx sf-sharing-cli

sf-sharing-cli is a CLI tool to read and write Salesforce object sharing models with beautiful HTML reports. Salesforce's sharing architecture — org-wide defaults, role hierarchy, sharing rules, and manual shares — is complex and often opaque. This tool reads the complete sharing configuration for any object and presents it in a structured, readable HTML report that maps the full access path from OWD through to individual record sharing.

The write capability enables automated sharing configuration changes that would otherwise require manual Setup navigation. This is invaluable for implementing sharing models as code, enabling reproducible governance across environments.

Productivity Gain

During a security audit, reviewing the complete sharing model for 15 key objects would require navigating multiple Setup pages per object — 3+ hours of manual work. npx sf-sharing-cli --objects Account,Contact,Opportunity generates a comprehensive sharing model HTML report in 5 minutes that auditors can review independently.

sf-permset-viewer

38 downloads/mo

npx sf-permset-viewer

sf-permset-viewer views Salesforce Permission Set and Permission Set Group details in a beautiful HTML interface. Permission sets are the modern Salesforce access control mechanism, but navigating their contents through the Setup UI is slow and doesn't support comparison or documentation. This tool generates comprehensive HTML reports of permission set contents — object permissions, field permissions, Apex access, system permissions, and connected app access.

For access reviews and security audits, the HTML output is searchable and can be shared with compliance reviewers who don't have direct Salesforce org access. The report serves as a point-in-time evidence artifact for audit purposes.

Productivity Gain

For an SOC 2 access review, generating reports for 30 permission sets via Setup UI would take an admin 6+ hours. npx sf-permset-viewer generates all 30 reports in minutes, creating the audit evidence package automatically. Saves a full day of prep work for each quarterly access review.

sf-permset-viz

10 downloads/mo

npx sf-permset-viz

sf-permset-viz visualizes Salesforce Permission Set details in a beautiful HTML interface with emphasis on visual representation. Where sf-permset-viewer is table-focused, sf-permset-viz uses charts and visual groupings to make permission set structures immediately comprehensible. This is particularly useful for presenting permission set designs to stakeholders who are more visual in their understanding.

Productivity Gain

In a stakeholder review of a new role-based permission set design, npx sf-permset-viz generates visual permission maps that non-technical business owners can understand and approve — replacing a lengthy verbal walkthrough of tabular data with a self-explanatory visual in minutes.

sf-owd-viewer

21 downloads/mo

npx sf-owd-viewer

sf-owd-viewer views Salesforce Organization-Wide Defaults (OWD) for all objects. OWD settings are the foundation of Salesforce's sharing model, and having an incorrect OWD can expose data to unauthorized users or unnecessarily restrict legitimate access. This tool fetches OWD settings for all objects and displays them in a clean, filterable table that highlights any settings that deviate from security best practices.

The viewer makes it easy to identify objects that are "Public Read/Write" when they should be more restrictive, and to document the current OWD configuration for compliance and security review purposes.

Productivity Gain

A security architect reviewing an org's sharing model can run npx sf-owd-viewer and immediately see a color-coded list of all 200+ standard and custom objects with their OWD settings — identifying the 3 objects that are incorrectly set to "Public Read/Write" in 2 minutes rather than scrolling through the Setup sharing settings page.

sf-pe-helper

21 downloads/mo

npx sf-pe-helper

sf-pe-helper is a Platform Encryption Helper — a Salesforce PE implementation assistant with a web interface. Salesforce Shield Platform Encryption has complex setup requirements including key management, field enablement, and compatibility checks. This tool guides teams through the implementation process, checking prerequisites, suggesting field encryption configurations, and validating that the chosen encryption scheme won't break existing Apex and integrations.

For compliance-driven encryption initiatives, sf-pe-helper significantly reduces implementation risk by surfacing compatibility issues before encryption is applied to live data, where problems become much harder to remediate.

Productivity Gain

Implementing Platform Encryption for HIPAA compliance on 50 sensitive fields typically involves 3–5 days of planning and compatibility analysis. npx sf-pe-helper automates the compatibility check matrix and generates a prioritized implementation plan, compressing the planning phase to half a day.

sf-jwt-tool

33 downloads/mo

npx sf-jwt-tool

sf-jwt-tool is a Salesforce OAuth2 JWT Setup Wizard — CLI + Web UI. JWT-based OAuth2 authentication is the standard for server-to-server Salesforce integration, but its setup involves certificate generation, Connected App configuration, and JWT assertion signing that is notoriously tricky to get right the first time. This wizard guides users through every step with clear instructions and immediate validation feedback.

The tool generates the correct key pair, prepares the Connected App settings, and tests the JWT flow end-to-end — confirming the configuration works before it's needed in production integration code.

Productivity Gain

Setting up JWT auth for a new integration that requires unattended server-to-server Salesforce access typically takes 2–3 hours of documentation reading and trial-and-error. npx sf-jwt-tool walks through the entire process with guided steps and immediate test validation, completing the setup correctly in 20–30 minutes.

sf-jwt-tool-mc

39 downloads/mo

npx sf-jwt-tool-mc

sf-jwt-tool-mc is an enhanced version of the JWT Setup Wizard with additional features and a refined Web UI. It includes certificate management, multi-org JWT configuration, and integration with common CI/CD platforms for automated authentication setup. The expanded feature set serves teams managing multiple Salesforce org connections with JWT authentication.

Productivity Gain

When setting up JWT authentication for a CI/CD pipeline that needs to authenticate to three different Salesforce orgs (dev, staging, production), npx sf-jwt-tool-mc handles all three configurations in a single session and generates the environment variable snippets needed for the pipeline configuration. Reduces multi-org JWT setup from a full day to under an hour.

sf-dkim-tool

18 downloads/mo

npx sf-dkim-tool

sf-dkim-tool is a Salesforce DKIM Setup Wizard — CLI + Web UI. DKIM (DomainKeys Identified Mail) is required for email deliverability from Salesforce — without proper DKIM configuration, Salesforce-sent emails risk being marked as spam. This wizard guides teams through generating DKIM keys, configuring them in Salesforce, and publishing the DNS records required by receiving mail servers.

Email deliverability is frequently overlooked during Salesforce implementations until users start complaining about emails not arriving. sf-dkim-tool makes proactive DKIM setup a simple, guided process.

Productivity Gain

Running npx sf-dkim-tool at the beginning of an implementation catches that DKIM is not configured for the org's email domain — before it causes deliverability issues post-go-live. The wizard generates the correct DNS TXT records to share with the DNS team, completing a task that typically requires multiple rounds of documentation research in 15 minutes.

sf-profile-viewer

14 downloads/mo

npx sf-profile-viewer

sf-profile-viewer is a command-line tool to visualize and analyze Salesforce Profiles with interactive HTML reports. Profiles remain a core access control mechanism for many Salesforce orgs despite the modern shift toward permission sets. Profile XML files are among the largest and most complex metadata files, making them difficult to review manually. This tool renders profile contents as navigable HTML with sections for each permission category.

The interactive report allows security reviewers to quickly navigate to specific sections — like which Apex classes a profile has access to, or which fields are hidden — without scrolling through thousands of lines of XML.

Productivity Gain

Reviewing a System Administrator profile change that added unexpected field permissions for sensitive data would be nearly impossible in raw XML. npx sf-profile-viewer renders the profile as an HTML report, making the unauthorized field access visible immediately during a code review. Catches security issues that would slip through XML-only reviews.

pmd-annotations

637 downloads/mo Top 3

npx pmd-annotations

pmd-annotations analyzes @SuppressWarnings PMD annotations in Salesforce Apex class files with a visual dashboard. With 637 downloads per month, this is the third most popular package in the ecosystem. PMD suppressions are sometimes used legitimately to bypass false positives, but they are frequently overused to hide genuine code quality issues. This tool makes the PMD suppression landscape visible and auditable.

The dashboard shows which classes have suppressions, how many, which PMD rules are being suppressed, and whether suppressions appear to be hiding real issues. For teams implementing quality gates in CI/CD pipelines, this tool provides the oversight needed to ensure suppressions are documented and justified.

Productivity Gain

During a code quality initiative, running npx pmd-annotations reveals that 23 Apex classes have PMD suppressions, of which 15 are suppressing security-related rules without documented justification. This finding drives a targeted code review that uncovers 3 actual security vulnerabilities — something that would have taken weeks to find without the visualization.

sf-code-scanner

45 downloads/mo

npx sf-code-scanner

sf-code-scanner is a Salesforce Code Scanner CLI for Apex and LWC best practices. It runs a comprehensive set of static analysis rules against your Apex classes and Lightning Web Components, checking for security vulnerabilities (SOQL injection, unescaped user input), performance anti-patterns (queries in loops, large data set processing without pagination), and coding standard violations.

The scanner generates an HTML report with findings grouped by severity and category, making it easy to prioritize remediation. Integration into CI/CD pipelines as a quality gate prevents new violations from reaching the codebase.

Productivity Gain

Running npx sf-code-scanner before a release identifies 8 SOQL-in-loop violations and 2 potential SOQL injection vulnerabilities in new code. Fixing these before deployment prevents both performance degradation under load and potential security exploits — issues that would have taken incident response time to address post-production.

dangling-fields

16 downloads/mo

npx dangling-fields

dangling-fields identifies and reports dangling field permissions in Salesforce profiles and permission sets. A "dangling field permission" is a field permission that references a field that no longer exists in the org — caused by deleting a custom field without cleaning up the related permissions. These dangling permissions are harmless in terms of access control but indicate governance debt and can cause unexpected behavior during metadata deployments.

Cleaning dangling permissions before a migration or major release prevents cryptic deployment failures where Salesforce rejects permission set metadata referencing non-existent fields.

Productivity Gain

Before a production deployment, npx dangling-fields reveals 150 dangling field permissions across 12 permission sets from 6 months of field cleanup work. Resolving them before deployment prevents the deployment from failing with obscure metadata errors — saving an emergency debugging session that would take 2–3 hours to diagnose.

permset-merger

15 downloads/mo

npx permset-merger

permset-merger is a Salesforce Permission Set Merger — an SF CLI powered web UI. When consolidating multiple permission sets into fewer, more comprehensive ones (a common governance initiative to reduce permission set sprawl), this tool compares permission sets, identifies overlaps, and generates a merged permission set that combines all unique permissions from the source sets.

The visual comparison interface makes it easy to see which permissions exist in which sets and decide how the merged configuration should look — a process that is extremely tedious when working with raw XML files.

Productivity Gain

Merging 5 legacy permission sets into 2 role-based permission sets for a governance cleanup initiative would take 2 days of manual XML comparison and merging. npx permset-merger visualizes all permissions side by side and generates the merged output in a 2-hour interactive session.

sf-persona-mapper

14 downloads/mo

npx sf-persona-mapper

sf-persona-mapper is a Salesforce Persona to Permission Set Group Mapper — a CLI tool with web UI. Modern Salesforce security design maps user personas (roles defined by business function) to permission set groups that aggregate all permissions needed for that role. This tool creates and manages these persona-to-permission-set-group mappings, ensuring consistent access configuration across an org.

The persona mapper documents the intended access design — "Sales Manager persona requires permission set groups A, B, and C" — making it auditable and reproducible. This documentation is invaluable during user onboarding, access reviews, and compliance audits.

Productivity Gain

Onboarding 50 new sales users with 4 different personas becomes a documented, repeatable process with npx sf-persona-mapper. The persona-to-permission mapping defines exactly what each new user receives based on their role, eliminating ad-hoc permission set assignment and ensuring consistent, auditable access from day one.

sf-external-id-manager

18 downloads/mo

npx sf-external-id-manager

sf-external-id-manager is a Salesforce External ID field manager with beautiful reporting. External ID fields are critical for data integrations — they link Salesforce records to identifiers in external systems. Managing which fields are designated as external IDs, ensuring they are properly indexed, and auditing their usage across integrations is an important governance concern. This tool provides a visual dashboard of all external ID fields across all objects.

Productivity Gain

Before a major integration project, npx sf-external-id-manager reveals that the Customer ID field needed for the ERP integration isn't designated as an external ID — catching a configuration gap that would have caused the entire integration to fail on first test. Discovery takes 2 minutes; fixing would have taken 2 days to diagnose from an integration failure.

sf-user-manager

33 downloads/mo

npx sf-user-manager

sf-user-manager is a Salesforce User Management CLI with Web UI. It provides a comprehensive interface for managing Salesforce users — creating users, updating profiles and permission sets, resetting passwords, managing login IP ranges, and generating user audit reports. The web UI makes bulk user operations accessible without requiring API knowledge.

For administrators managing large user populations, the bulk operation capabilities save significant time. The audit reporting generates user access snapshots suitable for compliance documentation, showing each user's profile, permission sets, and last login date.

Productivity Gain

Quarterly user access reviews requiring a full export of all users with their profiles, permission sets, and last login dates would take an admin 3 hours of manual report building. npx sf-user-manager --report access-review generates the complete audit report in 5 minutes.

sf-user-inactivator

14 downloads/mo

npx sf-user-inactivator

sf-user-inactivator is a Salesforce User Inactivation Tool with Web UI. When employees leave an organization, their Salesforce accounts must be deactivated promptly to prevent unauthorized access. This tool provides a bulk inactivation interface that accepts a list of users (by email or username), validates they can be safely inactivated (checking for ownership of records, scheduled jobs, and approval processes), and performs the inactivation with a comprehensive audit log.

Productivity Gain

During a quarterly HR-IT reconciliation that identifies 25 terminated employees still active in Salesforce, npx sf-user-inactivator validates and processes all 25 deactivations with ownership transfer suggestions in 15 minutes — versus manually processing each user through Setup, which would take 2+ hours and is prone to errors.

test-class-runner

26 downloads/mo

npx test-class-runner

test-class-runner is a Salesforce Apex Test Class Runner — a CLI + web UI to run and monitor Apex tests. It provides a modern interface for executing Apex test suites, monitoring test progress in real time, and presenting results with filtering, search, and drill-down into individual test method results. The web UI makes test execution accessible during development without requiring the Developer Console.

For CI/CD integration, the CLI mode provides scriptable test execution with structured JSON output that can be consumed by pipeline reporting tools. Combined with the web UI for interactive sessions, it covers both automated and manual testing workflows.

Productivity Gain

After a major refactoring, a developer needs to run all 450 Apex tests and quickly identify which 12 are failing and why. npx test-class-runner presents the results in a filterable dashboard that shows failing tests by class, with error messages and stack traces immediately visible. Cuts failure diagnosis time from 30 minutes of log scrolling to 5 minutes of visual review.

apex-test-class-failure-helper

0 downloads/mo New

npx apex-test-class-failure-helper

apex-test-class-failure-helper is an Apex Test Class Failure Helper — an AI-powered tool that analyzes and suggests fixes for Salesforce test failures. When Apex tests fail, the error messages are often cryptic and require deep context to understand. This tool uses an LLM to analyze the failing test, the error stack trace, and the relevant production code to suggest specific, actionable fixes.

This is especially valuable for developers who are new to a codebase, where understanding the context behind a failing test can take hours. The AI assistant compresses that investigation into minutes by surfacing the most likely root cause and suggesting code changes.

Productivity Gain

A newly joined developer encounters 8 failing test classes after a rebase. Instead of spending half a day tracing through unfamiliar code, npx apex-test-class-failure-helper analyzes each failure and suggests specific fixes — most of which are test data setup issues. The developer is unblocked in 30 minutes instead of 4 hours.
