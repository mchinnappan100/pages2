Developer Productivity & General Tools

A broad toolkit for every software professional — API clients, learning IDEs, Git tools, database studios, diff utilities, presentation builders, macOS utilities, and AI-powered analysis tools that multiply productivity across any technology stack.

Reading time: ~55 min
Packages: 37
Key theme: Cross-stack developer productivity

Not every productivity challenge a Salesforce developer faces is Salesforce-specific. API testing, database exploration, data visualization, Git conflict resolution, documentation, and presentation — these are universal developer needs that consume hours every week. The packages in Part 5 address this broader surface area: tools that make a developer faster regardless of the technology they are working with.

Many of these tools are direct complements to the Salesforce-specific tools in Parts 1–4. mc-postman-viewer makes API documentation shareable. mc-pg-studio supports developers who work with PostgreSQL as a backend alongside Salesforce. git-merge-forge resolves the merge conflicts that arise in every Salesforce DevOps pipeline. Together, these 37 packages form a complete workstation for a modern Salesforce developer-architect.

The Packages

mc-postman-viewer

673 downloads/mo

npx mc-postman-viewer

mc-postman-viewer is a CLI to visualize Postman collections in a browser — with Monaco editor, interactive canvas, full API docs, dark/light themes, and one-click PDF export. Postman collections are the de facto standard for documenting REST APIs, but sharing them requires the Postman app or a paid Postman account. This tool renders any Postman collection as a beautiful, self-contained HTML page that anyone can open in a browser — no Postman install required.

For Salesforce integration developers who maintain Postman collections documenting their org's API surface, mc-postman-viewer creates shareable documentation that non-developers (business analysts, QA teams, integration partners) can read without tooling setup. The PDF export makes it suitable for formal handover packages and compliance documentation.

Productivity Gain

Handing over a Salesforce integration to a client team normally requires walking them through Postman, setting up environments, and explaining collection structure. With npx mc-postman-viewer, the entire collection is exported as a professional HTML document with rendered examples, request details, and a navigable sidebar — eliminating a 2-hour onboarding session per handover.

git-merge-forge

53 downloads/mo

npx git-merge-forge

git-merge-forge is a browser-based Git merge conflict resolution tool with a multi-repo dashboard, three-pane Monaco editor, pre-merge conflict prediction, and AI assistant. Merge conflicts in Salesforce metadata XML — particularly in Permission Set, Profile, and Custom Label files — are notoriously painful to resolve in a standard text editor due to the dense, verbose XML structure.

The three-pane Monaco editor displays BASE, OURS, and THEIRS simultaneously with syntax highlighting, making it clear exactly what changed on each side. The AI assistant explains what each conflicting change does and recommends the correct resolution — transforming a frustrating, error-prone task into a guided, confident process. The pre-merge conflict prediction flags potential conflicts before a merge is attempted, enabling proactive resolution rather than reactive firefighting.

Productivity Gain

Two developers working in parallel modify the same Salesforce Profile metadata file. The resulting XML conflict has 400 lines of interleaved changes. In a text editor, resolving this takes 45 minutes and risks introducing subtle permission errors. npx git-merge-forge renders the three-pane view with AI-guided resolution in 10 minutes, with zero risk of inadvertently removing permission assignments.

mc-json-diff-cli

36 downloads/mo

npx mc-json-diff-cli

mc-json-diff-cli is a CLI tool to compare JSON files using Monaco Editor with jq query support. Salesforce API responses, metadata files, and configuration exports are frequently JSON. Comparing two versions of a complex JSON structure — such as a Connected App configuration, a metadata deployment response, or a REST API payload — is difficult in a plain text diff tool. The Monaco-powered side-by-side view renders JSON with syntax highlighting and semantic diff highlighting.

The integrated jq query support allows users to filter the JSON before diffing — essential for comparing only the fields that matter in a large, nested JSON response rather than wading through irrelevant changes.

Productivity Gain

A developer comparing two versions of a Salesforce metadata package manifest (JSON format) with 200 components uses npx mc-json-diff-cli with a jq filter to show only the components that changed — reducing a 400-line raw diff to 12 meaningful changes in seconds.

xml-diff-cli

12 downloads/mo

npx xml-diff-cli

xml-diff-cli is a powerful CLI tool to compare XML files. Salesforce metadata is XML — Profiles, Permission Sets, Flows, Custom Objects, and hundreds of other metadata types are stored as XML files. Standard text diff tools show XML differences but don't understand XML structure, leading to false positives from formatting differences and hard-to-read output. xml-diff-cli performs semantic XML comparison that ignores formatting changes and highlights only structural differences.

Productivity Gain

Before promoting a Profile change from sandbox to production, npx xml-diff-cli old-profile.xml new-profile.xml shows only the permission changes — not the hundreds of lines of XML formatting differences that a regular diff tool would include — confirming that exactly the intended permissions were modified and nothing else changed.
