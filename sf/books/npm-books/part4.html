Salesforce Specialized & Revenue Cloud

Deep-dive tooling for specialized Salesforce domains — Revenue Cloud product catalog management, Flow visualization, schema building, event monitoring, Apex exploration, LWC generation, and AI-powered documentation.

Reading time: ~45 min
Packages: 19
Key theme: Specialized Salesforce domains

As Salesforce's platform has expanded into CPQ, Revenue Cloud, and complex automation through Flows, the tooling needs of Salesforce developers have grown increasingly specialized. The packages in Part 4 address these specialized needs: from Revenue Cloud product catalog management to Flow visualization, from real-time event monitoring to AI-powered LWC and Apex code generation.

This part is particularly relevant for teams working on Revenue Cloud / Advanced Revenue implementations, complex automation-heavy orgs with many Flows and processes, and development teams seeking to accelerate component generation and documentation through AI assistance. The tools in this section fill gaps that are not addressed by Salesforce's native tooling or the SF CLI.

The Packages

sf-cml-deploy

71 downloads/mo

npx sf-cml-deploy

sf-cml-deploy is a CML Fetch and Deploy Tool — CLI + Web UI for Salesforce Revenue Cloud. Revenue Cloud's Configure, Price, Quote (CPQ) and Advanced Revenue capabilities introduce a new metadata layer — CML (Catalog Metadata Language) — that requires specialized tooling to fetch, inspect, and deploy. This tool provides a visual interface for working with Revenue Cloud catalog metadata that the standard SF CLI does not cover.

For Revenue Cloud implementation teams, sf-cml-deploy is essential — it bridges the gap between Revenue Cloud's proprietary metadata model and the standard Salesforce deployment pipeline, enabling CML artifacts to be versioned, reviewed, and deployed with the same rigor applied to standard Salesforce metadata.

Productivity Gain

Promoting a Revenue Cloud product catalog change from sandbox to production requires fetching the CML artifacts, reviewing changes, and deploying — a process that previously required extensive manual API calls and documentation reading. npx sf-cml-deploy provides a guided UI for the entire process, reducing Revenue Cloud deployment time from hours to 20 minutes.

pcm-erd-viewer

35 downloads/mo

npx pcm-erd-viewer

pcm-erd-viewer is a Salesforce Revenue Cloud Advanced — Product Catalog ERD Dependency Viewer. Revenue Cloud's product catalog has a complex hierarchical structure with Products, Price Books, Price Entries, Product Attributes, and Product Categories forming an intricate web of dependencies. This tool visualizes these dependencies as an interactive ERD, making the catalog structure comprehensible to implementation teams and business stakeholders.

Understanding the full dependency chain of a complex product configuration is critical before making catalog changes that could unexpectedly break pricing or quoting flows. The visual ERD makes this analysis intuitive rather than requiring deep Product Catalog API knowledge.

Productivity Gain

Before deprecating a Product Attribute used by 12 products across 4 product categories, npx pcm-erd-viewer visually shows the full dependency chain — preventing an attribute deletion that would have broken quoting for a significant portion of the product catalog.

product-category-viewer

7 downloads/mo

npx product-category-viewer

product-category-viewer visualizes Salesforce ProductCategory hierarchies with an interactive tree view. Product categories in Revenue Cloud can form deep, multi-level hierarchies that are difficult to navigate through the standard Salesforce UI. This tool renders the complete category hierarchy as a collapsible, searchable tree, making it easy to understand the catalog structure and navigate to specific categories.

Productivity Gain

For a Revenue Cloud implementation with 500+ product categories organized in a 6-level hierarchy, npx product-category-viewer provides a navigable tree view that replaces endless Salesforce page navigation. Business users can self-service their category questions instead of relying on the implementation team for catalog exploration.

sf-event-monitor

27 downloads/mo

npx sf-event-monitor

sf-event-monitor is a real-time event monitoring CLI for Salesforce orgs. It subscribes to Salesforce's Event Monitoring log files and Streaming API events, presenting them in a live dashboard that updates as events occur. This is invaluable for debugging integration issues, performance investigations, and security monitoring that requires real-time visibility into org activity.

For development teams debugging complex integration scenarios, sf-event-monitor provides the real-time correlation between API calls, database operations, and platform events that is impossible to get from periodic log file downloads. It transforms reactive post-incident analysis into proactive real-time observation.

Productivity Gain

During load testing of a new integration, npx sf-event-monitor shows in real time that API calls are triggering excessive SOQL queries due to a missing cache layer — identifying the performance bottleneck in minutes during the test, rather than requiring post-test log analysis that would take hours.

sf-log-viewer

34 downloads/mo

npx sf-log-viewer

sf-log-viewer is a CLI web app for viewing Salesforce Apex debug logs and Nebula Logger logs in a rich browser UI. Apex debug logs are dense, difficult-to-parse text files that contain crucial debugging information buried in thousands of lines. This tool parses log files into structured, filterable views that make it fast to find the specific log lines that matter.

Nebula Logger support is a significant differentiator — teams using this popular open-source logging framework get dedicated parsing that renders structured log entries as interactive tables rather than raw JSON strings embedded in debug logs. This transforms hours of manual log parsing into minutes of targeted analysis.

Productivity Gain

Debugging a production issue from a 15MB Apex debug log that contains 50,000+ lines normally requires grep and manual inspection. npx sf-log-viewer parses the log, filters to SOQL statements and DML operations, and highlights limit usage — reducing investigation time from 2 hours to 15 minutes.

sf-reports-dashboards-explorer

17 downloads/mo

npx sf-reports-dashboards-explorer

sf-reports-dashboards-explorer is a Salesforce Report and Dashboard Explorer CLI. It provides a browsable interface for discovering and inventorying all reports and dashboards in an org — organized by folder, type, and last run date. For large orgs with hundreds of reports, this tool enables rapid audit of the reporting landscape without navigating Salesforce's report folder structure.

The explorer identifies stale reports that haven't been run in months, reports with invalid filters or deleted objects, and orphaned dashboards — enabling a targeted cleanup that reduces org clutter and improves performance.

Productivity Gain

An org with 800 reports and 200 dashboards developed over 5 years needs cleanup before a license review. npx sf-reports-dashboards-explorer identifies 340 reports never run in the past year and 45 dashboards with no active subscribers — providing a data-driven cleanup list that saves hours of manual investigation.

sf-connected-apps

11 downloads/mo

npx sf-connected-apps

sf-connected-apps is a Node.js CLI tool that fetches and visualizes Salesforce Connected Apps along with associated OAuth Tokens. Connected Apps are the entry points for all external system integrations. Having a comprehensive view of which connected apps exist, which OAuth flows they use, which users have active OAuth tokens, and when tokens were last used is critical for security and integration governance.

Productivity Gain

During a security audit, npx sf-connected-apps reveals a connected app from a decommissioned integration that still has 300 active OAuth tokens — representing an unrevoked access risk. Discovery takes 2 minutes; manually finding this through Setup would take hours across multiple configuration pages.

sf-schema-builder

51 downloads/mo

npx sf-schema-builder

sf-schema-builder is a Web UI for creating and managing Salesforce custom objects, fields, and schemas via the SOAP Metadata API and REST API. It provides a visual form-based interface for schema design that generates and deploys the correct Salesforce metadata — eliminating the need to hand-write object and field XML. The tool supports all field types including complex picklist, formula, and relationship field configurations.

For rapid prototyping of new data models, sf-schema-builder dramatically accelerates the cycle from design to deployed schema. Changes can be reviewed visually before deployment, reducing the risk of schema design errors that are difficult to reverse once data exists.

Productivity Gain

Prototyping a new custom object with 25 fields for a requirements review meeting typically requires a developer to manually write metadata XML or navigate Setup. With npx sf-schema-builder, the schema is designed and deployed in 30 minutes, allowing the team to demo it in the org during the meeting itself rather than in a future sprint.

sf-deploy-viewer

52 downloads/mo

npx sf-deploy-viewer

sf-deploy-viewer is a Salesforce Deployment Viewer that visualizes deployment results with a modern UI supporting SOAP API + XML. After a deployment, the raw results from the Salesforce Metadata API are a nested JSON/XML structure that is tedious to interpret. This tool parses deployment results and presents them as a clear dashboard showing component successes, failures, and test results with drill-down capability.

The SOAP API + XML support means it works with both modern SF CLI deployments and legacy Ant/Force.com Migration Tool deployments — covering the full spectrum of deployment approaches used in enterprise Salesforce teams.

Productivity Gain

A deployment with 150 components where 8 fail would require parsing raw JSON output to understand what failed and why. npx sf-deploy-viewer renders the results as a filterable table with failure reasons highlighted, reducing post-deployment failure analysis from 20 minutes to 3 minutes per deployment.

sf-org-inspector

26 downloads/mo

npx sf-org-inspector

sf-org-inspector is a Salesforce Org Inspector CLI tool. It performs a deep inspection of a Salesforce org, cataloguing its configuration: installed packages and their versions, custom metadata types, platform events, custom settings, custom labels, named credentials, and dozens of other configuration elements. The inspection output provides a comprehensive technical profile of the org suitable for architecture reviews and risk assessments.

Productivity Gain

When joining an existing Salesforce project for a technical assessment, npx sf-org-inspector generates a complete org profile in minutes — revealing 3 outdated managed packages with known security vulnerabilities and 45 inactive platform event definitions that are consuming governor limit resources unnecessarily.

sf-flow-viewer

10 downloads/mo

npx sf-flow-viewer

sf-flow-viewer is a beautiful, interactive HTML viewer for Salesforce Flows. Salesforce Flows are powerful automation tools, but their visual representation in the Flow Builder is only available inside the Salesforce org. sf-flow-viewer renders Flow metadata XML as interactive HTML diagrams that can be viewed, shared, and reviewed without org access — essential for code reviews and documentation.

The interactive viewer allows reviewers to trace the execution paths of complex Flows, understand decision branches, and identify potential performance or logic issues without requiring a shared org session.

Productivity Gain

Conducting a code review of 10 complex Flows for a release requires sharing an org session or screen-sharing. With npx sf-flow-viewer, each Flow is exported as a standalone HTML file that reviewers can examine independently at their own pace, enabling asynchronous code reviews and reducing review meeting time by 50%.

dt2html

33 downloads/mo

npx dt2html

dt2html is a CLI tool to visualize Salesforce Decision Table XML as interactive HTML with Mermaid diagrams and SOQL generation. Decision Tables are a specialized Salesforce automation capability that encodes complex conditional logic in a table format. This tool renders Decision Table XML as clear HTML tables and Mermaid decision tree diagrams, making the logic understandable to both developers and business stakeholders.

The SOQL generation feature is particularly useful — it converts the Decision Table's conditions into equivalent SOQL queries, enabling developers to test the logic against live data without executing the Decision Table through a full Salesforce transaction.

Productivity Gain

During UAT of a complex pricing Decision Table with 200+ rules, stakeholders need to validate specific scenarios. npx dt2html renders the table as an interactive HTML with filterable rules and the equivalent SOQL for each condition — reducing stakeholder review sessions from 4 hours of screen sharing to self-service HTML review.

apex-explorer

36 downloads/mo

npx apex-explorer

apex-explorer browses, searches, and analyzes Salesforce Apex classes with a Monaco editor, global search, and KPI dashboard. It provides a complete Apex codebase browser that feels like a lightweight IDE — with syntax highlighting, cross-class search, method navigation, and metrics like class count, method count, and code coverage summaries displayed in a KPI dashboard.

For architects performing code reviews or technical due diligence, apex-explorer enables rapid navigation across large Apex codebases without setting up a full development environment. The global search finds usages of specific methods, field references, or patterns across all classes simultaneously.

Productivity Gain

During a technical acquisition review of a company's Salesforce org with 800 Apex classes, npx apex-explorer provides immediate global search and class browsing that reveals code quality patterns, identifies dependency hotspots, and surfaces classes with no test coverage — compressing a week-long code review into 2 days.

lwc-generator-cli

45 downloads/mo

npx lwc-generator-cli

lwc-generator-cli is an AI-powered Lightning Web Component generator with an interactive web UI. It takes a natural language description of the desired LWC — including functionality, UI elements, and data binding requirements — and generates production-ready HTML, JavaScript, and CSS files. The interactive UI allows iterative refinement of the generated component before committing to the file system.

For teams that need to rapidly prototype UI components during requirement reviews or sprint ceremonies, this tool bridges the gap between design conversations and working code. Generated components follow Salesforce LWC best practices and include standard SLDS styling.

Productivity Gain

A developer asked to prototype a custom account summary tile component for a requirements review can describe the component to npx lwc-generator-cli and have a working initial implementation in 10 minutes — turning a "we'll build it next sprint" into "here's a working prototype for feedback today."

sf-doc-generator-cli

20 downloads/mo

npx sf-doc-generator-cli

sf-doc-generator-cli is an AI-powered Salesforce project documentation generator from requirements. It takes requirements documents, user stories, and design notes as input and generates comprehensive technical documentation — including data model diagrams, deployment guides, test strategy documents, and architecture decision records — by combining AI generation with Salesforce org introspection.

Productivity Gain

At the end of a project phase, generating technical documentation from 50 user stories and the implemented org's metadata typically takes a consultant 5 days. npx sf-doc-generator-cli generates the initial documentation draft in hours, leaving the consultant to review and refine rather than write from scratch. Saves 3–4 days per project phase.

mc-apex-doc

17 downloads/mo

npx mc-apex-doc

mc-apex-doc generates inline documentation and test classes for Salesforce Apex classes. It analyzes existing Apex code and generates ApexDoc comments for classes and methods, including parameter descriptions, return type documentation, and usage examples. For codebases with poor or missing documentation, this tool provides an AI-assisted path to comprehensive inline documentation without manual writing effort.

The test class generation capability is equally valuable — it analyzes the production code's logic paths and generates test class scaffolding with test methods covering positive cases, negative cases, and boundary conditions.

Productivity Gain

Running npx mc-apex-doc on 100 Apex classes that lack documentation generates ApexDoc-formatted comments and test class scaffolding for each — a task that would take a developer 2 weeks of manual documentation writing. The AI-generated documentation requires review and refinement but provides 70% of the final content immediately.

apex-utils-cli

16 downloads/mo

npx apex-utils-cli

apex-utils-cli provides AI-powered Apex code utilities — generating inline documentation and test classes. It is the CLI companion to mc-apex-doc, providing scriptable access to the same capabilities for use in automation pipelines. This enables batch documentation generation across large codebases and integration into pre-commit hooks or CI/CD pipelines as a documentation enforcement mechanism.

Productivity Gain

Integrating npx apex-utils-cli into the CI/CD pipeline as a pre-merge check ensures that all new Apex classes submitted in a PR have at minimum AI-generated documentation stubs — establishing a documentation baseline even for teams under delivery pressure.

sf-apex-codegen

16 downloads/mo

npx sf-apex-codegen

sf-apex-codegen is a Salesforce Metadata CLI with beautiful HTML visualizations focused on Apex code generation from metadata. Given a Salesforce object's metadata, it generates boilerplate Apex code patterns — trigger handlers, service classes, selector classes — following the FFLIB or equivalent enterprise pattern frameworks. This scaffolding dramatically accelerates the setup of well-structured Apex for new objects.

Productivity Gain

Starting development on a new custom object that requires a full FFLIB pattern implementation (selector, service, domain, trigger handler) normally takes 2–3 hours of boilerplate writing. npx sf-apex-codegen generates all four layers from the object's metadata in minutes, letting the developer jump straight to implementing business logic.

generator-sfdx

40 downloads/mo

npx generator-sfdx

generator-sfdx is a Generator for SFDX — a Yeoman-based generator that scaffolds complete Salesforce DX project structures. It creates the correct directory layout, configuration files, scratch org definitions, CI/CD pipeline configurations, and initial metadata structures for new Salesforce DX projects. Starting a project from scratch with proper structure takes hours without tooling; this generator handles it in minutes.

The generator includes templates for common project types — standalone org implementations, managed package development, and multi-package projects — ensuring teams start with a structure that scales rather than one that needs refactoring after the first sprint.

Productivity Gain

Setting up a new Salesforce DX project with proper structure, CI/CD pipeline (GitHub Actions), scratch org definition, and baseline configuration typically takes a lead developer half a day. npx generator-sfdx generates the complete project scaffold in 5 minutes, with the team ready to write first-sprint code immediately.

Summary

Key Takeaways — Part 4
  • sf-cml-deploy and pcm-erd-viewer are essential for Revenue Cloud teams — providing CML deployment UI and product catalog visualization
  • sf-schema-builder and generator-sfdx accelerate new development setup significantly
  • sf-flow-viewer enables asynchronous Flow code reviews — a significant process improvement for automation-heavy orgs
  • lwc-generator-cli and apex-utils-cli bring AI code generation to the Salesforce front-end and back-end simultaneously
  • sf-log-viewer transforms hours of Apex debug log analysis into minutes with its structured parsing
  • apex-explorer enables rapid codebase navigation without setting up a full development environment
  • Documentation tools (mc-apex-doc, sf-doc-generator-cli) use AI to eliminate the documentation debt that plagues most Salesforce codebases
