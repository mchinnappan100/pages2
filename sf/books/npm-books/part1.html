Salesforce Core Dev Tools

The essential daily-driver packages for Salesforce developers and architects — covering SOQL execution, metadata browsing, REST API clients, MCP integration, anonymous Apex, and deployment tooling.

Reading time: ~35 min
Packages: 14
Key theme: Core developer workflow

The tools in Part 1 address the fundamental daily workflow of a Salesforce developer. Whether you are executing SOQL queries, inspecting metadata, calling REST APIs, or deploying components, these packages remove friction from routine operations. Built with modern web UIs using Monaco Editor and dark-themed interfaces, they feel at home in any professional development environment. Every tool runs via npx — no installation overhead, just instant productivity.

These packages collectively span the three pillars of Salesforce development: querying (SOQL, REST), metadata (browsing, deploying, diffing, dependency analysis), and connectivity (MCP, CLI APIs). Together they replace a scattered collection of browser bookmarks, Workbench sessions, and manual API calls with a coherent, keyboard-driven toolkit.

The Packages

sf-utils-cli

94 downloads/mo

npx sf-utils-cli

sf-utils-cli is a modern, web-based interface for executing SOQL queries, Anonymous Apex, and DML operations against Salesforce orgs, powered by Monaco Editor. It replaces the aging Workbench and Developer Console for day-to-day query and script execution, presenting results in sortable, filterable tables with syntax-highlighted editors. The tool authenticates via your existing SF CLI session, meaning no token juggling is needed.

Developers particularly value the Monaco-powered editor with Apex and SOQL syntax highlighting, auto-complete hints, and keyboard shortcuts that mirror VS Code. The DML editor lets you safely test Insert, Update, or Delete operations with confirmation dialogs, reducing costly accidents in sandboxes.

Productivity Gain

Instead of switching between Developer Console tabs and pasting tokens into Workbench, a developer can execute a complex SOQL query, iterate on Anonymous Apex to fix a logic bug, and perform a targeted data fix — all in one browser tab. Estimated time saved: 20–30 minutes per debugging session.

mc-sf-query

38 downloads/mo

npx mc-sf-query

mc-sf-query is a Node.js CLI tool to query Salesforce orgs, describe objects, and list metadata, with HTML output. It surfaces the full Salesforce object model through a clean command-line interface and generates shareable HTML reports. You can describe any SObject to see all fields, types, and relationships, or execute SOQL and save results as formatted HTML files for stakeholders who don't have org access.

The HTML output is self-contained and professional-looking — useful for generating lightweight data dictionaries on the fly, documenting API responses, or sharing query results with business analysts during requirements sessions.

Productivity Gain

During a requirements review meeting, instead of screen-sharing a Developer Console session, you can run npx mc-sf-query --object Account --html and share a polished HTML report of the Account object's fields. Stakeholders get a readable reference they can bookmark and search. Saves 30+ minutes of manual documentation per object.

sf-soql-cli

27 downloads/mo

npx sf-soql-cli

sf-soql-cli executes Salesforce SOQL queries using an access token and exports results as CSV. It is the scriptable, pipeline-friendly SOQL runner designed for automation and CI/CD environments where a browser UI is not available. By accepting credentials via environment variables, it integrates cleanly into shell scripts, GitHub Actions, and data extraction pipelines.

The CSV output makes it trivial to pipe results into data processing tools, load them into spreadsheets, or feed them to other command-line utilities. For architects who need to audit large datasets across multiple orgs, sf-soql-cli becomes a core component of automated reporting scripts.

Productivity Gain

An architect auditing user license utilization across 5 sandboxes can write a single bash loop using npx sf-soql-cli with different access tokens, collect 5 CSV files, and concatenate them for analysis — all in under 5 minutes. Replacing manual Workbench exports across each org saves 45+ minutes per audit cycle.

sf-rest-client

76 downloads/mo

npx sf-rest-client

sf-rest-client is a Postman-like REST client for Salesforce and Generic APIs with SOAP Support, GraphQL, and an AI assistant. It presents a full-featured browser UI for composing HTTP requests, inspecting responses, and managing collections — but with native Salesforce authentication baked in. SOAP support means you can test legacy Metadata API calls without spinning up a separate Java client.

The integrated AI assistant helps generate request bodies, explain API responses, and suggest correct endpoint URLs — dramatically reducing the time spent hunting through Salesforce API documentation. GraphQL support covers the newer Salesforce GraphQL API, making this a single client for all Salesforce API paradigms.

Productivity Gain

A developer integrating a third-party system via Salesforce REST API can prototype the entire request/response cycle, tweak headers, and test error scenarios in sf-rest-client before writing a single line of integration code. The AI assistant suggests the correct composite API structure. This replaces 1–2 hours of API documentation research per integration.

mc-api-cli

35 downloads/mo

npx mc-api-cli

mc-api-cli is a CLI API client with Postman-like features, designed for general API testing with a focus on developer ergonomics. It supports authorization headers, request collections, environment variables, and response formatting. While sf-rest-client is Salesforce-centric, mc-api-cli is the general-purpose companion for testing any HTTP endpoint.

It is particularly useful for developers building integration middleware who need to test both Salesforce endpoints and external system APIs from the same tool, keeping the workflow consistent and reducing context switching.

Productivity Gain

When debugging a Salesforce-to-ERP integration, you can use npx mc-api-cli to test both the Salesforce REST endpoint and the ERP's webhook endpoint from the same terminal session, comparing payloads side by side. Eliminates the need to maintain separate Postman workspaces for each system.

sf-mcp-cli

35 downloads/mo

npx sf-mcp-cli

sf-mcp-cli is a CLI for interacting with Salesforce Model Context Protocol (MCP) to execute SOQL queries, manage orgs, and perform metadata operations. MCP is an emerging protocol for AI-assisted development workflows, and this tool bridges Salesforce operations into that ecosystem. It allows AI coding assistants and agentic workflows to invoke Salesforce operations programmatically.

As AI-assisted Salesforce development matures, sf-mcp-cli positions developers at the frontier — enabling natural language-driven SOQL generation, AI-assisted metadata retrieval, and automated org management tasks that would otherwise require multiple manual steps.

Productivity Gain

An AI coding session where you ask "find all Apex classes modified in the last 30 days" can be executed directly through npx sf-mcp-cli as part of the AI agent's tool chain — no manual query composition needed. This unlocks fully automated code review prep workflows that previously required manual steps.

sf-commons-meta

36 downloads/mo

npx sf-commons-meta

sf-commons-meta is a Salesforce Commons Metadata Viewer CLI that provides a unified interface for browsing and inspecting common Salesforce metadata types. It presents metadata in clean, navigable HTML output that helps developers quickly understand the structure of an org without navigating Setup menus. It covers objects, fields, validation rules, workflow rules, and other frequently accessed metadata types.

For architects performing org assessments, sf-commons-meta provides a rapid inventory tool that can be executed in minutes to generate a browsable snapshot of key metadata — invaluable during discovery phases of implementation projects.

Productivity Gain

At the start of an org assessment engagement, running npx sf-commons-meta generates a comprehensive HTML snapshot of common metadata types that the whole team can navigate. Replaces 2–3 hours of manual Setup exploration with a 5-minute automated inventory generation.

sf-settings-viewer

38 downloads/mo

npx sf-settings-viewer

sf-settings-viewer is a CLI tool to parse and view Salesforce settings XML files in a user-friendly HTML format. Salesforce settings files (such as OrgPreferenceSettings.settings, SecuritySettings.settings, and dozens of others) are dense XML that is difficult to read and compare manually. This tool transforms those files into clean, searchable HTML tables.

During deployments and org migrations, settings files are often the source of hard-to-debug discrepancies. sf-settings-viewer makes it trivial to review what settings are configured in a package and catch misconfigurations before they reach production.

Productivity Gain

Before deploying a settings metadata file to production, run npx sf-settings-viewer --file OrgPreferenceSettings.settings to generate a human-readable HTML report. Share it with the release approver for a 5-minute review instead of asking them to parse raw XML. Catches misconfigured settings before they cause post-deployment incidents.

sf-metadata-selector

24 downloads/mo

npx sf-metadata-selector

sf-metadata-selector is an interactive CLI tool for browsing, selecting, and generating package.xml files. Composing package.xml manually is error-prone and time-consuming, especially for large deployments with many metadata types. This tool presents a searchable, filterable browser of org metadata from which you can select specific components and generate a validated package.xml with a single command.

The interactive selector supports multi-select across metadata types, making it easy to build targeted deployment packages that include exactly the components needed — nothing more, nothing less. This precision reduces deployment risk and speeds up release cycles.

Productivity Gain

Composing a package.xml for a targeted hotfix deployment that touches 3 Apex classes, 2 flows, and 1 custom object typically takes 20–30 minutes manually. With npx sf-metadata-selector, you search and select each component interactively and generate the file in under 5 minutes, with zero XML typos.

sf-metadata-deploy

18 downloads/mo

npx sf-metadata-deploy

sf-metadata-deploy is a Salesforce Metadata Deployment CLI with a Visual UI. It provides a browser-based interface for initiating and monitoring Salesforce metadata deployments, surfacing deployment status, component errors, and test results in a clear, navigable format. It abstracts over the raw SF CLI deployment commands with a more developer-friendly interface.

The visual deployment status page shows per-component pass/fail results in real time, making it far easier to diagnose deployment failures than parsing raw JSON output from the SF CLI. Test result summaries are presented alongside deployment results, giving a complete picture of each release.

Productivity Gain

When a deployment fails with 12 component errors across different metadata types, npx sf-metadata-deploy's visual UI lets you identify patterns in the failures at a glance — rather than scrolling through 200 lines of JSON. Diagnosis time drops from 20 minutes to 3 minutes per failed deployment.

salesforce-metadata-central

11 downloads/mo

npx salesforce-metadata-central

salesforce-metadata-central is a Salesforce Metadata Explorer with a Visual Interface — a comprehensive tool for browsing, visualizing, and generating SOQL queries for org metadata. It serves as a central hub for metadata exploration, allowing developers to navigate the complete metadata tree of an org, inspect individual components, and generate the SOQL queries needed to query related runtime data.

The visual interface is especially valuable for architects onboarding to an unfamiliar org, providing a map of what metadata exists before diving into implementation work. The integrated SOQL generator means you can go from "I see this custom object" to "here is a query for its data" in seconds.

Productivity Gain

During an architecture review of a legacy org, npx salesforce-metadata-central provides an immediate visual inventory of all metadata types, their counts, and cross-references — turning a 2-day manual discovery exercise into a 30-minute automated exploration with shareable screenshots.

sf-meta-cli

16 downloads/mo

npx sf-meta-cli

sf-meta-cli analyzes Salesforce manual steps and suggests Metadata API automation using LLM. This AI-powered tool takes descriptions of manual Salesforce configuration steps — the kind typically documented in runbooks — and generates the equivalent Metadata API XML or deployment artifacts. It bridges the gap between "click-ops" configuration and code-driven automation.

For teams modernizing their release processes from manual Setup changes to source-driven deployments, sf-meta-cli dramatically accelerates the conversion effort by suggesting the correct metadata structure for common configuration patterns.

Productivity Gain

A runbook with 15 manual Setup steps for enabling a new feature can be fed to npx sf-meta-cli, which generates draft Metadata API XML for each step. Converting a 4-hour manual task into a 30-minute review-and-refine session, while simultaneously building a repeatable deployment artifact.

sf-meta-diff

11 downloads/mo

npx sf-meta-diff

sf-meta-diff is a CLI tool to diff Salesforce metadata between two orgs using Monaco Editor and Tailwind dark theme. It connects to two orgs simultaneously, retrieves specified metadata components, and presents a side-by-side Monaco diff view — the same powerful diff engine used in VS Code — in a browser window. This is indispensable for release validation and environment synchronization checks.

Unlike simple text diff tools, sf-meta-diff understands Salesforce metadata structure, presenting diffs in context that makes changes meaningful. Architects use it to validate that a promotion from sandbox to production captured exactly the intended changes and nothing more.

Productivity Gain

Before approving a production deployment, a release manager can run npx sf-meta-diff --source sandbox --target production --component ProfileName to see a precise diff of what will change in that profile. Catches unintended changes that would otherwise slip through manual review. Saves 1–2 hours of painstaking XML comparison per release.

sf-dependency-analyzer

10 downloads/mo

npx sf-dependency-analyzer

sf-dependency-analyzer is a Salesforce Metadata Component Dependency Analyzer CLI. It queries the Salesforce Tooling API's MetadataComponentDependency object to build a comprehensive dependency graph for org components. Knowing what depends on what is critical before deleting components, restructuring packages, or planning managed package upgrades.

The analyzer generates visual HTML dependency graphs that make complex component relationships understandable at a glance. It identifies orphaned components, circular dependencies, and tightly coupled clusters that should be addressed during refactoring initiatives.

Productivity Gain

Before deprecating a custom field that "looks unused," running npx sf-dependency-analyzer --component CustomField__c immediately reveals that 3 Apex classes, 2 flows, and 1 report reference it. Prevents a production incident that would have taken hours to diagnose and roll back.
