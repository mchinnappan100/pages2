To access a parent Account's Name from a Contact query, which syntax is correct?
✓ Correct: B

Child-to-parent traversal uses the relationship name (not the field name). For the standard AccountId lookup, the relationship name is Account — so Account.Name. Custom lookup My_Field__c uses My_Field__r.Name.

2
A parent-to-child sub-select like (SELECT Id FROM Contacts) returns what if no child records exist?
✓ Correct: B

If no child records exist for a parent, the sub-select result is null, not an empty list. Always null-check: if (acc.Contacts != null) { for (Contact c : acc.Contacts) { ... } }. Iterating null directly throws a NullPointerException.

3
What is the maximum number of sub-selects (child queries) allowed in a single SOQL query?
✓ Correct: C

SOQL supports up to 20 sub-selects per query. Each sub-select can return up to 600 child records. All rows (parent + children) count toward the 50,000-row governor limit. The entire structure counts as a single SOQL query.

4
What does the TYPEOF keyword in SOQL enable?
✓ Correct: B

TYPEOF handles polymorphic lookups (Who = Lead or Contact; What = Account, Opportunity etc.) by specifying different fields to return depending on the related record's type. Without TYPEOF, accessing type-specific fields on the wrong type throws a QueryException.

5
What function filters on aggregate results AFTER grouping (not on individual rows)?
✓ Correct: B

HAVING filters on grouped aggregate results — equivalent to SQL HAVING. WHERE filters individual rows before aggregation. Using WHERE COUNT(Id) > 5 is a compile error; the correct syntax is HAVING COUNT(Id) > 5.

6
What type does a SOQL query with GROUP BY always return?
✓ Correct: B

Aggregate queries (with GROUP BY or aggregate functions like SUM, COUNT with an alias) return AggregateResult[]. Access values with (Type) ar.get('alias'). Exception: SELECT COUNT() FROM Obj (no alias, no GROUP BY) returns a plain Integer.

7
You write SELECT StageName, COUNT(Id) FROM Opportunity GROUP BY StageName. How do you access the count?
✓ Correct: B

Without an explicit alias, Salesforce auto-generates expr0, expr1... for aggregate columns. This is fragile — the index can change if columns are reordered. Always use aliases: COUNT(Id) cnt → ar.get('cnt').

8
What does GROUP BY ROLLUP add compared to a plain GROUP BY?
✓ Correct: A

GROUP BY ROLLUP(A, B) adds subtotal rows: one for each left-truncated combination (A+B, A only, grand total). Subtotal rows have null for the dimension being summarised. Use the GROUPING(field) function (returns 1 for subtotal rows) to distinguish them from real data.

9
A dynamic SOQL builder receives field names from user input. What is the correct security step?
✓ Correct: B

Field names can't be escaped with escapeSingleQuotes(). The correct approach is schema validation: check each field name exists in Schema.SObjectType.Account.fields.getMap().keySet() AND that .getDescribe().isAccessible() returns true before including it in the SELECT clause.

10
What is the relationship name for a custom child object Order_Item__c with a master-detail to Order__c?
✓ Correct: D

The child relationship name in a sub-select is set when you define the lookup/master-detail field — it's specified in the 'Child Relationship Name' field in Setup. The default is typically the plural of the object's label (e.g., Order_Items__r) but it can be customised. Always check the field definition in Setup.
