Which SOQL keyword is NOT valid — it does not exist in SOQL (unlike SQL)?
✓ Correct: B

SOQL has no SELECT *. You must explicitly name every field. This is by design — Salesforce needs to know exactly which fields to retrieve to enforce FLS and minimise data transfer. Always include Id explicitly.

2
What is the maximum number of rows a SOQL query can return?
✓ Correct: C

A SOQL query can return up to 50,000 rows per transaction. If you need more, use Batch Apex with a QueryLocator (supports up to 50 million). This limit applies to the total rows across all queries in the transaction, not per query.

3
You want records created in the rolling last 7 days (including today). Which date literal is correct?
✓ Correct: B

LAST_N_DAYS:7 returns records where the date field is within the last 7 days including today — a rolling window. LAST_WEEK is a fixed calendar week (Sun–Sat) before the current week — not a rolling 7-day window.

4
Which of these WHERE clause patterns does NOT use an index and always causes a TABLE_SCAN?
✓ Correct: C

A leading wildcard LIKE '%cloud%' forces a TABLE_SCAN — the index cannot be used because the pattern doesn't start with a known prefix. Trailing wildcard LIKE 'ACME%' CAN use an index. For contains searches, use SOSL instead.

5
What is the purpose of a bind variable (the : prefix) in SOQL?
✓ Correct: B

Bind variables inject Apex values into SOQL without string concatenation. They are automatically escaped, preventing SOQL injection. They work for primitives, Lists, Sets, and Map.keySet() — but NOT for field names or object names (use Schema validation for those).

6
A SOQL semi-join uses WHERE Id IN (SELECT AccountId FROM Opportunity ...). What does this achieve?
✓ Correct: B

A semi-join filters the outer query based on related records — evaluated entirely at the database level using a single SOQL query. It's equivalent to SQL's WHERE EXISTS and is far more efficient than loading both sets into Apex and comparing in code.

7
What is the difference between COUNT() and COUNT(Id) in SOQL?
✓ Correct: B

SELECT COUNT() FROM Obj (no field, no alias) returns a plain Integer. SELECT COUNT(Id) cnt FROM Obj returns AggregateResult[] — you access with ar.get('cnt'). Use COUNT() for simple counting without GROUP BY.

8
What is the maximum value allowed for OFFSET in a SOQL query?
✓ Correct: C

OFFSET maximum is 2,000. Beyond that, Salesforce throws a compile-time error. Even within this limit, large OFFSETs are slow — each page scans all prior rows. For deep pagination, use keyset pagination (WHERE Id > :lastId ORDER BY Id) instead.

9
Which SOQL clause enforces field-level security and throws a QueryException if the user can't access a field?
✓ Correct: B

WITH SECURITY_ENFORCED (API 48+) checks FLS for every field in SELECT and WHERE. If the running user cannot read any field, a System.QueryException is thrown. The class must also use with sharing to enforce record-level security.

10
An anti-join in SOQL uses which syntax to find records with NO matching related records?
✓ Correct: B

SOQL anti-joins use NOT IN (subquery). The AccountId != null filter is important — without it, null AccountIds would be included in the subquery result set and could cause unexpected exclusions. Always null-check the FK field in anti-join subqueries.
