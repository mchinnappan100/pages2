What is the maximum number of SOQL queries allowed in a single synchronous Apex transaction?
✓ Correct: B — 100

Synchronous Apex is limited to 100 SOQL queries per transaction. Asynchronous contexts (Batch, Queueable, Future) allow 200. This is why placing SOQL inside loops is catastrophic — with 101 records you'd immediately exceed the limit with a LimitException.

2
Which SOQL clause enforces field-level security and throws a QueryException if the running user cannot access a queried field?
✓ Correct: B

WITH SECURITY_ENFORCED (API 48+) checks field- and object-level security for every field in the SELECT and WHERE clauses. If the user lacks read access to any field, a System.QueryException is thrown. with sharing on the class enforces record-level sharing but not FLS.

3
You need to retrieve all Contacts and their parent Account name in one query. Which syntax is correct?
✓ Correct: B

Child-to-parent traversal uses dot notation on the relationship field name (not the ID field). For a standard lookup field AccountId, the relationship name is Account, so you write Account.Name. SOQL has no JOIN keyword — relationship traversal replaces it. Sub-selects (option A) are for parent-to-child queries.

What type does an aggregate SOQL query return?
✓ Correct: B

Aggregate queries (using COUNT, SUM, AVG, MAX, MIN, or GROUP BY) return AggregateResult[]. Access each value using ar.get('alias') and cast explicitly. Exception: SELECT COUNT() FROM Object (no alias) returns a plain Integer directly.

5
What is the primary difference between SOQL and SOSL?
✓ Correct: B

SOQL is a structured query language — it matches records based on exact or condition-based field values. SOSL is a full-text search that queries Salesforce's search index across multiple objects simultaneously (like a search box). Both count against governors. Use SOQL for data retrieval with known field values; use SOSL for "find this text anywhere" scenarios.

6
Which DML operation inserts new records or updates existing ones based on a matching external ID field?
✓ Correct: C

upsert checks each record: if no match is found (by Id or external ID field), it inserts; if a match is found, it updates. Syntax: upsert records ExternalId__c;. Without specifying a field, it falls back to the Salesforce Id. This is essential for data integration scenarios where records may or may not already exist.

7
You run delete myList; and then query those same records. What do you need to include in the SOQL to find the deleted records?
✓ Correct: C

Appending ALL ROWS to a SOQL query includes records in the Recycle Bin. Example: [SELECT Id FROM Account WHERE IsDeleted = true ALL ROWS]. Without ALL ROWS, deleted records are invisible to SOQL. You can then undelete them within 15 days.

8
What does Database.insert(records, false) do differently from insert records;?
✓ Correct: B

The boolean parameter is allOrNone. insert records defaults to allOrNone = true — any failure rolls back all records. Database.insert(records, false) sets allOrNone = false — valid records commit and you inspect the SaveResult[] for per-row errors.

9
Which SOQL date literal returns records created within the last 7 days?
✓ Correct: B

LAST_N_DAYS:n returns records where the date field is in the last n days (including today). LAST_WEEK refers to the full calendar week before the current week — not a rolling 7-day window. The :n suffix is the parameterised form available on many date literals (also NEXT_N_DAYS:n, LAST_N_MONTHS:n, etc.).

10
What is the correct way to count all Account records without loading them into heap memory?
✓ Correct: B

SELECT COUNT() FROM Account (no field alias, no parentheses argument) returns a plain Integer directly. This counts at the database level without materialising records into the heap. Option A is dangerous — it loads up to 50,000 records just to call .size(). Option D works but returns an AggregateResult[] — more verbose than needed.
