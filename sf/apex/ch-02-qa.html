Which numeric type should you always use for financial calculations in Apex, and why?
✓ Correct: B

Decimal is base-10 arbitrary-precision. Double is base-2 (IEEE 754) and cannot represent many decimal fractions exactly — for example, 0.1 + 0.2 in Double yields 0.30000000000000004. Currency fields on sObjects map to Decimal in Apex. Always use .setScale(2, RoundingMode.HALF_UP) before displaying monetary values.

What does String.isBlank(s) return when s = ' ' (three spaces)?
✓ Correct: C

String.isBlank(s) returns true when the string is null, empty (''), or contains only whitespace. String.isEmpty(s) only returns true for null or empty — it returns false for whitespace. This makes isBlank the right choice for validating user input where leading/trailing spaces are meaningless.

You are collecting Account Ids from a list of Opportunities, some of which share the same Account. Which collection type prevents duplicate Ids automatically?
✓ Correct: B

A Set stores only unique elements by definition — calling .add() with a duplicate value is silently ignored. A List allows duplicates. A Map could work (key = Id, value = Id) but is unnecessarily complex. Use Set<Id> when you need unique Ids for a SOQL WHERE Id IN :mySet clause.

What is printed by this code?

Integer a = 7;
Integer b = 2;
System.debug(a / b);
✓ Correct: B — 3

Integer division in Apex truncates toward zero — the fractional part is dropped. 7 / 2 = 3, not 3.5. To get 3.5 you must cast at least one operand: Decimal result = (Decimal)a / b; or declare a as Decimal. This is a common source of subtle bugs in percentage or ratio calculations.

Which loop syntax is specifically designed to process large SOQL result sets without consuming excessive heap memory?
✓ Correct: C

The SOQL for-loop — embedding a SOQL query directly in the for-loop — causes Salesforce to return records in 200-row batches. Each batch is processed and discarded before the next arrives, so you never load the full result set into the heap at once. This is the correct pattern for iterating over potentially millions of records without hitting the 6 MB heap limit. Note: DML statements inside the loop still count against the 150-statement governor.

6
A Boolean variable Boolean active = null;. What happens when you write if (active) { }?
✓ Correct: B

Unlike JavaScript, Apex does not coerce null to false. Using a null Boolean as a condition throws a NullPointerException at runtime. Always guard: if (active != null && active). This trips up developers coming from JavaScript or Python where null/falsy values are silently treated as false in conditionals.

7
You have a Map<Id, Account> and call .get(someId) where someId is not a key in the map. What is returned?
✓ Correct: B — null

Map.get(key) returns null silently when the key is not present — no exception is thrown. This means you must always null-check the result before using it, otherwise you risk a NullPointerException when you try to access a field on the returned object. Use map.containsKey(key) to test first, or null-check the result of get().

8
Which statement about Apex enums is correct?
✓ Correct: C

Every Apex enum value provides .name() (returns the String name of the constant) and .ordinal() (returns its 0-based position in the declaration). Apex does not have a switch statement — use if/else if chains or a Map<MyEnum, ...>. Enums cannot extend other enums (they implicitly extend the Enum base). They can be declared both at top-level and inside classes.

9
You want to initialize a Map<Id, Account> directly from a SOQL query in a single line. Which syntax is correct?
✓ Correct: B

Passing a List<sObject> (the result of a SOQL query) to the Map<Id, sObject> constructor is a standard Apex idiom. The Map is keyed by the Id field of each returned record. This eliminates the need to loop through the list to build the map manually, and is one line.

Map<Id, Account> m = new Map<Id, Account>(
    [SELECT Id, Name, Rating FROM Account WHERE Type = 'Customer']
);
Account a = m.get(someId); // O(1) lookup

A DML operation fails on 3 of 10 records. You want successful rows to be committed and to log details about each failure. Which catch block provides per-row failure details for a DmlException?
✓ Correct: B

DmlException exposes per-row error details. getNumDml() returns the number of failed rows, and getDmlMessage(i) / getDmlIndex(i) give the message and original list index for each failure. To allow partial success in the first place, use Database.insert(records, false) and inspect the SaveResult[] array.

try {
    insert records; // allOrNone = true by default
} catch (DmlException e) {
    for (Integer i = 0; i < e.getNumDml(); i++) {
        System.debug('Row ' + e.getDmlIndex(i) +
                     ': ' + e.getDmlMessage(i));
    }
}
