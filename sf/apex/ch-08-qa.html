Which annotation makes an Apex method callable as an Agentforce action?
✓ Correct: B

@InvocableMethod is the annotation that exposes an Apex method to Agentforce, Flow, and Process Builder. When you create an Agent Action backed by Apex, the action targets a static method annotated with @InvocableMethod(label='...' description='...'). @AuraEnabled exposes methods to LWC/Aura, not to Agentforce.

2
An @InvocableMethod must accept parameters in what form?
✓ Correct: B

@InvocableMethod accepts parameters as a List<InputClass> where the input class has public fields annotated with @InvocableVariable. The List wrapper is required because Flow and Agentforce can call the method with multiple input records (bulk invocation). The method must also return a List<OutputClass> or void.

3
Why is the description parameter on @InvocableMethod critically important for Agentforce?
✓ Correct: B

The Agentforce LLM uses the description (along with the label and parameter descriptions) to make a decision: "Should I call this action for this user request?" A vague description like "Does something with accounts" will result in the agent calling it at wrong times or not calling it when it should. Write descriptions as precise instructions: "Use this when the user asks about a specific company or wants to look up account details."

4
An agent action's Apex class does not declare with sharing. What is the security risk?
✓ Correct: B

Agent actions run on behalf of the current user — but if the class has no sharing keyword, sharing rules are inherited unpredictably (or bypassed entirely if a without sharing class is in the call stack). This could allow an agent to surface records the user has no access to. Always declare with sharing on agent action classes to enforce the running user's record visibility.

5
What should an @InvocableMethod return when a DML operation fails, instead of throwing an unhandled exception?
✓ Correct: C

Agentforce agents cannot catch exceptions from action methods. An unhandled exception causes the agent turn to fail with a generic error message that doesn't help the user. By catching the exception inside the action and returning a structured output (success=false, errorMessage='...'), the agent can read the error and relay a user-friendly response like "I was unable to create the case because: field X is required."

6
In Agentforce, what is a Topic?
✓ Correct: B

In Agentforce, a Topic is a thematic grouping of agent actions. For example, a "Customer Support" topic might contain actions like "Create Case", "Look Up Account", and "Search Knowledge Base". Topics help the agent understand the scope of its capabilities and make better decisions about which action to invoke. Topics are configured in Agent Builder under Setup → Agents.

7
Which SOQL clause should always be included in agent action queries to prevent data leakage?
✓ Correct: B

WITH SECURITY_ENFORCED enforces field-level security (FLS) on the queried fields. If the running user cannot read a field in the SELECT clause, a QueryException is thrown. This prevents agents from inadvertently surfacing sensitive fields (like SSN__c or SalaryBand__c) to users who don't have field access, even when the class uses with sharing.

8
What does the required=true attribute on an @InvocableVariable do?
✓ Correct: B

required=true marks an @InvocableVariable as mandatory for callers (Flow, Agentforce). The builder will enforce that a value is mapped to this parameter. It does not automatically throw an exception at runtime — you should still add a null check in your Apex for defensive coding. Optional parameters omit required=true (the default is false).

9
How should you test an @InvocableMethod in an Apex unit test?
✓ Correct: B

Because @InvocableMethod methods are just static Apex methods with annotations, they can be tested directly: create input objects, call the method, and assert the output — exactly like any other Apex test. The annotation doesn't change how the method executes, only how it's surfaced to Agentforce and Flow. No special test framework is needed.

10
An agent action returns data to Agentforce. What format should the output be to ensure the agent can use it effectively?
✓ Correct: C

Agents incorporate your output into natural language responses. A small set of typed fields (an Id, a summary string, key metrics) is far more useful than a raw sObject with 50 fields or an opaque JSON blob. Include a summaryText or similar field containing a human-readable description the agent can directly embed in its response. Returning too much data wastes tokens and can cause the agent to hallucinate or misrepresent the information.
