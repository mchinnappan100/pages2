Which LoggingLevel should you use for errors that indicate a critical failure in production code?
✓ Correct: C

LoggingLevel.ERROR is for critical failures. The hierarchy from most to least verbose: FINEST → FINER → FINE → DEBUG → INFO → WARN → ERROR. Setting Apex Code level to DEBUG in log filters shows DEBUG and above — ERROR always appears. Use ERROR sparingly so it stands out.

What does Limits.getCpuTime() return?
✓ Correct: C

Limits.getCpuTime() returns consumed CPU time in milliseconds for the current transaction. Compare against Limits.getLimitCpuTime() (10,000 ms sync / 60,000 ms async) to see how much is left. Use it before and after suspect code sections to pinpoint bottlenecks.

Which pattern eliminates the most common cause of CPU limit exceptions in Apex?
✓ Correct: B

Nested loops over large collections are O(n²) — 200 records × 200 records = 40,000 iterations. Replace the inner loop with a Map built once outside the outer loop, then use map.get(key) (O(1)) inside. This is the single most impactful CPU optimisation.

What is the synchronous CPU time limit per Apex transaction?
✓ Correct: B

Synchronous Apex has a 10,000 ms (10 second) CPU limit per transaction. Asynchronous contexts (Batch, Queueable, Future, Scheduled) have a 60,000 ms limit. CPU time counts only Apex execution — SOQL wait time is excluded.

5
String concatenation inside a loop (s += item) causes what problem?
✓ Correct: B

Each s += item creates a new immutable String object in heap. In a 10,000-iteration loop this means 10,000 allocations and copies. Replace with List<String> parts = new List<String>(); ... String.join(parts, ',') — one allocation.

What does the Query Plan Tool's 'cost' value indicate?
✓ Correct: B

Cost is a relative score. Cost < 0.1 = excellent index use; 0.1–0.5 = good; 0.5–0.9 = concerning; >= 1.0 = full TABLE_SCAN (every row scanned). Enable it in Developer Console → Help → Preferences → Enable Query Plan, then click Query Plan before Execute.

Which SFDX CLI command streams Apex debug logs to your terminal in real-time?
✓ Correct: C

sf apex log tail --target-org <alias> streams logs as they are generated. Add --color for colored output. Pair with sf apex run --file script.apex in another terminal to see output in real-time as you execute anonymous Apex.

What is the synchronous heap size limit in Apex?
✓ Correct: B

Synchronous Apex has a 6 MB heap limit. Asynchronous contexts (Batch, Queueable, Future) have 12 MB. Heap overflow throws a LimitException. Use SOQL for-loops to avoid loading large result sets into heap at once.

After profiling with Limits.getCpuTime(), you find Phase 2 (data processing) uses 7,000 ms. What is the best fix?
✓ Correct: C

7,000 ms out of 10,000 ms is dangerously high. Analyse Phase 2 for O(n²) nested loops (replace with Maps), String concatenation in loops (replace with String.join), JSON.serialize calls (move outside loops), or repeated Schema.describe calls (cache results). Profiling pinpoints where to look — then fix the root cause.

10
Which Apex method checks how many DML statements have been issued in the current transaction?
✓ Correct: B

Limits.getDmlStatements() returns the number of DML statements issued. Limits.getLimitDmlStatements() returns the limit (150 synchronous). Check both to see how close you are: Limits.getDmlStatements() < Limits.getLimitDmlStatements() - 10 is a safe guard pattern.
