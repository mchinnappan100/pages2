SOSL supports searching up to how many objects in a single FIND query?
✓ Correct: C

SOSL supports up to 20 objects in a single RETURNING clause. The entire query counts as 1 SOQL query against the 100-query governor limit. This multi-object capability is SOSL's key advantage over SOQL for global search scenarios.

2
What does the trailing wildcard '*' do in a SOSL search term?
✓ Correct: B

* is a wildcard that matches zero or more characters. 'cloud*' matches 'cloud', 'cloudforce', 'cloudtech' etc. A trailing wildcard uses the index efficiently. A leading wildcard ('*cloud') forces a full scan. The single-character wildcard ? matches exactly one character.

3
SOSL supports which kind of text matching that standard SOQL cannot efficiently do?
✓ Correct: B

The SOSL search index supports stemming — it tokenises and reduces words to their root form. Searching for 'run' can match 'running', 'runs', 'runner'. SOQL LIKE requires the exact substring. Stemming is language-aware and makes SOSL far better for natural-language search.

4
How do you add a WHERE filter in the RETURNING clause to only return Customer accounts?
✓ Correct: B

Per-object filters go inside the parentheses of each RETURNING object: RETURNING Account(Id, Name WHERE Type = 'Customer' LIMIT 10). Each object can have its own WHERE, ORDER BY, and LIMIT — completely independent of other objects in the same query.

5
You run: [FIND 'test' IN ALL FIELDS RETURNING Account, Contact]. Results is empty. What is the most likely cause?
✓ Correct: B

Index lag is the most common culprit — if the records were created recently (seconds to minutes ago), the search index may not have updated yet. In tests, you must use Test.setFixedSearchResults() because the index is never updated during test execution.

6
The SOSL WITH clause supports which useful filter?
✓ Correct: B

WITH DATA CATEGORY filters Knowledge articles by data category. SOSL also supports WITH NETWORK (for community/Experience Cloud searches), WITH SNIPPET (returns highlighted text), and WITH SPELL_CORRECTION = true (enables spell correction). SOSL does NOT use WITH SECURITY_ENFORCED (that's SOQL-only).

7
What does SOSL's RETURNING clause ORDER BY affect?
✓ Correct: B

ORDER BY in a RETURNING clause sorts the records within that specific object's result list. Each object can have its own ORDER BY, independent of others. Without ORDER BY, results are returned in relevance score order (most relevant first based on the search index scoring).

8
Which SOSL feature highlights the matching text in the returned results?
✓ Correct: B

WITH SNIPPET(target_length=120) returns an excerpt of the matched field content with the search term highlighted. Used with Knowledge articles and long text fields. The result includes a snippet field on each record with the highlighted context around the match.

9
SOSL returns results in what default order when no ORDER BY is specified?
✓ Correct: C

Without ORDER BY, SOSL returns records in relevance score order — records where the search term appears more prominently (e.g., in the Name field, or appearing multiple times) are ranked higher. This is similar to how a web search engine ranks results.

10
Can SOSL be used inside a trigger to search for related records?
✓ Correct: A

SOSL can be used directly inside triggers — it counts as a SOQL query against the 100-query governor limit (sync), not a callout. There are no trigger-specific restrictions on SOSL. However, the same best practice applies: don't put SOSL inside a loop, and be aware of index lag if you just performed DML on the records you're searching for.
