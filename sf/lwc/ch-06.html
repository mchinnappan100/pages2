Scoped CSS

Shadow DOM Style Isolation

/* myComponent.css — styles ONLY apply inside this component */
/* No class name collisions with other components */

.container {
    padding: 1rem;
    background: white;
}

/* Target elements */
h2 { color: navy; }
p { font-size: 0.875rem; }

/* :host — styles the component's host element itself */
:host {
    display: block;
    border: 1px solid #ccc;
}
:host(.active) {
    border-color: blue; /* when parent adds class="active" to the component */
}

/* CSS custom properties cross shadow boundaries */
:host {
    --card-background: #fff;  /* define and expose */
}
.card {
    background: var(--card-background, white);
}

Design Tokens — CSS Custom Properties

Theming with CSS Variables

/* Define tokens at component level */
:host {
    --color-brand:     #1b5297;
    --color-brand-hover: #163f75;
    --spacing-base:    0.5rem;
    --border-radius:   4px;
}

/* Use tokens throughout */
.button {
    background: var(--color-brand);
    padding: var(--spacing-base) calc(var(--spacing-base) * 2);
    border-radius: var(--border-radius);
}
.button:hover { background: var(--color-brand-hover); }

/* Consumer component overrides tokens from outside */
/* parentStyle.css: */
/* c-my-button { --color-brand: #c23934; } */

/* SLDS design tokens */
.heading {
    color: var(--lwc-colorTextDefault);      /* from SLDS token */
    font-size: var(--lwc-fontSize4);
    font-weight: var(--lwc-fontWeightBold);
}
04

:host Selector

Styling the Component Element Itself

/* :host targets the <c-my-component> element in the parent DOM */

:host {
    display: block;          /* LWC components are inline by default */
    position: relative;
    box-sizing: border-box;
}

/* :host(selector) — styles host when matching selector is applied */
:host(.compact) {
    --spacing-base: 0.25rem;
    font-size: 0.8rem;
}
:host(:hover) {
    box-shadow: 0 2px 8px rgba(0,0,0,0.15);
}
:host([disabled]) {
    opacity: 0.5;
    pointer-events: none;
}
05

::part() — Shadow Piercing

Exposing Internals for External Styling

<!-- myButton.html — expose internal parts with 'part' attribute -->
<template>
  <button part="button" class="inner-btn">
    <span part="label">{label}</span>
  </button>
</template>
/* Parent CSS can style exposed parts */
/* parentStyle.css */
c-my-button::part(button) {
    background: navy;
    border-radius: 8px;
}
c-my-button::part(label) {
    font-weight: bold;
    text-transform: uppercase;
}
06

Best Practices

Always set display:block on :host

LWC custom elements are display:inline by default (like a <span>). Set :host { display: block; } to make your component behave like a block element.

✅ :host { display: block; box-sizing: border-box; }

Use CSS Custom Properties for Theming

CSS variables cross shadow boundaries. Define your component's visual tokens as CSS custom properties so parents can customise your component's appearance without breaking encapsulation.

✅ background: var(--card-bg, #fff); /* fallback provided */

Prefer SLDS Utilities Over Custom Classes

SLDS utility classes like slds-grid, slds-m-around_medium keep your components consistent with the Salesforce design system and responsive by default.

✅ <div class="slds-grid slds-gutters slds-wrap">
