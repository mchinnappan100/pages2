Which OAuth 2.0 flow is most appropriate for machine-to-machine (server-to-server) integrations with no user involved?
✓ Correct: C

The Client Credentials flow is designed for machine-to-machine communication. The application authenticates as itself using a client_id and client_secret, with no user interaction. Salesforce handles token acquisition and refresh automatically.

2
What is the key security advantage of the JWT Bearer Token flow over Client Credentials?
✓ Correct: B

JWT Bearer eliminates the client_secret entirely. The application signs a JWT with a private RSA key stored in Salesforce Certificate and Key Management. The external system trusts the public key. No shared secret to leak or rotate.

3
In the Authorization Code (per-user) flow, whose access token is used when a Salesforce user makes a callout?
✓ Correct: B

With per-user (Named Principal) auth, each Salesforce user authenticates individually with the external system. Their personal access token is stored and used for their callouts. This is ideal for integrations where the external system needs to know the actual user's identity.

4
Salesforce Named Credentials handle OAuth token refresh automatically. What does this mean for Apex code?
✓ Correct: B

Named Credentials automatically detect when an OAuth access token is expired and use the stored refresh token to get a new one — completely transparent to Apex code. The developer just writes callout:NC_Name/path and Salesforce handles the rest.

5
A Connected App in Salesforce is needed when:
✓ Correct: B

A Connected App defines an OAuth client for systems authenticating TO Salesforce. When Org A calls Org B's REST API via OAuth, Org B needs a Connected App to issue OAuth tokens to Org A.

6
Which Token URL should a Named Credential use to call a Salesforce sandbox org's APIs?
✓ Correct: B

Sandbox orgs use https://test.salesforce.com for OAuth token requests. Production orgs use https://login.salesforce.com. Always configure separate Named Credentials for sandbox vs production.

7
What is the correct Salesforce setup path to configure an External Credential with OAuth 2.0?
✓ Correct: B

External Credentials (the modern auth layer) are configured at Setup → Security → External Credentials. This is separate from Legacy Named Credentials and provides the more flexible two-layer architecture.

8
When a user needs to grant OAuth access for a per-user (Named Principal) External Credential, where does this happen?
✓ Correct: B

Users with the appropriate Permission Set can authorize their per-user credential at Setup → Authentication Settings for External Systems. They click the External Credential entry and are redirected to the external system's OAuth consent screen.

9
Which certificate store does Salesforce use for JWT Bearer Token signing?
✓ Correct: B

For JWT Bearer flow, the private key/certificate is stored in Salesforce's Certificate and Key Management (Setup → Security → Certificate and Key Management). The External Credential references this certificate for signing JWT assertions.

10
What scope values should you include when configuring OAuth for a Salesforce-to-Salesforce integration?
✓ Correct: B

For Salesforce-to-Salesforce, api grants access to Salesforce REST/SOAP APIs, and refresh_token allows Salesforce to get new access tokens when the current one expires. The exact scopes depend on what the integration needs.
