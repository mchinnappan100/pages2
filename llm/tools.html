Automatic differentiation 

import jax


def f(x): return x ** 2 + 3 * x

df = jax.grad(f)

print(df(5.))
f(x) = x² + 3x
f′(x) = 2x + 3
f′(5) = 13

Vectorization 

import jax


def f(x): return x ** 2

vf = jax.vmap(f)

results = vf(xs)

Instead of manually writing a loop over inputs, vmap() transforms the function into a vectorized version.

The Big Picture

The Philosophical Difference

🔧

TensorFlow

Build and execute computational graphs for machine learning.

🔥

PyTorch

Write Python that manipulates tensors and trains neural networks.

⚡

JAX

Write mathematical functions and transform them with differentiation, compilation, vectorization, and parallelization.

What Should You Learn?

If your goal is modern LLM engineering, here's a practical path.

1

Learn PyTorch

Start with tensors, autograd, neural networks, optimizers, training loops, Transformers, and distributed training.

2

Learn JAX

Explore jnp, grad, jit, vmap, sharding, and XLA.

3

Learn TensorFlow

Learn enough TensorFlow and Keras to understand its ecosystem, production tooling, and deployment capabilities.
