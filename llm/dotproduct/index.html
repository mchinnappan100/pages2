UNDERSTANDING THE MATHEMATICS OF AI

Dot Products & Matrix Multiplication

The mathematical machinery behind Transformers, attention, embeddings, neural networks and Large Language Models.

Simple mathematical operations. Extraordinary computational possibilities.

01 · THE BIG PICTURE

Why should we care about matrix multiplication?

An LLM may contain billions of parameters, process thousands of tokens, and learn complicated language relationships. Yet a surprisingly large portion of its computational work comes down to multiplying matrices and calculating dot products.

Dot Product Combines corresponding dimensions using multiplication and addition.
Matrix Multiply Performs many dot products efficiently in parallel.
Tensor Organizes numerical information across multiple dimensions.
Transformer Uses these operations repeatedly to build contextual representations.
02 · THE FUNDAMENTAL OPERATION

What exactly is a dot product?

Consider two vectors. Multiply corresponding elements and add the results. That is a dot product.

A · B = Σ (Aᵢ × Bᵢ) = 37

The two vectors contain four dimensions each. The dot product combines those four pairs into one scalar value.

Important intuition: A dot product is a weighted combination of dimensions. It can measure alignment, similarity or compatibility, depending on what the vectors represent.
03 · MANY DOT PRODUCTS AT ONCE

Matrix multiplication: dot products at scale

A matrix multiplication is essentially a systematic collection of dot products. Every row of the first matrix is combined with every column of the second matrix.

C = A × B

Instead of calculating each result individually, GPUs can execute enormous numbers of these multiply-and-accumulate operations in parallel.

Why GPUs matter: Neural networks perform huge amounts of regular numerical work. GPUs are designed to process many such operations concurrently. Matrix multiplication is one of their most important workloads.
04 · YOUR DIMENSION IDEA

Can dot products add dimensions or attributes?

My intuition touches on one of the most powerful concepts in neural networks: transforming a representation into a richer set of learned features.

Start with an existing representation

Imagine these four numbers encode aspects of a word, a token, an image or some other input.

Apply a learned projection

[1 × 4] × [4 × 8] = [1 × 8]

Here, each of the eight output dimensions is a dot product between the input vector and one column of the weight matrix. The network has learned eight new feature combinations.

A useful distinction: Dot products do not inherently increase dimensionality. They produce scalar combinations. The weight matrix determines the number of output dimensions. In this example, four input dimensions become eight output dimensions through a learned linear projection.

Three ways neural networks handle dimensions

Projection Matrix multiplication transforms features into a new dimensional space.
Concatenation Joins representations along a dimension, explicitly increasing its size.
Elementwise Combines corresponding values without changing the tensor shape.
05 · THE TRANSFORMER CONNECTION

Dot products make attention possible

Transformers use dot products to decide which tokens should pay attention to which other tokens.

Consider this sentence

The cat sat on the mat because it was comfortable.

When processing the word "it", the model needs to establish relationships with other words in the sentence. Attention helps it construct contextual representations.

Queries, Keys and Values

Attention(Q,K,V) = softmax(QKᵀ / √dₖ)V

What is happening?

  1. Query: What information is this token looking for?
  2. Key: What information does another token offer?
  3. Dot product: How compatible are this query and key?
  4. Softmax: Convert scores into attention weights.
  5. Values: Combine information using those weights.
The key insight: Dot products help calculate relationships between tokens. Attention uses those relationships to mix information from across the sequence.
06 · FROM TOKENS TO TENSORS

Where do all these matrices come from?

A transformer converts token IDs into numerical embeddings. Those embeddings are organized into tensors and repeatedly transformed by learned matrices.

Every transformer block repeats a combination of projections, attention calculations, feed-forward transformations, normalization and residual connections.

07 · THE SHAPE OF THE COMPUTATION

Understanding tensor dimensions

Imagine a batch of 32 sequences, each containing 128 tokens, with an embedding size of 768.

X = [32, 128, 768]
DimensionMeaning
32Number of sequences in a batch
128Tokens per sequence
768Features representing each token

A projection matrix can transform each 768-dimensional token representation into a different feature space.

[32, 128, 768] × [768, 2304] = [32, 128, 2304]

This is one reason matrix multiplication is so fundamental: the same learned transformation is applied across every token and every sequence in the batch.

08 · WHY COMPUTE MATTERS

Why modern AI depends on GPUs and specialized hardware

CPU

Excellent for general-purpose logic, branching, operating systems and sequential workloads.

GPU

Designed for massive parallel computation, particularly matrix operations and tensor workloads.

TPU / Accelerators

Specialized architectures designed to accelerate machine-learning workloads.

Modern accelerators also use specialized low-precision arithmetic, high-bandwidth memory and optimized matrix multiplication kernels.

Important engineering connection: FlashAttention optimizes attention computation by reducing expensive data movement between memory levels while preserving the mathematical attention operation. It demonstrates that efficient LLMs require both mathematical insight and hardware-aware engineering.
09 · PUTTING IT ALL TOGETHER

One mathematical idea, many AI capabilities

Embeddings Represent tokens as numerical vectors.
Projection Learn new feature combinations and representations.
Attention Calculate token-to-token compatibility using dot products.
Feed-forward Transform representations through learned weight matrices and nonlinearities.
Training Update millions or billions of parameters using gradients.
Inference Execute learned transformations to predict the next token.
10 · FINAL THOUGHT

My perspective: simple operations, extraordinary intelligence

A dot product is a remarkably simple mathematical operation. It combines dimensions, calculates compatibility and produces weighted results.

Matrix multiplication scales this idea into thousands or millions of simultaneous transformations.

LLMs are built by repeatedly transforming numerical representations, learning relationships and combining information across dimensions.

Simple mathematics. Massive parallelism. Powerful intelligence.
