🔍 sfr data soql-builder

An interactive, browser-based SOQL query builder that launches a local axum server, discovers your org's schema live, and lets you compose queries visually — no SOQL syntax knowledge required.

Overview Usage UI Tour Shortcuts Flags Workflow Tips

Overview

sfr data soql-builder -o <alias> starts a lightweight local HTTP server and opens the builder in your default browser. The builder talks to Salesforce through sf-rust's own REST client — credentials never leave your machine.

  • Loads all queryable SObjects from /services/data/v{ver}/sobjects/
  • Fetches field metadata on demand via /sobjects/{name}/describe
  • Runs SOQL via /services/data/v{ver}/query with auto-pagination (up to 10 pages)
  • Renders results in a sortable HTML table with CSV and JSON export
  • Live SOQL preview updates as you click — fully editable before running

Usage

# Start on default port 7802
sfr data soql-builder -o dev1

# Custom port
sfr data soql-builder -o dev1 --port 9090

# Short alias
sfr     data soql-builder -o prod
Auto-open: The browser opens automatically on startup. If it doesn't, navigate to http://localhost:7802 (or your chosen port).

UI Tour

Left sidebar — SObject list

  • All queryable SObjects loaded on startup, sorted A–Z
  • Search box filters by API name and label in real time
  • Click any row to load its fields into the Fields panel

Fields panel

  • Checkboxes for every field; Id is pre-selected
  • All / None buttons to select/deselect all
  • Field type badge (string, date, reference, …) shown for each field
  • Search box filters field list instantly

WHERE builder

  • Click + Condition to add a row
  • Each row has: AND/OR logic (second row onward), field selector, operator, value input
  • Operators: =, !=, <, >, <=, >=, LIKE, NOT LIKE, IN, NOT IN, INCLUDES, EXCLUDES
  • String values are automatically quoted; booleans and dates are left unquoted
  • Remove a condition with the ✕ button

Options row

  • ORDER BY: sortable fields only; direction (ASC/DESC) and NULLS placement
  • LIMIT and OFFSET numeric inputs

SOQL preview bar

  • Rendered live as you interact with the builder
  • Fully editable — click and type to override any part of the generated SOQL
  • The edited SOQL is used as-is when you click ▶ Run

Results panel

  • Sticky header row; horizontal scroll for wide result sets
  • Record count and query time displayed in the toolbar
  • Hover any cell to see the full value in a tooltip

Typical Workflow

  1. Run sfr data soql-builder -o dev1 — browser opens at http://localhost:7802
  2. Search for and click an SObject (e.g. Account)
  3. Check the fields you want: Id, Name, Industry, AnnualRevenue
  4. Add a WHERE condition: Industry = 'Technology'
  5. Set ORDER BY AnnualRevenue DESC, LIMIT 50
  6. The SOQL preview updates live. Edit it if needed.
  7. Press ▶ Run (or Ctrl+Enter)
  8. Browse results; click ↓ CSV or ↓ JSON to export
  9. Click ⎘ Copy SOQL to copy the query for use elsewhere
  10. Press Ctrl+C in the terminal to stop the server

Tips & Notes

Pagination: The builder auto-paginates up to 10 Salesforce pages (up to ~20 000 records). For very large exports, prefer sfr data query --csv with --all.
Auto token refresh: If your session expires, the builder automatically POSTs grant_type=refresh_token to Salesforce, persists the new token to ~/.sf-rust/credentials.json, and retries the request — no manual re-login needed. The terminal prints [soql-builder] token refreshed when this happens. Only if the refresh itself fails (no refresh token stored) will an error appear — in that case re-authenticate with sfr org login web -o dev1.
IN / NOT IN values: Enter comma-separated values without parentheses — the builder wraps them automatically. Example: SFDC,Oracle,SAP becomes IN ('SFDC','Oracle','SAP').
Direct SOQL editing: Click the green SOQL preview bar to position the cursor and type. This is useful for adding sub-selects, aggregate functions (COUNT(), SUM(Amount)), or relationship traversal (Account.Name).
CORS: The server uses CorsLayer::permissive() (permissive for localhost dev only). Do not expose port 7802 to external networks.
