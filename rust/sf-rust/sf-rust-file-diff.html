Text diff

Unified diff with ANSI color output. Used for .cls, .sh, .md, and any extension not otherwise recognized. Context window is 3 lines.

bash
sf-rust file diff old.cls new.cls
sf-rust file diff --stat old.cls new.cls
sf-rust file diff --viz  old.cls new.cls
@@ diff @@
public static List<Vehicle__c> getActiveVehicles() {
return [
- SELECT Id, Name, Make__c, Status__c
+ SELECT Id, Name, Make__c, Model__c, Status__c, Color__c
FROM Vehicle__c
WHERE Status__c = 'Active'
- ORDER BY Name
+ ORDER BY Make__c, Name
];
+1 lines added -1 lines removed

JSON semantic diff

Key-order independent comparison. {"a":1,"b":2} and {"b":2,"a":1} are identical. Changes are reported as dot-notation paths starting from $.

bash
sf-rust file diff --semantic a.json b.json
sf-rust file diff --semantic --stat a.json b.json
sf-rust file diff --semantic --json a.json b.json
sf-rust file diff --semantic --viz  a.json b.json
~ $.sharingModel: "ReadWrite" → "Private"
+ $.enableActivities: true
- $.legacyField: "old value"
+1 added -1 removed ~1 changed

JSON output (--json)

json
[
  { "op": "change", "path": "$.sharingModel", "from": "ReadWrite", "to": "Private" },
  { "op": "add",    "path": "$.enableActivities", "value": true },
  { "op": "remove", "path": "$.legacyField", "value": "old value" }
]

XML structural diff

Auto-detected for .xml files. No flag needed.

  • Insignificant whitespace between elements is ignored
  • Attribute order is irrelevant — a="1" b="2" equals b="2" a="1"
  • Changes reported as XPath-like paths: CustomObject/fields[0]/length
  • Attribute changes: Root[@version]
bash
sf-rust file diff Vehicle__c-v1.xml Vehicle__c-v2.xml
sf-rust file diff --stat Vehicle__c-v1.xml Vehicle__c-v2.xml
sf-rust file diff --json Vehicle__c-v1.xml Vehicle__c-v2.xml
sf-rust file diff --viz  Vehicle__c-v1.xml Vehicle__c-v2.xml
~ CustomObject/fields[0]/length text: "100" → "255"
~ CustomObject/sharingModel text: "ReadWrite" → "Private"
+ CustomObject/fields[4]
+1 added -0 removed ~2 changed

Salesforce metadata types

Tested against: CustomObject, CustomField, Layout, Profile, PermissionSet, ApexClass meta, CustomLabels, Workflow, FlexiPage, and any well-formed XML.

CSV diff

Auto-detected for .csv files. Column-order independent — the same data in a different column order is treated as identical. By default rows are matched positionally; use --key for field-based alignment.

bash
# Positional (default)
sf-rust file diff before.csv after.csv

# Key-field row alignment
sf-rust file diff --key Id before.csv after.csv

# Counts only
sf-rust file diff --key Id --stat before.csv after.csv

# Monaco visual diff
sf-rust file diff --viz before.csv after.csv
+ row: Id=4, Name=Dave, Score=95
~ 2
Score: "75" → "80"
+0 cols -0 cols +1 rows -0 rows ~1 rows

JSON output (--json)

json
{
  "schema": [],
  "rows": [
    { "op": "add",    "row": { "Id": "4", "Name": "Dave", "Score": "95" } },
    { "op": "change", "key": "2",
      "fields": [{ "column": "Score", "from": "75", "to": "80" }] }
  ]
}

Directory diff

Auto-detected when either argument is a directory. Walks both trees recursively, matches files by relative path, and dispatches each changed file to the right per-file engine.

bash
# File list (default)
sf-rust file diff force-app-v1/ force-app-v2/

# Inline per-file diff bodies
sf-rust file diff --expand force-app-v1/ force-app-v2/

# Counts only
sf-rust file diff --stat force-app-v1/ force-app-v2/

# Machine-readable
sf-rust file diff --json force-app-v1/ force-app-v2/

# Browser sidebar + Monaco
sf-rust file diff --viz force-app-v1/ force-app-v2/
- main/default/classes/LegacyMigrationHelper.cls
+ main/default/classes/VehicleRetireController.cls
~ main/default/classes/VehicleService.cls
~ main/default/classes/VehicleService.cls-meta.xml
~ main/default/objects/Vehicle__c/Vehicle__c.object-meta.xml
~ main/default/permissionsets/Vehicle_Manager.permissionset-meta.xml
+2 added -2 removed ~8 changed 2 identical
