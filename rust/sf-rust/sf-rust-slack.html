sfr slack New

Post messages to Slack channels via an incoming webhook. No OAuth tokens, no Slack app credentials — just a webhook URL. Pipe any command output directly to Slack for instant notifications.

Overview

sfr slack post sends a message to a Slack channel using Slack's Incoming Webhook API. It supports plain text messages, custom usernames, icon emojis, and optionally reading the message from stdin.

Webhook URL: Create an Incoming Webhook in your Slack workspace under Apps → Incoming WebHooks and copy the generated URL. Pass it via --webhook-url or the SLACK_WEBHOOK_URL environment variable.

Subcommands

SubcommandDescription
postPost a message to a Slack channel via incoming webhook

sfr slack post — Flags

FlagShortDescription
--webhook-url-wSlack Incoming Webhook URL (or set SLACK_WEBHOOK_URL)
--message-mMessage text to post (omit to read from stdin)
--usernameBot display name (default: sf-rust)
--icon-emojiEmoji for bot avatar (default: :rocket:)

Examples

Post a plain text message

sfr slack post \
  --webhook-url https://hooks.slack.com/services/T.../B.../... \
  --message "Deploy to production completed successfully"

Use environment variable for webhook URL

export SLACK_WEBHOOK_URL=https://hooks.slack.com/services/T.../B.../...
sfr slack post -m "Org backup finished"

Pipe command output to Slack

sfr data query -q "SELECT Id, Name FROM Account LIMIT 5" -o dev1 \
  | sfr slack post -w "$SLACK_WEBHOOK_URL"

Custom bot name and emoji

sfr slack post \
  --webhook-url "$SLACK_WEBHOOK_URL" \
  --message "Deployment pipeline triggered" \
  --username "sfr-bot" \
  --icon-emoji ":gear:"

Post Apex test results to Slack

sfr apex test run -o dev1 --result-format human 2>&1 \
  | sfr slack post -w "$SLACK_WEBHOOK_URL" --username "apex-ci" --icon-emoji ":test_tube:"

Notify on deploy completion

sfr metadata deploy -d force-app -o prod \
  && sfr slack post -w "$SLACK_WEBHOOK_URL" -m "prod deploy succeeded" \
  || sfr slack post -w "$SLACK_WEBHOOK_URL" -m "prod deploy FAILED"

Setup: Create a Slack Incoming Webhook

  1. Go to your Slack workspace → Apps → search Incoming WebHooks
  2. Click Add to Slack, choose a channel, then Add Incoming WebHooks integration
  3. Copy the Webhook URL (starts with https://hooks.slack.com/services/)
  4. Store it as SLACK_WEBHOOK_URL in your shell profile or pass it via --webhook-url

Implementation Notes

  • Uses Slack's Incoming Webhooks API — no OAuth, no bot token
  • Message payload: { "text": "...", "username": "...", "icon_emoji": "..." }
  • Reads from stdin when --message is omitted — works as a pipe sink
  • HTTP POST via reqwest (native TLS, no OpenSSL required)
  • Returns a non-zero exit code on HTTP error so && / || shell chaining works
Tip: Combine with sfr cron to schedule periodic Salesforce status summaries posted to Slack automatically.
