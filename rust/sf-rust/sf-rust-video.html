Overview

sf-rust video is a thin, ergonomic wrapper around ffmpeg and ffprobe. It handles the most common media tasks a developer or content creator needs: converting between formats, cleaning up noisy audio, and quickly inspecting what's inside a media file — all from one familiar CLI.

🔄
Convert
webm → gif, any video → mp4, extract audio as mp3, or combine a static image + audio track into an mp4 slideshow.
🎙️
Denoise
Remove background hiss and hum from recordings with the ffmpeg afftdn filter. Three strength presets: low, medium, high.
🔍
Info
Probe any media file with ffprobe and show codec, resolution, duration, sample rate, and channel count in a table or datatable.

video convert

Two modes:

  • File conversion — --input + --format
  • Slideshow — --image + --audio → mp4

webm → gif (screen recording)

sf-rust video convert --input recording.webm --format gif # default framerate: 2 fps — good for silent screencasts sf-rust video convert --input recording.webm --format gif --framerate 5 # higher framerate for smoother motion # equivalent ffmpeg command: ffmpeg -i recording.webm -r 2 recording.gif

webm / any video → mp4

sf-rust video convert --input input.webm --format mp4 # default CRF 26 — good quality / size balance sf-rust video convert --input input.webm --format mp4 --crf 18 # lower CRF = higher quality, larger file sf-rust video convert --input input.mp4 --format mp4 --output compressed.mp4 --crf 32 # re-encode to smaller file # equivalent ffmpeg command: ffmpeg -i input.webm -crf 26 input.mp4

Extract audio track as mp3

sf-rust video convert --input meeting.mp4 --format mp3 # extracts audio track at best quality (-q:a 0) sf-rust video convert --input meeting.mp4 --format mp3 --output meeting_audio.mp3

Image + Audio → mp4 (slideshow / podcast cover)

sf-rust video convert \ --image cover.jpg \ --audio narration.mp3 \ --output podcast.mp4 # default output name: narration_slideshow.mp4 sf-rust video convert --image cover.png --audio talk.mp3 # equivalent ffmpeg command: ffmpeg -loop 1 -i cover.jpg -i narration.mp3 \ -c:v libx264 -tune stillimage -c:a aac -b:a 192k \ -pix_fmt yuv420p -shortest podcast.mp4

video denoise

Applies ffmpeg's afftdn (Audio FFT Denoiser) filter to reduce steady-state background noise like fan hum, room noise, or recording hiss.

# medium strength (default) — good for most recordings sf-rust video denoise --input recording.mp3 # output: recording_clean.mp3 sf-rust video denoise --input recording.mp3 --strength high # aggressive — good for very noisy recordings sf-rust video denoise --input recording.mp3 --output podcast_ep1_clean.mp3 sf-rust video denoise --input meeting.wav --strength low # low strength preserves more audio detail # equivalent ffmpeg command: ffmpeg -i recording.mp3 -af "afftdn=nf=-25" recording_clean.mp3

Strength presets

StrengthNoise floor (nf)Best for
low-15 dBLightly noisy recordings, preserve audio fidelity
medium-25 dBTypical room noise, fan hum — most recordings
high-40 dBHeavy background noise, outdoor recordings
Tip: afftdn works best on consistent background noise (fans, HVAC, electrical hum). For intermittent noise (traffic, keyboard), try high strength.

video info

Calls ffprobe under the hood and presents stream metadata in a clean terminal table. Supports --json for raw output and --datatable to open in the browser.

# terminal table (default) sf-rust video info --input recording.webm # raw ffprobe JSON sf-rust video info --input recording.mp4 --json # open in browser datatable sf-rust video info --input podcast.mp3 --datatable # equivalent ffprobe command: ffprobe -v quiet -print_format json -show_streams -show_format recording.webm

Info table columns

ColumnDescription
TypeStream type: video or audio
CodecCodec name, e.g. vp8, h264, aac
ResolutionWidth × Height for video streams
Duration (s)Stream duration in seconds
Sample RateAudio sample rate in Hz
ChannelsNumber of audio channels (1=mono, 2=stereo)

Full examples

Screen recording workflow (webm → gif for README)

# 1. Record your screen → recording.webm # 2. Convert to gif at 2fps sf-rust video convert -i recording.webm -f gif # → recording.gif

Podcast / narration workflow

# 1. Denoise raw recording sf-rust video denoise -i episode1_raw.mp3 --strength medium # → episode1_raw_clean.mp3 # 2. Create mp4 with podcast artwork for YouTube sf-rust video convert \ --image artwork.jpg \ --audio episode1_raw_clean.mp3 \ --output episode1.mp4 # 3. Inspect the result sf-rust video info -i episode1.mp4

Meeting recording — extract audio

sf-rust video convert -i meeting.mp4 -f mp3 sf-rust video denoise -i meeting.mp3 --strength high
