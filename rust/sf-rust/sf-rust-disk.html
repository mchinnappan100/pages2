Overview

sf-rust disk scan walks any directory recursively with walkdir, collects files matching your size and age filters, and presents them sorted largest-first. Inspired by diskclean-cli — ported to native Rust with zero runtime dependencies.

📋
Terminal table
Default output: UTF8_FULL comfy-table with path, size, age (days), modified date, and file type columns.
📊
HTML report
Full browser report: KPI tiles, Chart.js doughnut (types by size) + bar (age buckets), sortable file table, bash cleanup script.
📄
CSV export
Saves path, size (bytes + human), modified date, age in days, and extension to a CSV file for further analysis.
🌐
Datatable view
--datatable opens results in an sf-output HTML datatable in the browser — sortable, filterable, searchable.
🧹
Cleanup script
Every HTML report includes a copy-to-clipboard bash script with per-file confirmation prompts and a freed-space summary.
🛡️
Safe by design
Validates directory existence before scanning. Clear error message when path is not found. No silent empty results.

Flags

FlagShortDefaultDescription
--directory <PATH>-d~Directory to scan (tilde expanded)
--min-size <MB>-s10Minimum file size in megabytes
--older-than <MONTHS>-o0 (all)Only files older than N months (0 = no age filter)
--limit <N>-l100Maximum number of files in output
--html <FILE>——Save full HTML report with Chart.js; auto-opens in browser
--csv <FILE>——Save CSV export (path, size bytes, size human, modified, age, ext)
--datatable——Open results in sf-output HTML datatable in the browser
Tip: --html, --csv, and terminal table output can all run together in one command. --datatable skips the terminal table and opens the browser instead.

Examples

bash — basic scans
# Default: scan home dir, files ≥10MB, table output
sf-rust disk scan

# Scan Downloads folder (files ≥10MB, default)
sf-rust disk scan -d ~/Downloads

# Lower threshold — find files ≥1MB
sf-rust disk scan -d ~/Downloads -s 1

# Only files larger than 500MB
sf-rust disk scan -d ~ --min-size 500

# Files older than 6 months
sf-rust disk scan -d ~/Documents --older-than 6

# Top 50 largest files in home
sf-rust disk scan -d ~ -l 50
bash — HTML and CSV reports
# Full HTML report (auto-opens in browser)
sf-rust disk scan -d ~/Downloads --html /tmp/disk-report.html

# CSV export for spreadsheet analysis
sf-rust disk scan -d ~ -s 50 --csv ~/disk-large-files.csv

# Both HTML and CSV in one pass
sf-rust disk scan -d ~/Downloads -s 1 \
  --html /tmp/disk-report.html \
  --csv /tmp/disk-report.csv

# Targeted: 100MB+, older than 1 year, top 200
sf-rust disk scan -d ~ -s 100 -o 12 -l 200 \
  --html /tmp/old-large.html
bash — datatable and filtering
# Open as interactive browser datatable (sortable/filterable)
sf-rust disk scan -d ~/Downloads --datatable

# Scan specific project directory
sf-rust disk scan -d ~/projects/my-app -s 5 --datatable

# Large video files older than 3 months
sf-rust disk scan -d ~/Movies --older-than 3 --datatable

Cleanup Script

Every --html report includes a bash cleanup script you can copy and run. Each file prompts individually before deletion:

bash — generated cleanup script (excerpt)
#!/usr/bin/env bash
# sf-rust disk cleanup script — generated by sf-rust disk scan
set -euo pipefail

size=$(stat -f%z '/Users/you/Downloads/old-backup.zip' 2>/dev/null || echo 0)
read -rp "Delete '/Users/you/Downloads/old-backup.zip' (540.0 MB)? [y/N] " ans
if [[ "$ans" =~ ^[Yy]$ ]]; then
  rm -f '/Users/you/Downloads/old-backup.zip' && echo "  Deleted"
fi

# ... (one block per file)

echo "Done. Freed approximately $((freed / 1048576)) MB."
