sfr os memory

RAM and swap usage at a glance — colored pressure bars, GiB display, animated HTML dashboard. Powered by the sysinfo crate. No Node.js, no shell scripts.

sysinfo crate ASCII pressure bar --json --datatable swap pressure cross-platform

Quick Start

# Terminal table with colored pressure bars
sfr os memory

# JSON output (for scripting / piping)
sfr os memory --json

# Open interactive HTML dashboard in browser
sfr os memory --datatable

Flags

Implementation Notes

sysinfo crate

Uses sysinfo = "0.32" with MemoryRefreshKind::everything(). On macOS, available_memory() returns 0 (the OS uses compressed memory and wired pages in ways sysinfo can't expose); the implementation falls back to free_memory() in that case.

// macOS quirk: available_memory() returns 0; fall back to free
let available = {
    let a = sys.available_memory();
    if a > 0 { a } else { sys.free_memory() }
};

ASCII Bar

fn make_bar(pct: u64, width: usize) -> String {
    let filled = (pct as usize * width / 100).min(width);
    let empty  = width - filled;
    format!("{}{}", "█".repeat(filled), "░".repeat(empty))
}
