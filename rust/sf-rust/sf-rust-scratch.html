🧪 sf-rust scratch

Manage Salesforce Scratch Orgs via the Tooling API (ScratchOrgInfo). Requires a Dev Hub org.

3
subcommands
Tooling
API
ScratchOrgInfo
object

Status is color-coded in the terminal: Active ✓ in green, Deleted ✗ in red. Connect to your Dev Hub org with -o.

list — Show all scratch orgs

sfr scratch list -o devhub sfr scratch list -o devhub --json sfr scratch list -o devhub --datatable

Output columns: OrgName, SignupUsername, Status, ExpirationDate, Edition, Features. Sorted by ExpirationDate descending.

ColumnDescription
OrgNameHuman-readable name of the scratch org
SignupUsernameUsername generated for the scratch org
StatusActive / Deleted / Expired (color-coded)
ExpirationDateWhen the scratch org expires
EditionDeveloper, Enterprise, etc.
FeaturesComma-separated feature flags

info — Show details of one scratch org

Look up by SignupUsername or by Name.

sfr scratch info "john-scratch@example.com" -o devhub sfr scratch info "My Scratch Org" -o devhub sfr scratch info "john-scratch@example.com" -o devhub --json sfr scratch info "john-scratch@example.com" -o devhub --datatable

delete — Soft-delete a scratch org

Looks up the ScratchOrgInfo record by SignupUsername, then deletes it via the Tooling API. Prompts for confirmation unless --no-prompt is passed.

sfr scratch delete "john-scratch@example.com" -o devhub sfr scratch delete "john-scratch@example.com" -o devhub --no-prompt sfr scratch delete "john-scratch@example.com" -o devhub --json
Note: Scratch org deletion is irreversible. The org and all its data will be permanently removed.
Tip: To see active orgs approaching expiry: sfr scratch list -o devhub --json | jq '.records[] | select(.Status == "Active")'
