sf-rust map geocodes any place name via Nominatim (OpenStreetMap's free geocoder) then generates a self-contained interactive HTML map using Leaflet.js and ESRI World Street Map tiles — no account, no API key, no config needed. The page opens instantly in your default browser with a named marker and popup.

Unlike sf-rust weather which uses city-level geocoding, sf-rust map uses Nominatim which resolves specific landmarks — "Eiffel Tower", "Taj Mahal", "Colosseum", "Salesforce Tower" — in addition to cities, streets, and administrative areas.

The generated HTML page is completely self-contained. ESRI public tiles are used so the map renders correctly from a local file:// URL with no API key required.

How to use

Cities

# Any city — opens interactive map in browser sf-rust map --place "Chennai" sfr map -p "Tokyo" sfr map -p "San Francisco" --zoom 13

Landmarks

# Specific landmarks worldwide sfr map -p "Eiffel Tower" sfr map -p "Taj Mahal" sfr map -p "Colosseum" sfr map -p "Salesforce Tower" sfr map -p "Grand Canyon" --zoom 11

JSON — coordinates for scripting

sfr map -p "Taj Mahal" --json { "name": "Taj Mahal", "display": "Taj Mahal, Taj East Gate Road, Taj Ganj, Agra, Uttar Pradesh, 282004, India", "latitude": 27.1750075, "longitude": 78.0421013, "country": "India" } # Pipe to jq sfr map -p "Eiffel Tower" --json | jq '.latitude,.longitude'

Geocoding — Nominatim

Nominatim is OpenStreetMap's free geocoding API. It covers cities, countries, streets, postal codes, and specific named places (landmarks, parks, buildings, universities). Unlike weather-focused geocoders it resolves landmarks directly.

ESRI World Street Map server.arcgisonline.com/ArcGIS/rest/services/World_Street_Map/ Map tiles — works from local file:// URLs None

The generated HTML file is fully self-contained except for the CDN tile requests (Leaflet + ESRI tiles). An internet connection is required when the page is opened in a browser.
