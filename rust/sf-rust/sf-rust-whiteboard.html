◼ sf-rust · Whiteboard

Interactive concept whiteboard — served locally, opens in any browser

v0.4.0

Quick Start

sfr whiteboard # opens on http://localhost:7778 sfr whiteboard --port 8080 # custom port

The browser opens automatically. Press Ctrl-C in the terminal to stop the server.

Features

✏️

Freehand Pen

Smooth freehand strokes with round caps. Variable stroke width.

▭ ○ → ╱

Shapes

Rectangle, circle/ellipse, line, and arrow — drag to draw any size.

T

Text Labels

Click anywhere to place text. Shift+Enter for multiline. Enter to commit.

📌

Sticky Notes

5 pastel colors, draggable by header, editable text, × to dismiss.

◻

Eraser

Large-radius eraser using canvas destination-out compositing.

↩↪

Undo / Redo

50-step snapshot history. Ctrl+Z to undo, Ctrl+Y to redo.

💾

Save as PNG

Flattens canvas + sticky notes into a single PNG. Named from the board title.

🎨

10 Colors + 3 Widths

Blue, green, red, yellow, purple, orange, sky, white, gray, rose. Thin / medium / thick.

Use Cases

  • Sketch architecture diagrams or data-flow charts during a code review
  • Map out SOQL query relationships with boxes and arrows
  • Plan a Salesforce deployment with sticky notes per metadata type
  • Wireframe a Lightning page layout before building it
  • Brainstorm automation flows (triggers → process → flow → email)
  • Draw an org structure for a multi-org migration
  • Annotate a screenshot pasted as a sticky note

Implementation

# Crate: crates/sf-whiteboard/src/lib.rs # Embeds ~350-line self-contained HTML/JS/CSS whiteboard app as a Rust const # Serves via minimal std::net::TcpListener (zero extra dependencies) # Browser opened with the open crate (same as sfr voice-record) # Default port: 7778 (voice-record uses 7777)
