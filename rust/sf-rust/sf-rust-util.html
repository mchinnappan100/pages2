📱 sfr qr — QR code generator

Generates a QR code from any text or URL. Outputs Unicode ASCII art directly in the terminal, or saves a pixel-perfect PNG via the qrcode crate.

Basic usage

sfr qr "https://github.com/sf-rust" # ASCII art in terminal sfr qr "https://my-org.lightning.force.com" -o org-link.png sfr qr "hello world" --size 20 # 20px per module sfr qr "secret" --ec H --invert # high error-correction, white-on-black sfr qr "open me" -o qr.png --open # save + open in viewer

Flags

--output FILE-o—Save as PNG instead of printing ASCII art

# sfr hash — file and string hashing

Compute MD5, SHA-256, or SHA-512 digests for files, literal strings, or stdin. Pure Rust — md-5 and sha2 crates, no openssl dependency.

Examples

sfr hash deploy.zip # SHA-256 (default) sfr hash deploy.zip --algo md5 sfr hash deploy.zip --algo sha512 sfr hash deploy.zip --all # print MD5 + SHA-256 + SHA-512 sfr hash --text "hello world" # hash a literal string sfr hash --text "hello world" --algo md5 cat cert.pem | sfr hash # hash stdin (SHA-256)
$ sfr hash --text "hello world" --all --no-time MD5 5eb63bbbe01eeed093cb22bb8f5acdc3 SHA-256 b94d27b9934d3e08a52e52d7da7dabfac484efe37a5380ee9088f7ace2efcde9 SHA-512 309ecc489c12d6eb4cc40f50c902f2b4d0ed77ee511a7c7a9bcd3ca86d4cd86f989dd35bc5ff499670da34255b45b0cfd830e81f605dcf7dc5542e93ae9cd76f

Flags

FlagShortDefaultDescription
FILE—stdinFile to hash (omit to use --text or stdin)
--text TEXT-t—Hash a literal string
--algo ALGO-asha256md5 · sha256 · sha512
--all—offPrint all three algorithms at once

🔐 sfr encode — base64 · URL · hex

Three encoding subcommands in one command — no python3 -c or openssl enc required.

Base64

sfr encode base64 --text "sf-rust rocks" # → c2YtcnVzdCByb2Nrcw== sfr encode base64 --text "c2YtcnVzdCByb2Nrcw==" --decode sfr encode base64 cert.pem # encode file sfr encode base64 cert.pem --decode # decode file sfr encode base64 --text "data" --url-safe --no-pad # JWT-style

URL percent-encoding

sfr encode url "SELECT Id FROM Account WHERE Name='Acme'" # → SELECT%20Id%20FROM%20Account%20WHERE%20Name%3D%27Acme%27 sfr encode url "SELECT%20Id%20FROM%20Account" --decode

Hex

sfr encode hex --text "sf-rust" # → 73662d72757374 sfr encode hex --text "73662d72757374" --decode sfr encode hex binary.bin # hex-dump a binary file
$ sfr encode base64 --text "sf-rust rocks" --no-time c2YtcnVzdCByb2Nrcw== $ sfr encode url "SELECT Id FROM Account WHERE Name='Acme'" --no-time SELECT%20Id%20FROM%20Account%20WHERE%20Name%3D%27Acme%27 $ sfr encode hex --text "sf-rust" --no-time 73662d72757374

base64 flags

FlagShortDescription
FILE—File to encode/decode (or use --text or stdin)
--text TEXT-tEncode/decode a literal string
--decode-dDecode instead of encode
--url-safe—URL-safe alphabet (- and _ instead of + and /)
--no-pad—Omit = padding (useful for JWT)

{} sfr json — query · pretty-print · validate

jq-like dot-path queries on JSON files or stdin, plus pretty-print, minify, and validation — all using serde_json, no external jq binary required.

Pretty-print and validate

sfr json data.json # pretty-print sfr json data.json --minify # compact single line sfr json data.json --validate # exit 0 if valid, 1 if not cat response.json | sfr json # pretty-print stdin

Dot-path queries

# Object field sfr json -q ".name" data.json # Nested field sfr json -q ".address.city" data.json # Array index (0-based, negative from end) sfr json -q ".records[0].Id" data.json sfr json -q ".items[-1]" data.json # last element # Iterate all array elements, extract a field sfr json -q ".records[].Name" data.json # Built-in functions sfr json -q "length" data.json # number of keys / array length sfr json -q "keys" data.json # array of object keys sfr json -q "values" data.json # array of object values sfr json -q "type" data.json # "object" | "array" | "string" | … # Raw string output (no JSON quotes) sfr json -q ".name" -r data.json # Top-level keys shorthand sfr json --keys data.json
$ echo '{"name":"Mohan","items":[10,20,30]}' | sfr json -q ".items[1]" --no-time 20 $ echo '{"name":"Mohan","items":[10,20,30]}' | sfr json --keys --no-time [ "name", "items" ] $ echo '{"name":"Mohan","items":[10,20,30]}' | sfr json -q ".items[].length" --no-time 2 2 2 $ sfr json --validate bad.json 2>&1 Error: Invalid JSON: expected `,` or `}` at line 3 column 1

Supported query syntax

SyntaxMeaning
.Identity — return the whole document
.keyObject field
.key.nestedChained field access
.[N]Array index (0-based; negative counts from end)
.[]Iterate all array elements (or object values)
.key[]Field then iterate (e.g. .records[].Name)
lengthString length / array length / object key count
keysObject keys as an array (or array indices)
valuesObject values as an array
typeType name: null · boolean · number · string · array · object

json flags

FlagShortDescription
FILE—JSON file (omit to read from stdin)
--query PATH-qDot-path query or built-in function
--keys—List top-level object keys (or array length)
--minify—Output compact/minified JSON
--validate—Validate only — exit 0 valid, 1 invalid
--raw-rOutput raw strings without JSON quotes

📊 barcode — 1-D barcode generator

Generate standard 1-D barcodes as ASCII art in the terminal, PNG images (via resvg), or SVG files. Human-readable label text is printed automatically below the bars in every output format. Pure Rust — no ImageMagick, no GhostScript, no Java.

Supported symbologies

FlagSymbologyInput
code128 (default)Code 128 (all printable ASCII, uppercase + lowercase)Any text
code39Code 39Uppercase A-Z, 0-9, space, - . $ / + %
code93Code 93Uppercase A-Z, 0-9, space, - . $ / + %
ean13EAN-13 (product barcodes)12 digits — check digit auto-computed
ean8EAN-8 (small product barcodes)7 digits — check digit auto-computed
itfITF (Interleaved 2 of 5)Numeric digits only

Basic usage

# ASCII art in terminal (default Code 128) sfr barcode "HELLO WORLD" # EAN-13 product barcode (12 digits; 13th check digit is auto-added) sfr barcode "750103131130" -t ean13 # EAN-8 (7 digits) sfr barcode "1234567" -t ean8 # Code 39 (uppercase) sfr barcode "SFRUST-2026" -t code39 # ITF (numeric only) sfr barcode "123456789012" -t itf

Save to PNG or SVG

# PNG — rasterised via resvg (label text rendered cleanly) sfr barcode "HELLO WORLD" -o barcode.png # SVG — vector, label as a <text> element sfr barcode "750103131130" -t ean13 -o product.svg # Open immediately after save sfr barcode "SFRUST" -o barcode.png --open

Sizing & label options

# Taller bars (default 80px) sfr barcode "HELLO" -o barcode.png --height 120 # Wider bars (xdim = narrow-bar width; default 2) sfr barcode "HELLO" -o barcode.png --xdim 3 # Suppress human-readable label below the bars sfr barcode "HELLO" -o barcode.png --no-label # Taller ASCII art (default 10 lines) sfr barcode "HELLO" --ascii-height 15

All flags

FlagDefaultDescription
-t / --barcode-typecode128Symbology: code128 | code39 | code93 | ean13 | ean8 | itf
-o / --output—Save to file (.png → PNG, .svg → SVG). Prints ASCII art if omitted.
--height80Bar height in pixels (PNG/SVG)
--xdim2Narrow-bar width — pixels (PNG/SVG) or characters (ASCII)
--ascii-height10Height of ASCII art in lines
--no-labeloffSuppress human-readable text below bars
--openoffOpen saved file (requires --output)

🔑 sfr jwt — JWT token inspector

Decode and inspect any JWT token without verifying the signature. Displays the header and payload claims in a readable table, converts exp / iat / nbf timestamps to human dates, and flags expired tokens in red.

Basic usage

# Decode a JWT — shows header + payload with expiry status sfr jwt eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9.eyJzdWIiOiIxMjM0NTY3ODkwIiwibmFtZSI6IkpvaG4gRG9lIiwiaWF0IjoxNTE2MjM5MDIyfQ.SflKxwRJSMeKKF2QT4fwpMeJf36POk6yJV_adQssw5c # Output raw JSON (pipe-friendly) sfr jwt "$TOKEN" --json # Grab expiry epoch with jq sfr jwt "$TOKEN" --json | jq '.payload.exp' # Show raw decoded JSON (header + payload, no formatting) sfr jwt "$TOKEN" --raw

All flags

FlagDescription
TOKENJWT string (header.payload.signature)
--rawOutput raw decoded JSON (header + payload)
-j / --jsonOutput as structured JSON
💡 Salesforce use-case: paste your Connected App JWT Bearer token to verify iss, sub, aud, and check whether the token has expired — without opening jwt.io.

🆔 sfr uuid — UUID generator

Generate UUIDs in two versions: v4 (cryptographically random) and v7 (time-ordered, lexicographically sortable — ideal for database primary keys). Pure Rust via the uuid crate.

Basic usage

# One v4 UUID (default) sfr uuid # Generate 5 UUIDs at once sfr uuid -n 5 # v7 time-ordered UUID (sortable, good for DB primary keys) sfr uuid -V 7 # Uppercase, no hyphens sfr uuid --upper --no-hyphens # Batch generate 10 sortable IDs for a migration script sfr uuid -V 7 -n 10

All flags

FlagDefaultDescription
-V / --version4UUID version: 4 (random) or 7 (time-ordered)
-n / --count1Number of UUIDs to generate
-u / --upperoffOutput in uppercase
--no-hyphensoffRemove hyphens (outputs 32 hex chars)

📅 sfr date — date/time utilities

Five subcommands covering the most common date/time tasks: show the current time in multiple formats, convert between epoch and ISO 8601, calculate the difference between two timestamps, humanize a timestamp, and add or subtract durations. Uses the chrono crate.

Subcommands

SubcommandWhat it does
nowShow current time — UTC, local, epoch, ISO 8601, epoch ms
convert <VALUE>Auto-detect epoch/ISO input and show both formats
diff <FROM> <TO>Difference between two timestamps (days/hours/mins/secs + human)
humanize <VALUE>"3 days ago" / "in 2 weeks" for any timestamp
add <DATE> <DURATION>Add/subtract duration (2d, 3h, 30m, 1w, 10s). Use now as date.

Examples

# Current time in all formats sfr date now # Convert epoch to ISO 8601 (and vice versa) sfr date convert 1700000000 sfr date convert 2024-01-15T09:30:00Z # How many days between two dates? sfr date diff 2024-01-01 2024-12-31T23:59:59Z # How long ago was this timestamp? sfr date humanize 1700000000 # What is the date 90 days from now? sfr date add now 90d # What was the time 6 hours ago? sfr date add now -6h

🔒 sfr password — secure password generator

Generate cryptographically secure random passwords using the rand crate's thread_rng. Configurable length, count, and character classes — uppercase, lowercase, digits, symbols.

Basic usage

# 16-character password (default) sfr password # 32-character password sfr password -l 32 # Generate 5 passwords at once sfr password -n 5 # Alphanumeric only (no symbols) sfr password --no-symbols # Digits only (useful for PINs) sfr password --no-upper --no-lower --no-symbols -l 6 # Custom symbol set sfr password --symbols '!@#$' -l 20

All flags

FlagDefaultDescription
-l / --length16Password length
-n / --count1Number of passwords to generate
--no-upperoffExclude uppercase letters A-Z
--no-loweroffExclude lowercase letters a-z
--no-digitsoffExclude digits 0-9
--no-symbolsoffExclude symbols
--symbols!@#$%^&*()-_=+[]{}|;:,<>?Custom symbol set

.* sfr regex — regex tester

Test regular expressions against input text with colored match highlighting, capture group extraction, invert mode, and line counts. Reads from an inline argument, a file (--file), or stdin. Uses the regex crate.

Basic usage

# Test a pattern against inline text sfr regex '[0-9]+' "order 42 ships in 3 days" # Pipe from another command sfr data query -q "SELECT Name FROM Account" -o dev1 --csv | sfr regex 'Tech' # Case-insensitive sfr regex -i 'hello' -f greetings.txt # Show only non-matching lines sfr regex --invert '^\s*$' -f data.csv # Count matching lines only sfr regex -c 'ERROR' -f app.log # Show named capture groups sfr regex --captures '(?P<year>\d{4})-(?P<month>\d{2})' "event: 2024-11" # Multiline mode (^ and $ match line boundaries) sfr regex -m '^SELECT' -f queries.soql

All flags

FlagDefaultDescription
PATTERN—Regular expression pattern
INPUTstdinInput text (optional positional argument)
-f / --file—Read input from file (line by line)
-i / --ignore-caseoffCase-insensitive matching
-m / --multilineoff^ and $ match line boundaries
--invertoffShow only lines that do NOT match
-c / --countoffPrint only the count of matching lines
--capturesoffPrint numbered and named capture groups per match
