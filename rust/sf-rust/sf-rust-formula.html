🔢 sfr formula

List formula fields on any sObject, or evaluate a formula field expression against a live record

📋
--list
▶
--formula

sfr formula has two modes. Use --list to discover formula fields on an sObject — it queries the FieldDefinition Tooling API object and returns every field whose CalculatedFormula is non-null. Use --formula to evaluate an existing formula field (or any SOQL-valid expression) against a live record — useful for testing before or after field changes.

Tip: --formula must be a name or expression that is valid in a SOQL SELECT clause. For arbitrary formula testing, use sfr apex execute with System.debug().

📋 sfr formula --list

List all formula fields on a given sObject. Uses the Tooling API FieldDefinition object — no Apex, no describe overhead.

Usage

sfr formula --sobject Account --list -o dev1 sfr formula --sobject Opportunity --list -o dev1 sfr formula --sobject Contact --list -o dev1 --json sfr formula --sobject Account --list -o dev1 --csv sfr formula --sobject Account --list -o dev1 --datatable

▶ sfr formula --formula

Evaluate a formula field (or any SOQL-valid expression) against a live record. Useful for checking that a formula returns the expected value for a specific record before deploying a change.

Usage

# by record Id sfr formula --sobject Account --formula "BillingState" \ --record-id "0011a000005xxxAAA" -o dev1 # find a record by WHERE clause sfr formula --sobject Account --formula "BillingState" \ --where-clause "Name = 'Acme'" -o dev1 # use first available record (no record-id or where-clause) sfr formula --sobject Opportunity --formula "Amount * 0.1" -o dev1 # custom formula fields sfr formula --sobject Opportunity --formula "Discount_Pct__c" \ --where-clause "Name = 'Big Deal'" -o dev1 # output as JSON sfr formula --sobject Account --formula "BillingState" \ --where-clause "Name = 'Acme'" -o dev1 --json

Options

FlagDescription
--sobject <NAME>sObject API name (required)
--formula <EXPR>Formula field API name or SOQL-valid expression
--record-id <ID>Evaluate against this specific record Id
--where-clause <SQL>SOQL WHERE clause to find a test record
--listList all formula fields on the sObject instead
--jsonOutput as JSON
--csvOutput CSV (applies to --list mode)
--datatableOpen browser datatable (applies to --list mode)
Ad-hoc formula testing: --formula evaluates fields that already exist on the sObject. To test a brand-new formula before creating it, use sfr apex execute with an Anonymous Apex script containing System.debug() calls.
