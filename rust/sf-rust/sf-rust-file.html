Markdown viewer

Uses comrak — a CommonMark + GitHub Flavored Markdown renderer in pure Rust. Rendered HTML is wrapped in a styled page that auto-follows the system dark/light preference.

Supported GFM extensions

  • Tables — pipe-syntax tables with header row
  • Task lists — - [x] and - [ ] checkboxes
  • Autolinks — bare URLs become clickable links
  • Strikethrough — ~~text~~
  • Footnotes — [^1] reference-style footnotes
  • Mermaid diagrams — fenced ```mermaid blocks render as live diagrams
  • Linked .md files pre-rendered — clicking any local [text](other.md) opens the rendered version, not raw text

Linked .md files are pre-rendered

✦ Smart .md link handling

When a Markdown file links to another local .md file (e.g. [KEYCHAIN.md](KEYCHAIN.md)), sf-rust automatically renders the target file to its own /tmp/sf-rust-view-*.html page and rewrites the link to point there. Clicking the link opens the rendered page — not raw text. One level deep (linked pages do not recurse further).

Mermaid diagrams

✦ Mermaid diagram rendering

Fenced ```mermaid code blocks are automatically detected at page load and rendered as live SVG diagrams using Mermaid.js v10 from CDN. Supports flowcharts, sequence diagrams, class diagrams, Gantt charts, ER diagrams, and all other Mermaid diagram types. Theme follows prefers-color-scheme.

Monaco file viewer

All non-Markdown, non-CSV files open in a full Monaco editor (v0.44) in read-only mode. Features: syntax highlighting, code folding, minimap, word wrap toggle, copy, and dark/light theme toggle.

sf-rust file diff

Format-aware file and directory diffing. See the dedicated reference page for full docs. Quick reference below.

ExtensionEngineKey flag
.jsonJSON semantic (key-order independent)--semantic
.xmlXML structural (whitespace-normalized)auto
.csvCSV column-aware--key <COL>
DirectoryRecursive per-file dispatch--expand
Anything elseUnified text diff—
bash
# Text / Apex
sf-rust file diff VehicleService-v1.cls VehicleService-v2.cls
sf-rust file diff --viz VehicleService-v1.cls VehicleService-v2.cls

# JSON semantic
sf-rust file diff --semantic a.json b.json
sf-rust file diff --semantic --viz a.json b.json

# XML (Salesforce metadata, auto-detected)
sf-rust file diff Vehicle__c-v1.xml Vehicle__c-v2.xml
sf-rust file diff --viz Vehicle__c-v1.xml Vehicle__c-v2.xml

# CSV
sf-rust file diff --key Id before.csv after.csv

# Directory
sf-rust file diff force-app-v1/ force-app-v2/
sf-rust file diff --expand force-app-v1/ force-app-v2/
sf-rust file diff --viz    force-app-v1/ force-app-v2/
