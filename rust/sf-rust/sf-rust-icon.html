sf-rust icon generates app icon sets from a short text label (1–3 characters) or any emoji. It outputs 8 PNG sizes (16 → 1024), an HTML preview report, and optionally a macOS .icns file — all in pure Rust with zero external dependencies (no ImageMagick, no libvips).

Emoji mode fetches the matching Twemoji SVG from the jsDelivr CDN and renders it with a colored rounded background. Text mode renders via the system font stack using resvg (the pure-Rust SVG renderer).

Inspired by mc-icon-gen (npm) — reimplemented in Rust with no Node.js, no sharp, no native addons.

How to use

Text label (1–3 chars)

sfr icon --text "SF" # → ./icons/icon16.png … icon1024.png report.html sfr icon -t "MC" --bg "#6c8cff" --color "#0b0d14" sfr icon -t "R" --bg "#ff4500" --radius 50 # circle sfr icon -t "API" --bg "#1c2030" --radius 0 # square

Emoji mode (Twemoji)

sfr icon -t "🦀" --bg "#1c2030" sfr icon -t "🚀" --bg "#2463EB" sfr icon -t "⚡" --bg "#d29922" sfr icon -t "🔐" --bg "#3fb950" --radius 12

Custom output directory + open HTML report

sfr icon -t "SF" --output assets/icons --open

Custom sizes

sfr icon -t "SF" --sizes 16,32,64,128,256

macOS .icns (requires iconutil)

sfr icon -t "🦀" --bg "#2463EB" --icns # → icons/icon.icns (uses Apple's iconutil from Xcode CLI tools)

HTML report

The generated report.html shows:

  • Config summary — text, background swatch, foreground swatch, radius, font, mode
  • Preview grid — all generated sizes, displayed at ≤128px with size label
  • Auto dark / light mode via prefers-color-scheme

Use --open to have report.html open in the browser automatically after generation.

Emoji mode — Twemoji

When the --text value is an emoji character, sfr icon:

  1. Derives the Unicode codepoint (e.g. 🦀 → 1f980)
  2. Fetches the matching SVG from the Twemoji 14 CDN (jsDelivr — free, no auth)
  3. Embeds the SVG inside a colored rounded-corner background
  4. Renders each PNG size using resvg (pure Rust, system fonts)

If the fetch fails, it falls back to text rendering of the emoji character.
