💬 sf-rust chat

Peer-to-peer terminal chat between two machines — pure TCP, zero infrastructure

sf-rust chat opens a direct TCP connection between two machines. One side runs chat serve and waits; the other runs chat connect. Once connected, both sides can type freely — messages are delivered in real time with timestamps and the sender's name.

🖥️
chat serve
Binds a TCP port and waits for a peer. Accepts one connection (1-to-1 chat). Share your LAN IP and port with the other machine.
🔌
chat connect
Connects to the serving machine's IP and port. As soon as the handshake succeeds, the chat session starts on both ends.
📋
History log
Pass --history on either side to append every message (sent and received) to ~/.sf-rust/chat_history.log.

How to use

Step 1 — Server side (Machine A, e.g. MacBook)

sf-rust chat serve # default port 7878, name auto-detected as user@hostname sf-rust chat serve --port 9000 --name mohan-mbp # custom port and display name sf-rust chat — listening on port 7878 (you: mohan@MacBook-Pro.local) Waiting for peer… (Ctrl+C to cancel)

Step 2 — Client side (Machine B, e.g. mac-mini)

# replace 192.168.1.5 with the server machine's LAN IP sf-rust chat connect 192.168.1.5:7878 sf-rust chat connect 192.168.1.5:7878 --name sarojan-mini Connecting to 192.168.1.5:7878 (you: sarojan@mac-mini.local) … ✓ Connected!

Step 3 — Chat!

# both sides see the banner, then type freely ───────────────────────────────────────────────── Type a message and press Enter. /quit to exit. Remote messages appear prefixed with their name. ───────────────────────────────────────────────── # to exit: /quit # or /exit or /q

Network setup

Same local network (easiest — MacBook ↔ mac-mini)

# find server machine's LAN IP ifconfig | grep "inet " | grep -v 127 # macOS ip addr show # Linux # typical LAN session # Machine A (192.168.1.5): sf-rust chat serve # Machine B: sf-rust chat connect 192.168.1.5:7878

Same machine (testing)

# Terminal 1: sf-rust chat serve --name alice # Terminal 2: sf-rust chat connect 127.0.0.1:7878 --name bob

Different networks (port forwarding / VPN)

# Option A: router port forwarding # forward router port 7878 → Machine A's LAN IP # Machine B uses your public IP: sf-rust chat connect <public-ip>:7878 # Option B: Tailscale / WireGuard VPN (recommended) # both machines on the same VPN → use VPN IP as if on LAN sf-rust chat connect 100.64.x.x:7878 # Tailscale IP
V1 is plaintext. Messages travel unencrypted over the TCP connection. Fine for a trusted local network; use a VPN for anything sensitive.

History log

Pass --history on either or both sides. Messages are appended to ~/.sf-rust/chat_history.log:

# log format (one line per message): [2026-11-14 14:32:09] mohan@MacBook-Pro: hello from the MacBook! [2026-11-14 14:32:11] sarojan@mac-mini: hi! can you hear me? # view recent history tail -50 ~/.sf-rust/chat_history.log # search history sf-rust grep "deploying" ~/.sf-rust/chat_history.log
