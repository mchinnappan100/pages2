sfr dependency New

Visualize Salesforce metadata dependencies as an interactive D3.js force graph using the Tooling API MetadataComponentDependency object. Understand which Apex classes depend on which fields, which Flows reference which objects, and more — all in a live browser graph.

Overview

The sfr dependency command queries MetadataComponentDependency from the Salesforce Tooling API and outputs the dependency graph in your choice of format: interactive D3.js HTML, table, JSON, or Graphviz DOT.

Tooling API: Requires a connected org with Tooling API access. Use sfr org login web -o <alias> to authenticate.

Usage

sfr dependency [OPTIONS]

Flags

FlagShortDescription
--target-org-oOrg alias (defaults to default org)
--type-tFilter by component type (e.g. ApexClass, CustomObject, Flow)
--name-nFilter by component name (requires --type)
--htmlOpen interactive D3.js force graph in browser
--json-jOutput raw JSON records
--dotOutput Graphviz DOT format
--datatableOpen as interactive HTML datatable

Examples

All org dependencies — force graph

sfr dependency -o dev1 --html

Fetches up to 2000 dependency edges and opens an interactive D3.js force graph in your browser.

Filter by type — table

sfr dependency -o dev1 --type ApexClass

Filter by specific component

sfr dependency -o dev1 --type ApexClass --name MyTriggerHandler

Flow dependencies

sfr dependency -o dev1 --type Flow --html

Export as Graphviz DOT (render with dot -Tsvg)

sfr dependency -o dev1 --type CustomField --dot > deps.dot
dot -Tsvg deps.dot -o deps.svg

Export as JSON

sfr dependency -o dev1 --json | jq '.[] | .MetadataComponentType' | sort | uniq -c | sort -rn

Interactive datatable

sfr dependency -o dev1 --datatable

D3.js Force Graph UI

The --html output opens a full-screen dark-mode interactive graph with:

  • Nodes — colored by metadata component type (ApexClass, CustomField, Flow, etc.)
  • Directed edges — arrow markers showing dependency direction
  • Zoom & pan — scroll to zoom, drag canvas to pan
  • Drag nodes — click and drag any node to reposition it
  • Click highlight — click a node to highlight its direct neighbors; click canvas to reset
  • Tooltip — hover any node to see its type, name, and in/out edge counts
  • Filter — type in the search box to fade unmatched nodes/edges
  • Legend — auto-generated color legend, bottom-left
  • Reset zoom — ⊙ button, top-right
  • Toggle labels — 𝐓 button, top-right

Workflow Tips

Tip: Start with --type ApexClass --html to focus the graph — an org-wide query can return thousands of edges that make the graph dense.
Tip: Use --dot with Graphviz dot -Tpng -Grankdir=LR for a hierarchical left-to-right dependency diagram, easier to read for Apex class hierarchies.
Limit: The Tooling API query uses LIMIT 2000. For orgs with very large dependency graphs, use --type filters to narrow the result.

Implementation Notes

  • Uses Tooling API endpoint: /services/data/v{version}/tooling/query
  • Queries MetadataComponentDependency (read-only Tooling API object)
  • HTML template is embedded at compile time via include_str!() and uses str::replace() with __PLACEHOLDER__ tokens — no format!() escaping issues
  • D3.js v7 force simulation: forceManyBody + forceLink + forceCenter + forceCollide
  • DOT output is compatible with Graphviz, dot, neato, fdp
