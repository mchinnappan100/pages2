sf-rust pdf turns one or more images into a PDF document, one page per image, in pure Rust using the printpdf crate — no GhostScript, no ImageMagick, no libpoppler. RGBA images are automatically composited onto a white background before embedding.

Shell glob expansion works directly: sfr pdf *.png -o icons.pdf — the shell expands the glob before passing the file list to sf-rust.

URL input (image & PDF URLs)

Pass any http:// or https:// URL in place of a local file path. sf-rust downloads it, detects the content-type, and handles it accordingly.

Content-typeBehaviour
image/*Downloaded to a temp file, converted to a PDF page — same as a local image.
application/pdfDownloaded and copied directly to --output. No image pipeline.
text/htmlError with a helpful tip. For arxiv the PDF URL is suggested automatically.

Download a paper from arxiv and open it

sfr pdf https://arxiv.org/pdf/1706.03762 -o attention.pdf --view # ↓ downloading https://arxiv.org/pdf/1706.03762… # PDF written: attention.pdf (1 page, copied from URL)

Download a paper, open it, and speak the summary

sfr pdf https://arxiv.org/pdf/1706.03762 -o attention.pdf --view --speak # → "PDF created: attention.pdf with 1 page."

Download an image URL

sfr pdf https://example.com/diagram.png -o diagram.pdf

Mix local files and image URLs

sfr pdf cover.png https://example.com/fig1.jpg results.png -o report.pdf --page-size a4

HTML URL — helpful error

sfr pdf https://arxiv.org/abs/1706.03762 -o paper.pdf Error: URL returned HTML — cannot convert a webpage to PDF without a headless browser. Tip: use the PDF URL instead: https://arxiv.org/pdf/1706.03762

How to use

Single image → PDF

sfr pdf screenshot.png -o screenshot.pdf

Multiple images → multi-page PDF

sfr pdf photo1.png photo2.jpg photo3.png -o album.pdf

Glob — all PNGs in a directory

sfr pdf icons/*.png -o icon-sheet.pdf sfr pdf screenshots/*.png -o demo.pdf

A4 page size (image fitted, centered)

sfr pdf report-*.png -o report.pdf --page-size a4

US Letter page size

sfr pdf slide-*.png -o slides.pdf --page-size letter

Custom DPI (retina / print)

sfr pdf retina.png -o retina.pdf --dpi 144 # @2x sfr pdf print.png -o print.pdf --dpi 300 # print quality

Custom PDF title

sfr pdf diagram.png -o arch.pdf --title "Architecture Diagram"

Terminal output

$ sfr pdf slide-*.png -o slides.pdf --page-size a4 --no-time ✓ slide-01.png (1920×1080) ✓ slide-02.png (1920×1080) ✓ slide-03.png (1920×1080) ✓ slide-04.png (1920×1080) ✓ slide-05.png (1920×1080) PDF written: slides.pdf (5 pages)

--view and --speak

Open in system viewer after creation

sfr pdf slides/*.png -o deck.pdf --view # Opens deck.pdf in Preview (macOS) immediately after writing

Speak the result aloud (requires phonon-studio running)

sfr pdf report.png -o report.pdf --speak # → "PDF created: report.pdf with 1 page." sfr pdf https://arxiv.org/pdf/1706.03762 -o paper.pdf --view --speak --voice Harper # Downloads, opens in viewer, speaks with Harper voice
phonon-studio must be running: phonon-studio --port 3000. If unreachable, --speak prints a warning and the command still succeeds.

Page size modes

ModeDimensionsBehaviour
image (default)Matches imagePDF page exactly equals the image size in mm at the given DPI. No margins.
a4210 × 297 mmISO A4. Image is scaled to fit (preserves aspect, white margin).
letter215.9 × 279.4 mmUS Letter. Image is scaled to fit (preserves aspect, white margin).

When --page-size a4 or letter is used, fit mode is enabled automatically — images are always scaled to fill the page.

Common workflows

Icon set PDF (from sfr icon output)

# Generate icons first sfr icon -t "SF" --bg "#0176d3" --output my-icons # Combine all sizes into a single PDF sfr pdf my-icons/icon*.png -o my-icons/preview.pdf --page-size a4 --title "SF Icon Set"

Screenshot documentation

# Combine feature screenshots into a PDF sfr pdf screenshots/*.png -o feature-walkthrough.pdf --page-size a4 --title "Feature Walkthrough"

Print-ready slide deck

# Export slides as PNGs then bundle sfr pdf slides/slide-*.png -o deck.pdf --page-size letter --dpi 144

sf-rust alias tip

# Add to ~/.zshrc alias sfr="$HOME/.local/bin/sf-rust" # Single image to PDF sfr pdf diagram.png -o diagram.pdf # All PNGs in current directory → one PDF sfr pdf *.png -o all-images.pdf # A4 handout from screenshots sfr pdf screenshots/*.png -o handout.pdf --page-size a4 --title "Handout"
