sf-rust os — macOS / Linux / Windows
System information commands that work without Node.js, python, or any external tool. Cross-platform (macOS · Linux · Windows), every command supports --json and --datatable.
sf-rust os servers
Scan all listening TCP ports, fetch page titles, show dashboard. Port of macos-servers-dashboard npm package.
sf-rust os info
Hostname, OS version, kernel, CPU brand & core count, RAM used/total, system uptime.
sf-rust os disk
Disk usage per mount point — total, used, free, usage percent, filesystem type, device name.
sf-rust os procs
Top processes sorted by CPU or memory. --limit N, --sort cpu|mem|name, filterable HTML dashboard.
sf-rust os battery
Battery level %, charging status, time remaining. No dependencies — uses native OS APIs.
sf-rust os network
Network interfaces: name, IP address(es) with prefix, MAC address, cumulative RX/TX bytes.
os servers New

Scans all locally listening TCP ports using lsof -iTCP -sTCP:LISTEN, fetches HTML page titles asynchronously in parallel, deduplicates IPv4+IPv6 entries, and shows the result as a table or interactive browser dashboard.

# Table output (default)
sf-rust os servers

# Skip title fetching for a faster scan
sf-rust os servers --no-title

# Interactive HTML dashboard in browser
sf-rust os servers --datatable

# JSON output
sf-rust os servers --json

# Increase HTTP timeout for slow services
sf-rust os servers --timeout 10
FlagDefaultDescription
--no-titlefalseSkip fetching HTML page titles (faster)
--timeout <s>3HTTP timeout in seconds for title fetch
--json / -jfalsePrint JSON array of server entries
--datatablefalseOpen interactive HTML dashboard in browser

The --datatable dashboard has: sortable columns (default: port), live search, "⬡ Open" link, "⊗ Copy kill" button (copies kill -9 <pid> to clipboard), dark/light toggle.

Implementation note: lsof appends (LISTEN) as a whitespace-separated token after the NAME column, so the port is extracted by scanning columns in reverse for the first token containing : that doesn't start with (.
os info New

Shows a system summary table: hostname, OS version, kernel, CPU model and logical core count, memory usage, and uptime. Uses the sysinfo crate — works identically on macOS, Linux, and Windows with no external commands.

sf-rust os info --json
sf-rust os info --datatable

os procs New

Shows top N processes by CPU usage, memory usage, or name. The interactive datatable has live search, sortable columns, and color-coded CPU % (green/yellow/red).

# Top 20 by CPU (default)
sf-rust os procs

# Top 10 by memory
sf-rust os procs --sort mem --limit 10

# Top 50 by name, open in browser
sf-rust os procs --sort name --limit 50 --datatable

# JSON output
sf-rust os procs --json --limit 100
FlagDefaultDescription
--sort cpu|mem|namecpuSort column
--limit N20Number of processes to show
--json / -jfalsePrint JSON with pid, name, cpu_pct, mem_mb, mem_pct
--datatablefalseSearchable HTML dashboard with colorized CPU %, sortable columns

os battery New

Shows battery level, charging status, and time remaining. Desktop systems without a battery return "No battery found". The --datatable view shows a large visual percentage bar.

sf-rust os battery
sf-rust os battery --json
sf-rust os battery --datatable
╔══════════╦═══════════════════════╗ ║ Property ║ Value ║ ╠══════════╬═══════════════════════╣ ║ Source ║ Battery Power ║ ║ Level ║ 67% ║ ║ Status ║ Discharging ║ ║ Time ║ 2:45 remaining ║ ╚══════════╩═══════════════════════╝
macOS
Runs pmset -g batt, parses InternalBattery line for %, status, and remaining time
Linux
Reads /sys/class/power_supply/BAT*/capacity and /status sysfs files; falls back through BAT0–BAT5
Windows
Runs wmic path win32_battery get EstimatedChargeRemaining,BatteryStatus /format:csv

Cross-platform notes
CommandmacOSLinuxWindowsMethod
os servers✓✓—lsof (not available on Windows)
os info✓✓✓sysinfo crate
os disk✓✓✓sysinfo::Disks
os procs✓✓✓sysinfo::System::processes()
os battery✓ pmset✓ sysfs✓ wmicPlatform-native (compile-time #[cfg])
os network✓✓✓sysinfo::Networks
sysinfo dependency: The sysinfo = "0.32" crate abstracts macOS, Linux, and Windows OS APIs into a single Rust API for os info, disk, procs, and network. No external commands, no C FFI — pure Rust.
Quick reference
# All commands support --json and --datatable

sf-rust os servers                        # listening TCP ports + titles
sf-rust os servers --datatable            # full browser dashboard
sf-rust os info                           # system summary
sf-rust os disk                           # disk usage per mount
sf-rust os disk --datatable               # bar-chart view in browser
sf-rust os procs                          # top 20 by CPU
sf-rust os procs --sort mem --limit 10    # top 10 by memory
sf-rust os procs --datatable              # filterable process dashboard
sf-rust os battery                        # battery level and status
sf-rust os battery --datatable            # visual percentage bar
sf-rust os network                        # network interfaces
sf-rust os network --json                 # JSON for scripting

# All --json outputs include status:0 and result:[...]
sf-rust os info --json | jq '.cpu_cores'
sf-rust os disk --json | jq '.result[] | select(.pct > 80)'
sf-rust os procs --json | jq '.result[] | select(.cpu_pct > 10)'
