Overview

sf-rust slides turns Markdown files into browser-based slide decks and can generate those Markdown files from a topic using any supported LLM. Use --- on its own line to separate slides — the same convention as Marp, remark, and reveal.js.

sf-rust slides view <file.md>
Open a Markdown file as a slide deck. Auto-detects front matter theme. Mermaid diagrams render live.
sf-rust slides generate -t "topic"
Ask an LLM to write the slide deck for you, then open it immediately.

Viewers

Three rendering engines, selectable with --viewer:

🎬
reveal.js default
reveal.js 5.1 from CDN. Full-featured: Mermaid live diagrams, highlight.js code, speaker notes (press S), zoom, keyboard & touch nav, 10 themes. Dark by default.
📝
remark.js
Lightweight. Raw Markdown placed in a <textarea> — no Rust pre-processing. CDN only. Two themes: dark / light. Speaker notes after ???. Great for text-heavy decks.
🗂️
Marp CLI
Shells out to the marp binary on PATH. Pixel-perfect Marp theme fidelity (default, gaia, uncover). Install: npm i -g @marp-team/marp-cli. Graceful error if not found.

sf-rust Architecture

Native Salesforce CLI in Rust
  • No Node.js · No npm · One statically-linked binary
  • AES-256-GCM credentials at rest (~/.sf-rust/)
  • OAuth PKCE · JWT Bearer · Device Flow
  • Async throughout — tokio runtime
Space / → to advance  ·  ← to go back  ·  S for speaker notes  ·  F for fullscreen

Slide separators & front matter

Use --- alone on a line to separate slides. YAML front matter between the first pair of --- lines sets the deck title and theme. Marp-style HTML comment directives control per-slide properties.

✦ Marp-compatible syntax

sf-rust slides reads the same --- separators and YAML front matter as Marp, so existing Marp decks work without modification. The marp: true key is silently stripped.

Mermaid diagrams in slides

✦ Mermaid diagrams render live

Fenced ```mermaid blocks in any slide are detected at page load and rendered as SVG using Mermaid.js v10 from CDN. Supports flowcharts, sequence diagrams, class diagrams, Gantt, ER, and more. Theme follows the deck's dark/light state.

AI slide generation

sf-rust slides generate calls any configured LLM to write a full Marp-compatible Markdown deck from a topic, then immediately opens it in the chosen viewer. Provider settings are shared with sf-rust ask — configure once, use everywhere.

✦ One command from topic to open deck

The prompt instructs the LLM to produce ----separated slides with Mermaid diagrams, GFM tables, code examples, and speaker notes — no manual cleanup required. A fence-stripping pass removes accidental ` ```markdown ``` ` wrappers.

bash — generate examples
# Configure LLM once (shared with sf-rust ask)
sf-rust ask configure

# Generate 8 slides, open in reveal.js (black theme)
sf-rust slides generate -t "Salesforce DevOps with sf-rust"

# Save to file + open with remark, dark theme
sf-rust slides generate -t "Apex Best Practices" \
  -o apex.md --viewer remark --theme dark

# 10 slides with marp, save only (no auto-open)
sf-rust slides generate -t "sf-rust Architecture" -n 10 \
  --viewer marp -o arch.md --no-open

# Override provider + model per-call
sf-rust slides generate -t "JWT Bearer Auth" \
  -p claude -m claude-sonnet-4-5 --api-key $ANTHROPIC_API_KEY

# Local Ollama — llama3.1 (8-slide deck, saved to file, slide numbers on)
sf-rust slides generate \
  -t "what is embedding in LLM" \
  -n 8 \
  -p ollama \
  -m llama3.1:latest \
  --base-url http://localhost:11434 \
  -o /tmp/sf-rust-llama-test.md \
  --slide-number

# Local Ollama — llama3.2
sf-rust slides generate -t "SOQL Optimization" \
  -p ollama -m llama3.2 --base-url http://localhost:11434

# Extra prompt instructions
sf-rust slides generate -t "sf-rust file view" \
  --extra "include a code example on every content slide"

# Chain: generate → save → view with mermaid
sf-rust slides generate -t "OAuth PKCE Flow" -n 6 \
  -o oauth.md --no-open
sf-rust slides view oauth.md --theme moon --slide-number
