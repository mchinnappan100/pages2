Overview

sfr slides2mov launches the mc-slides2movie-generator — a self-hosted Node.js web app that turns Markdown documents into polished MP4 videos. Write slides in a live-preview editor, pick a visual theme, optionally add AI-generated content / voice narration / background music / logo branding, then click Render MP4.

Prerequisites: node ≥ 22 · npm ≥ 10 · ffmpeg (brew install ffmpeg). Run make install-slides2mov once to put mc-slides2movie on your PATH.

Quick Start

# 1 — install wrapper (once)
make install-slides2mov

# 2 — start the web UI
sfr slides2mov serve             # opens http://localhost:4321
sfr slides2mov serve --port 8080 # custom port
sfr slides2mov serve --no-open   # don't auto-open browser
sfr slides2mov --version         # 1.0.0

# equivalents using the mc-slides2movie binary directly
mc-slides2movie serve
mcs2m serve --port 4321
The mc-slides2movie wrapper is a shell script pointing at the Node.js source tree. Run make install-slides2mov again if you move the mc-slides2movie-generator directory.

Markdown Slide Format

Slides are plain Markdown separated by --- on its own line.

# Slide Title

- Bullet one
- Bullet two

Some **bold** text and `inline code`.

---

# Code Slide

```python
def greet(name):
    return f"Hello, {name}!"
```

---

# Math Slide

Inline: $E = mc^2$

Display:
$$\int_0^\infty e^{-x}\,dx = 1$$

---

# Table Slide

| Column A | Column B |
|----------|----------|
| Value 1  | Value 2  |

---

# Quote Slide

> A blockquote for emphasis.
Title rules: the first H1–H3 heading becomes the slide title. Font size scales automatically: 72 px (≤28 chars) → 60 → 50 → 42 px for long titles. Minimum 2 slides recommended; tested with up to 50.

Workflow

  1. Select provider and model.
  2. Enter your API key (not needed for Ollama).
  3. Set slide count (2–20).
  4. Type a prompt: "Create 5 slides about nginx load balancing".
  5. Click Generate — tokens stream in real time.
  6. Click Insert to append generated slides to the editor.

Voice Narration

Click the 🎤 Voice tab in the left pane to add per-slide narration.

  1. Select the target slide from the dropdown (syncs with the preview navigator).
  2. Click Record — microphone permission is requested; live waveform animates.
  3. Click Stop — the recording is uploaded and normalised to MP3 via FFmpeg.
  4. Or click Upload audio file to attach an existing MP3/WAV.
  5. Recorded clips appear in the list with inline playback and ✕ delete.
On render, each voice clip is embedded as a timed audio element at slideIndex × dwell seconds, playing at full volume alongside background music.

Background Music & MIDI

MP3 / WAV upload

  1. Open the 🎵 Music tab in the left pane.
  2. Click Add background.mp3 / .wav.
  3. Set volume in Settings → Music Volume (default 30%).
  4. The file is automatically looped to cover the full video duration.

MIDI support (no soundfont needed)

  1. Click Add MIDI file (.mid).
  2. Click Convert to MP3 — the server synthesises up to 80 note events as time-gated sine waves via FFmpeg's aevalsrc filter. No FluidSynth required.
  3. A preview audio player appears with the converted duration.
  4. The converted file is used as background music on render.

Rendering Pipeline

Clicking Render MP4 (or Ctrl+R) runs a 4-step pipeline:

  1. Parse — markdown pre-processed to protect math (stashMath), rendered by marked, math placeholders replaced with KaTeX HTML; slides split on ---.
  2. Compose — a HyperFrames index.html is generated with per-slide timed clips (glow, counter, content, logo, copyright), GSAP entrance/exit animations, audio clips for music loops and voice narration.
  3. Render — npx hyperframes render --quality <q> --fps <n> is invoked; progress streams line-by-line via SSE to the right-pane log.
  4. Download — a path token is returned; browser fetches /api/download?token=… to save slides-movie.mp4.

API Reference

All endpoints are served at http://localhost:4321/api/.

POST /api/parse

Parse markdown into slide objects with KaTeX math pre-rendered.

curl -s http://localhost:4321/api/parse \
  -H 'Content-Type: application/json' \
  -d '{"markdown":"# Slide 1\n\nContent.\n\n---\n\n# Slide 2\n\n$E=mc^2$"}' \
  | sfr json

Response: { "slides": [{ "index", "title", "rawMd", "html" }] }

POST /api/render

Render slides to MP4. Returns an SSE stream of log / done / error events.

POST /api/voice/upload

Upload a voice recording for a slide. Body: audio (file) + slideIndex (number). Returns { token, slideIndex }.

DELETE /api/voice/:token

Delete a voice clip.

POST /api/midi/convert

Convert a .mid MIDI file to MP3. Body: midi (file). Returns { token, durationSec }.

GET /api/audio/:token

Stream a previously uploaded or converted audio file.

GET /api/download?token=…

Download the rendered slides-movie.mp4 file by token returned from /api/render.

POST /api/ai/generate

Generate slides from a prompt using the configured AI provider. Used internally by the AI Sidekick panel.

Tip: combine /api/parse with sfr json to inspect parsed slide structure from the terminal:
curl -s localhost:4321/api/parse -H 'Content-Type:application/json' -d '{"markdown":"# Hello\n\nWorld"}' | sfr json
