Quick start

# Install
make install                        # release + copy to ~/.local/bin + man pages + completions

# Optional: add a short alias to ~/.zshrc (or ~/.bashrc)
echo 'alias sfr="$HOME/.local/bin/sf-rust"' >> ~/.zshrc
source ~/.zshrc                     # sfr is now available as a shorthand

# Authenticate  (use sf-rust or the sfr alias interchangeably)
sfr org login web -o dev1 --instance-url https://login.salesforce.com

# Query data
sfr data query -q "SELECT Id, Name, Industry FROM Account" -o dev1

# Search project files (rgrep engine)
sfr grep -rn --include='*.cls' 'Database\.query' force-app/

sf-rust diagram New
Render Mermaid diagrams (.mmd files or inline code) to HTML (browser, no install), SVG, or PNG. Default: self-contained HTML with Mermaid.js — open instantly. --svg / --png: fetch rendered output from Kroki.io API (internet required). --mmdc: use local mmdc CLI. --file · --code · stdin pipe --svg · --png (Kroki.io API) --mmdc (local mmdc CLI) --theme dark|forest|default|neutral · --background

sf-rust send-email New
Send email from the CLI via Gmail SMTP using a Google App Password stored in ~/.gmail/access.json. Plain-text (--body), HTML (--html), or body-from-file (--body-file). Multiple --to / --cc / --bcc. Attach any file(s) with --attach — MIME type auto-detected. Pure Rust via lettre + rustls — no C libs, no OpenSSL, no Node.js.
--to · --cc · --bcc (multi-recipient) --body · --body-file · --html --attach (PDF, CSV, XLSX, PNG, …) ~/.gmail/access.json · STARTTLS 587
