Quick start

# Install
make install                        # release + copy to ~/.local/bin + man pages + completions

# Authenticate
sf-rust org login web -o dev1 --instance-url https://login.salesforce.com

# Query data
sf-rust data query -q "SELECT Id, Name, Industry FROM Account" -o dev1

# Search project files (rgrep engine)
sf-rust grep -rn --include='*.cls' 'Database\.query' force-app/

Search & Filtering
🔍
sf-rust & rgrep New 2–3.5× faster
The rgrep engine (pure Rust, linear-time NFA/DFA regex) is embedded directly in sf-rust. Use sf-rust grep to search Apex, XML, LWC, and JS files at blazing speed. Use --grep on any data query or data arrow-view command to post-filter SOQL or Parquet results by regex — works with every output format (table, CSV, Parquet, Arrow, Excel, SQLite, datatable). Dedicated to Ken Thompson, creator of grep.
sf-rust grep --grep --grep-ignore-case --include --exclude-dir -r -n -i -l -c rgrep crate regex NFA/DFA POSIX exit codes

File Diff New
Format-aware file and directory diffing built into the Salesforce CLI. Auto-detects the engine from the file extension: XML structural diff (whitespace-normalized, attribute-order independent), CSV column-order independent diff with optional key-field row alignment, JSON semantic diff, recursive directory diff with per-file engine dispatch. Visual Monaco editor via --viz. Exit codes follow the diff/grep convention (0=identical, 1=differs, 2=error).
