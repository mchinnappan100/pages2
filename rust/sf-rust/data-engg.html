sf-rust Data Engineering

Salesforce → Any Data Format, Zero Node.js

sf-rust ships a complete data engineering toolkit built on Apache Arrow and rsqlite. Query Salesforce data and land it directly into Parquet, Arrow IPC, Excel, SQLite, NDJSON, or Markdown — or open an interactive SQL REPL to run joins, aggregations, and window functions over local copies of your org data.

⬡ Parquet ⟶ Arrow IPC ⊞ Excel ⬡ SQLite { } NDJSON ⌗ Markdown ◫ Arrow Viewer ▷ rsql REPL

NDJSON STREAMING

Newline-delimited JSON — one object per line. The format of choice for streaming pipelines, Spark, Kafka, and jq processing.

# Stream to stdout — pipe directly into jq or any line processor
sf-rust data query -q "SELECT Id, Name, Industry FROM Account" -o dev1 --ndjson

# Pipe into jq to extract a single field
sf-rust data query -q "SELECT Id, Name FROM Account" -o dev1 --ndjson \
  | jq '.Name'

# Write to file
sf-rust data query -q "SELECT Id, Name FROM Contact" -o dev1 --ndjson \
  > contacts.jsonl

# Re-read an Arrow file as NDJSON
sf-rust data arrow-view accounts.arrow --ndjson
💡
NDJSON output redirects cleanly to files or pipes — sf-rust writes totals to stderr so stdout stays machine-readable.

Markdown Table DOCS

GitHub-flavoured Markdown tables, ready to paste into PRs, READMEs, Confluence, or Notion.

sf-rust data query -q "SELECT Name, Industry, AnnualRevenue FROM Account LIMIT 5" \
  -o dev1 --markdown

Output:

| Name             | Industry    | AnnualRevenue |
| ---              | ---         | ---           |
| Acme Corp        | Technology  | 5000000       |
| GlobeCo          | Finance     | 12000000      |

Parquet COLUMNAR

Apache Parquet with Snappy compression. The dominant format for data lakes, DuckDB, Spark, pandas, and every cloud data warehouse.

# Auto-named to /tmp/sf-rust-query-<ts>.parquet
sf-rust data query -q "SELECT Id, Name, Industry, AnnualRevenue FROM Account" \
  -o dev1 --parquet

# Explicit path
sf-rust data query -q "SELECT Id, Name, AnnualRevenue FROM Account" \
  -o dev1 --parquet accounts.parquet

# Query a Parquet file back as a table
sf-rust data arrow-view accounts.parquet

# Inspect schema only
sf-rust data arrow-view accounts.parquet --schema

# Convert Parquet → Excel in one step
sf-rust data arrow-view accounts.parquet --xlsx accounts.xlsx

DuckDB

Read sf-rust Parquet files directly from DuckDB.

SELECT Industry, SUM(AnnualRevenue)
FROM 'accounts.parquet'
GROUP BY Industry;

pandas / PyArrow

Load into Python for analysis or ML.

import pandas as pd
df = pd.read_parquet("accounts.parquet")
print(df.describe())

Apache Arrow IPC COLUMNAR

Arrow IPC (Inter-Process Communication) file format — the fastest way to exchange columnar data between Polars, pandas, DataFusion, and any Arrow-native tool. Zero-copy reads.

# Write Arrow IPC — auto path
sf-rust data query -q "SELECT Id, Name, AnnualRevenue FROM Account" \
  -o dev1 --arrow

# Explicit path
sf-rust data query -q "SELECT Id, Name FROM Contact" \
  -o dev1 --arrow contacts.arrow

# Write Parquet AND Arrow in the same query (one Salesforce round-trip)
sf-rust data query -q "SELECT Id, Name FROM Account" \
  -o dev1 --parquet accounts.parquet --arrow accounts.arrow

Polars

Ultra-fast DataFrame reads from Arrow files.

import polars as pl
df = pl.read_ipc("accounts.arrow")
print(df.group_by("Industry")
        .agg(pl.col("AnnualRevenue").sum()))

DataFusion

Query Arrow files with SQL via DataFusion.

ctx = SessionContext()
ctx.register_ipc("accounts",
                 "accounts.arrow")
ctx.sql("SELECT * FROM accounts
         WHERE AnnualRevenue > 1e6")
ℹ
Type inference: sf-rust scans the first non-null value per column — Booleans → Boolean, integers → Int64, decimals → Float64, everything else → Utf8.

Excel (.xlsx) BUSINESS

Native Excel workbooks via rust_xlsxwriter — bold headers, correct numeric types, no CSV round-trip. The format Salesforce admins and business analysts want.

# Auto path → /tmp/sf-rust-query-<ts>.xlsx
sf-rust data query -q "SELECT Id, Name, AnnualRevenue, Industry FROM Account" \
  -o dev1 --xlsx

# Named file
sf-rust data query -q "SELECT Id, Name, Amount FROM Opportunity WHERE StageName = 'Closed Won'" \
  -o dev1 --xlsx closed-won.xlsx

# Parquet file → Excel (no Salesforce call)
sf-rust data arrow-view accounts.parquet --xlsx accounts.xlsx

# Combine: write Parquet (for engineering) + Excel (for business) in one shot
sf-rust data query -q "SELECT Id, Name, AnnualRevenue FROM Account" -o dev1 \
  --parquet accounts.parquet --xlsx accounts.xlsx

SQLite LOCAL SQL

Write query results directly to a SQLite database. Load multiple Salesforce objects into one .db file and query across them with standard SQL tools — DB Browser, datasette, DBeaver, or any SQLite client.

# Auto path → /tmp/sf-rust-query-<ts>.db  (table: records)
sf-rust data query -q "SELECT Id, Name, Industry FROM Account" -o dev1 --sqlite

# Explicit file + custom table name
sf-rust data query -q "SELECT Id, Name FROM Account" -o dev1 \
  --sqlite sf.db --sqlite-table accounts

# Load multiple objects into ONE database (one command each, append to same file)
sf-rust data query -q "SELECT Id, Name FROM Account"    -o dev1 --sqlite sf.db --sqlite-table accounts
sf-rust data query -q "SELECT Id, Name, AccountId FROM Contact" -o dev1 --sqlite sf.db --sqlite-table contacts

# Now JOIN across objects with any SQLite tool
sqlite3 sf.db "SELECT a.Name, COUNT(c.Id) AS contacts
               FROM accounts a JOIN contacts c ON c.AccountId = a.Id
               GROUP BY a.Name ORDER BY contacts DESC LIMIT 10"
💡
Column types are inferred automatically: Bool → INTEGER, integers → INTEGER, floats → REAL, everything else → TEXT. All rows inserted in a single transaction.

Arrow Viewer READ

sf-rust data arrow-view reads Arrow IPC and Parquet files (detected by extension) and renders them in any output format. A complete round-trip: write with data query, read with arrow-view.

# View as Unicode table (default)
sf-rust data arrow-view accounts.parquet

# Show schema: column names + Arrow types
sf-rust data arrow-view accounts.parquet --schema

# First 10 rows
sf-rust data arrow-view accounts.arrow --limit 10

# Convert formats without touching Salesforce
sf-rust data arrow-view accounts.parquet --ndjson   # → NDJSON stream
sf-rust data arrow-view accounts.parquet --markdown # → Markdown table
sf-rust data arrow-view accounts.parquet --xlsx     # → Excel workbook
sf-rust data arrow-view accounts.parquet --sqlite sf.db --sqlite-table accounts

# Open in browser datatable
sf-rust data arrow-view accounts.parquet --datatable

rsql REPL SQL ANALYTICS

An interactive SQL REPL powered by rsqlite — a pure-Rust SQLite-inspired engine. Pre-load one or more Salesforce objects, then run full SQL: JOIN, GROUP BY, CTEs, window functions, and more.

# Load Account + Contact into an in-memory database
sf-rust data rsql -o dev1 --load Account --load Contact

# Cap at 500 rows per object
sf-rust data rsql -o dev1 --load Opportunity --limit 500

# Persist to file — reopen later without hitting Salesforce
sf-rust data rsql -o dev1 --load Account --load Contact --db sf.db
sf-rust data rsql --db sf.db   # reopen — no Salesforce call

Inside the REPL:

rsql [table]> .tables
  Account
  Contact

rsql [table]> .schema Account
CREATE TABLE "Account" (
  "Id"            TEXT,
  "Name"          TEXT,
  "Industry"      TEXT,
  "AnnualRevenue" REAL
);

-- simple query
rsql [table]> SELECT Name, Industry, AnnualRevenue
               FROM Account
               WHERE AnnualRevenue > 1000000
               ORDER BY AnnualRevenue DESC LIMIT 5;

-- cross-object JOIN
rsql [table]> SELECT a.Name, COUNT(c.Id) AS contacts
               FROM Account a
               JOIN Contact c ON c.AccountId = a.Id
               GROUP BY a.Name
               ORDER BY contacts DESC LIMIT 10;

-- CTE + window function
rsql [table]> WITH ranked AS (
                 SELECT Name, Industry, AnnualRevenue,
                        RANK() OVER (PARTITION BY Industry
                                      ORDER BY AnnualRevenue DESC) AS rnk
                 FROM Account
               )
               SELECT * FROM ranked WHERE rnk = 1;

-- switch output mode
rsql [table]> .mode markdown
rsql [markdown]> SELECT Name, Industry FROM Account LIMIT 3;

rsql [markdown]> .quit

Data Pipeline Recipes

Real-world patterns combining multiple features.

Recipe 1 — Daily snapshot to data lake

Extract Account data → Parquet for the lake, Excel for the business team.

#!/bin/bash — daily_snapshot.sh
DATE=$(date +%Y%m%d)
sf-rust data query \
  -q "SELECT Id, Name, Industry, AnnualRevenue, OwnerId FROM Account" \
  -o prod \
  --parquet snapshots/accounts_${DATE}.parquet \
  --xlsx    reports/accounts_${DATE}.xlsx
# → columnar Parquet for Spark/DuckDB AND Excel for the business team
#   in a single Salesforce API call

Recipe 2 — Multi-object SQL analytics

Load Account + Contact + Opportunity into rsqlite, run cross-object SQL locally.

# Step 1: pull data once, save to disk
sf-rust data rsql -o prod \
  --load Account --load Contact --load Opportunity \
  --db salesforce.db

# Step 2: reopen any time — zero Salesforce calls
sf-rust data rsql --db salesforce.db

# Inside the REPL:
rsql> SELECT a.Name, a.Industry,
              COUNT(DISTINCT c.Id) AS contacts,
              SUM(o.Amount)         AS pipeline
       FROM Account a
       LEFT JOIN Contact     c ON c.AccountId = a.Id
       LEFT JOIN Opportunity o ON o.AccountId = a.Id
                                AND o.StageName != 'Closed Lost'
       GROUP BY a.Name, a.Industry
       ORDER BY pipeline DESC LIMIT 20;

Recipe 3 — Parquet → NDJSON stream to Kafka / S3

Read a cached Parquet file and stream each record as a JSON line.

# Read Parquet, stream NDJSON to stdout, pipe to kafka-console-producer
sf-rust data arrow-view accounts.parquet --ndjson \
  | kafka-console-producer --topic sf-accounts --bootstrap-server localhost:9092

# Or upload to S3 as NDJSON
sf-rust data arrow-view accounts.parquet --ndjson \
  | aws s3 cp - s3://my-bucket/salesforce/accounts/latest.jsonl

Recipe 4 — Inspect schema before building a pipeline

Fetch once as Parquet, inspect types, then build your transformation.

# Step 1: fetch sample data
sf-rust data query -q "SELECT Id, Name, AnnualRevenue, CreatedDate FROM Account LIMIT 1" \
  -o dev1 --parquet sample.parquet

# Step 2: inspect Arrow schema (column names + inferred types)
sf-rust data arrow-view sample.parquet --schema
# [{"name":"Id","type":"Utf8","nullable":true},
#  {"name":"Name","type":"Utf8","nullable":true},
#  {"name":"AnnualRevenue","type":"Float64","nullable":true},
#  {"name":"CreatedDate","type":"Utf8","nullable":true}]

# Step 3: full load once you know the schema is right
sf-rust data query -q "SELECT Id, Name, AnnualRevenue, CreatedDate FROM Account" \
  -o prod --parquet accounts_full.parquet

Recipe 5 — GitHub PR table from a SOQL query

Paste live Salesforce data straight into a PR description.

sf-rust data query \
  -q "SELECT Name, StageName, Amount FROM Opportunity WHERE CloseDate = THIS_QUARTER ORDER BY Amount DESC LIMIT 10" \
  -o prod --markdown | pbcopy
# → ready to paste into GitHub, Confluence, Notion
