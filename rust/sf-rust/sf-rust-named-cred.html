🔑 sfr named-cred

Inspect Salesforce Named Credentials via the Tooling API — audit endpoints and auth config without opening Setup

📋
list
🔍
get

sfr named-cred queries the NamedCredential Tooling API object. Named credentials bundle a callout URL with authentication settings (OAuth, password, certificate, etc.). Inspecting them from the CLI is useful for security audits, CI validation scripts, and cross-org comparison — without navigating to Setup UI.

Tip: Use --csv or --json to export a full inventory for security review or cross-environment comparison.

📋 sfr named-cred list

List all named credentials in the org. Filter by name with --search.

Usage

sfr named-cred list -o dev1 sfr named-cred list -o dev1 --search "Stripe" sfr named-cred list -o dev1 --json sfr named-cred list -o dev1 --csv sfr named-cred list -o dev1 --datatable

🔍 sfr named-cred get

Show full details of a single named credential. Accepts the developer name or the label.

Usage

sfr named-cred get "Stripe_API" -o dev1 sfr named-cred get "Stripe API" -o dev1 # also matches by label sfr named-cred get "Stripe_API" -o dev1 --json sfr named-cred get "Stripe_API" -o dev1 --datatable
