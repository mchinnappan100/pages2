sf-rust weather fetches live weather data for any city on Earth — no account, no API key, no config. It uses the Open-Meteo geocoding API to resolve city names to coordinates, then the Open-Meteo forecast API for current conditions and a 7-day outlook. Output is a rich terminal table, a self-contained HTML page (opens in browser with --html), or raw JSON (with --json).

Open-Meteo is an open-source weather API that provides free access to weather forecast models. No registration, no API key.

How to use

Basic — table output

# Current conditions + 7-day forecast in the terminal sf-rust weather --city "San Francisco" sfr weather -c "Chennai" sfr weather -c "Tokyo" --units imperial

HTML — self-contained page opens in browser

sfr weather -c "London" --html # → generates /tmp/sf-rust-weather-{ts}.html and opens it sfr weather -c "Mumbai" --html --units metric

JSON — pipe to jq or save to file

sfr weather -c "Berlin" --json sfr weather -c "New York" --json | jq '.current.temperature_2m'

WMO weather codes

Open-Meteo uses standard WMO (World Meteorological Organization) codes to describe conditions. sf-rust weather maps every code to a description and emoji.

☀️
0 — Clear sky
No clouds, full sun
🌤️
1 — Mainly clear
Few clouds, mostly sunny
⛅
2 — Partly cloudy
Mix of sun and cloud
☁️
3 — Overcast
Completely cloudy
🌫️
45 / 48 — Fog
Fog or rime fog
🌦️
51–55 — Drizzle
Light to dense drizzle
🌧️
61–65 — Rain
Slight to heavy rain
🌨️
71–75 — Snow
Slight to heavy snowfall
🌦️
80–82 — Showers
Slight to violent rain showers
🌨️
85–86 — Snow showers
Slight to heavy snow showers
⛈️
95 — Thunderstorm
Slight or moderate thunderstorm
⛈️

Thunderstorm with slight or heavy hail

Data source

ServiceEndpointPurposeKey required
Open-Meteo Geocoding geocoding-api.open-meteo.com/v1/search City name → latitude / longitude None
Open-Meteo Forecast api.open-meteo.com/v1/forecast Current conditions + 7-day daily forecast None

Open-Meteo is open-source and free for non-commercial use. It aggregates data from NOAA, DWD, ECMWF, and other national weather services.

sf-rust alias tip

# Add to ~/.zshrc for a shorter alias alias sfr="$HOME/.local/bin/sf-rust" sfr weather -c "Chennai" sfr weather -c "Chennai" --html
