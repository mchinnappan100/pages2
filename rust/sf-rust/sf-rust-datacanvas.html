📊 DataCanvas

A drag-and-drop XLSX dashboard builder for the terminal era. Load any spreadsheet and explore it with 27 widget types, cross-filtering, AI-generated scripts, voice-queryable AI Sidekick, PostgreSQL mode, and offline-ready HTML export — all from a local Node.js server.

Overview

sfr datacanvas launches DataCanvas — a self-hosted web app that turns any .xlsx file into a fully interactive analytics environment. It exposes two independent single-page applications on the same server:

XLSX file
→ express + xlsx →
localhost:3000 · Data Explorer
+
localhost:3000/dashboard.html · Builder
Prerequisites: node ≥ 22 · npm ≥ 10. Run make install-datacanvas once to put datacanvas on your PATH. Then cd ~/xlsx-dashboard && npm install to install Node dependencies.

Quick Start

# 1 — install wrapper (once)
make install-datacanvas

# 2 — install Node dependencies (once)
cd ~/xlsx-dashboard && npm install

# 3 — launch with a file
sfr datacanvas --file data.xlsx            # port 3000
sfr datacanvas --file data.xlsx --port 4000
sfr datacanvas                             # no file — drag-drop in browser

# 4 — open the two SPAs
open http://localhost:3000                 # Data Explorer
open http://localhost:3000/dashboard.html  # Dashboard Builder

# sample files bundled
sfr datacanvas --file ~/xlsx-dashboard/samples/sales-report.xlsx
sfr datacanvas --file ~/xlsx-dashboard/samples/hr-data.xlsx
sfr datacanvas --file ~/xlsx-dashboard/samples/web-analytics.xlsx

# PostgreSQL mode
sfr datacanvas --file data.xlsx --pg postgresql://localhost/mydb

# HTTPS (self-signed cert auto-generated)
sfr datacanvas --file data.xlsx --https

Generate Script from conversation

Ask the AI sidekick to perform a data task in plain English, then click ⚙ Generate Script from conversation. The AI writes a DataCanvas script and loads it directly into the Script tab, ready to run with Ctrl+Enter.

AI Sidekick → Generate Script
You: Flag all rows where Revenue is more than 2 standard deviations above the mean AI generating DataCanvas script… const { rows, columns } = DataCanvas.getSheet(); const revenues = rows.map(r => parseFloat(r["Revenue"]) || 0); const mean = revenues.reduce((a, b) => a + b, 0) / revenues.length; const std = Math.sqrt(revenues.map(v => (v - mean) ** 2).reduce((a,b)=>a+b,0) / revenues.length); const updated = rows.map(r => ({ ...r, _outlier: parseFloat(r["Revenue"]) > mean + 2 * std ? "⚠ HIGH" : "" })); DataCanvas.setSheet(updated); DataCanvas.showMessage(`${updated.filter(r=>r._outlier).length} outliers flagged`); ✓ Loaded into Script tab — press Ctrl+Enter to run

PostgreSQL Mode

Pass a --pg connection string to import every sheet into PostgreSQL on startup.

createdb mydb
sfr datacanvas --file data.xlsx --pg postgresql://localhost/mydb

# Each sheet → PG table named sheet_<sheetname>
# SQL tab accepts SELECT statements only (read-only)
Only SELECT statements are accepted in the SQL tab — DataCanvas does not issue INSERT, UPDATE, or DELETE against PostgreSQL.

Script Tab

The Script tab embeds a Monaco editor running JavaScript in a sandboxed Web Worker (10 s timeout). Scripts read and mutate sheet data via the DataCanvas API.

DataCanvas API surface

// Read current sheet
const { rows, columns } = DataCanvas.getSheet();

// Write back transformed rows
DataCanvas.setSheet(updatedRows);

// Show a toast message
DataCanvas.showMessage("Done! 42 rows updated");

// Log to the output panel
DataCanvas.log("Processing row 1…");
