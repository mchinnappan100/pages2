Pure Rust

sf-rust image wraps the image crate (pure Rust, no libvips, no ImageMagick, no C addons) to resize images and convert between six formats in a single command. Output file name is derived automatically from the input name, or set explicitly with --output.

The output file name defaults to <stem>-resized.<ext> when --resize is used, or <stem>.<new-ext> for format-only conversion. Use --output to override both.

How to use

Resize only (keep format)

sfr image photo.png --resize 800x600 # → photo-resized.png (800×600) sfr image logo.jpg --resize 128x128 # → logo-resized.jpg (128×128)

Convert format only (no resize)

sfr image photo.png --format webp # → photo.webp sfr image photo.jpg --format png # → photo.png

Resize + convert in one step

sfr image photo.png --resize 1920x1080 --format webp # → photo-resized.webp (1920×1080) sfr image logo.png --resize 64x64 --format jpg --quality 90 # → logo-resized.jpg (JPEG quality 90)

Explicit output path

sfr image hero.png --resize 400x300 --format webp -o assets/hero-sm.webp

High-quality resize filter

sfr image photo.jpg --resize 2560x1440 --filter lanczos3 # best quality upscale / downscale (default) sfr image thumbnail.png --resize 16x16 --filter nearest # pixel-art / favicon, no anti-aliasing

Terminal output

$ sfr image photo.png --resize 800x600 --format webp --no-time Input: photo.png (1920×1440, 2048.3 KB) Output: photo-resized.webp (800×600, 42.1 KB, WEBP) $ sfr image banner.jpg --resize 1200x628 --quality 85 --no-time Input: banner.jpg (3000×1572, 4096.0 KB) Output: banner-resized.jpg (1200×628, 184.2 KB, JPG)

Batch examples

# Convert all PNGs in a directory to WebP at 800px wide for f in *.png; do sfr image "$f" --resize 800x600 --format webp done # Generate Salesforce community thumbnails (370x280) sfr image hero.jpg --resize 370x280 --format png -o thumbnail.png # Favicon sizes from master PNG sfr image logo.png --resize 16x16 --filter nearest -o favicon-16.png sfr image logo.png --resize 32x32 --filter nearest -o favicon-32.png sfr image logo.png --resize 192x192 -o icon-192.png

sf-rust alias tip

# Add to ~/.zshrc alias sfr="$HOME/.local/bin/sf-rust" sfr image photo.png --resize 800x600 --format webp sfr image logo.svg --format png -o logo.png
