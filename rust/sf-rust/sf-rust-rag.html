How it works

#StageWhat happensRust module
1LoadRecursively read .txt .md .html .pdf .apex .cls .json .rs … files from a file or directory — or fetch a https:// URL (PDF downloaded + extracted; HTML tag-stripped via html2text)sf-rag/loader.rs · commands.rs
2ChunkSplit each document into overlapping word windows (--chunk-size chars, --chunk-overlap chars)sf-rag/chunker.rs
3EmbedCall Ollama or OpenAI embeddings API to get a float vector per chunk. With --cache, SHA-256 keyed vectors are saved to ~/.sf-rust/rag-cache/ and re-used on subsequent runssf-rag/embeddings.rs · sf-rag/cache.rs
4SearchEmbed the question, compute cosine similarity against all chunks, return top-Ksf-rag/vectorstore.rs
5AnswerPass retrieved chunks as context to Ollama / OpenAI / Claude, print the answer. With --datatable, also open an interactive HTML table of sources in the browsersf-rag/commands.rs

Usage examples

Quickstart — local Ollama (no API key)

# Pull models once ollama pull nomic-embed-text ollama pull llama3.2 # Ask a question about your project docs sfr rag -d docs/ -q "What is the deployment process?" # Show retrieved chunks before the answer sfr rag -d docs/ -q "What is the deployment process?" --show-sources

Index only Markdown files in a large tree

sfr rag -d . --include '*.md' \ -q "How do I run the test suite?"

Use Claude as the answering LLM

sfr rag -d force-app/ \ --include '*.cls' --include '*.trigger' \ --llm claude:claude-opus-4-5 \ --anthropic-key $ANTHROPIC_API_KEY \ -q "Which classes handle order processing?"

Use OpenAI embeddings + GPT-4o answer

sfr rag -d docs/ \ --embedding-model openai:text-embedding-3-small \ --llm openai:gpt-4o-mini \ --openai-key $OPENAI_API_KEY \ -q "Summarize the authentication architecture"

Fine-tune chunking and retrieval

sfr rag -d specs/ \ --chunk-size 800 --chunk-overlap 200 --top-k 8 \ -q "What are the rate limits for the REST API?"

Ask about Apex code

sfr rag -d force-app/main/default/classes/ \ --include '*.cls' \ --llm ollama:codellama \ -q "Which methods call Database.query without binding variables?" \ --show-sources

Cache embeddings — fast re-runs on the same docs

# First run: embeds all chunks and writes ~/.sf-rust/rag-cache/nomic-embed-text/*.json sfr rag -d docs/ --cache -q "How does authentication work?" # Second run: all chunks loaded from cache — embedding step is instant sfr rag -d docs/ --cache -q "What is the token refresh flow?" 87 chunk(s) loaded from cache, 0 embedded fresh.

Index a PDF document

# Ask questions about a PDF spec or design doc sfr rag -d architecture.pdf -q "What are the data retention policies?" # Mixed directory — Markdown + PDFs together sfr rag -d specs/ --cache -q "Which API version introduced batch Apex limits?" # .pdf files are auto-indexed alongside .md, .txt, etc.

Index a URL — PDF or HTML page

# PDF from URL — downloaded to temp file, extracted, temp removed sfr rag -d https://arxiv.org/pdf/1706.03762 \ --llm ollama:gemma4 \ --cache \ -q "What is the positional encoding used in transformer?" # HTML documentation page — tags stripped, plain text indexed sfr rag -d https://developer.salesforce.com/docs/atlas.en-us.api_rest.meta/api_rest/intro_rest.htm \ --llm ollama:gemma4 \ -q "What REST endpoints are available for Salesforce?"

Open retrieved sources as interactive datatable

# Print answer to terminal AND open sources in browser HTML table sfr rag -d ~/rag/test/ --cache \ --llm ollama:gemma4 \ -q "How do I deploy metadata?" \ --datatable # Opens: Source · Chunk # · Score · Preview columns in sortable HTML table

All flags

FlagShortDefaultDescription

--openai-key KEY——OpenAI API key
--anthropic-key KEY——Anthropic API key
--show-sources—offPrint retrieved chunks before the answer
--cache—offCache embeddings in ~/.sf-rust/rag-cache/; subsequent runs skip re-embedding unchanged chunks
--datatable—offOpen retrieved chunks (Source · Chunk · Score · Preview) in an interactive HTML datatable in the browser

Supported file extensions

When no --include filter is given, these extensions are auto-indexed:

txt · md · markdown · html · htm · rst · csv · json · toml · yaml · yml · apex · cls · trigger · js · ts · py · rs · pdf

Setup — Ollama (recommended, free)

# macOS brew install ollama ollama serve & # starts at http://localhost:11434 # Pull the embedding model and an LLM ollama pull nomic-embed-text ollama pull llama3.2 # Verify ollama list
Tip: Ollama runs entirely on-device. No data leaves your machine, no API key needed. nomic-embed-text is 274 MB; llama3.2 is 2 GB.

Alias tip

# ~/.zshrc alias sfr="$HOME/.local/bin/sf-rust" # Ask about your Salesforce project sfr rag -d force-app/ --include '*.cls' \ -q "Which trigger handlers use the Unit Of Work pattern?"
