🎞 sf-rust slideshow

Auto-advancing image browser in the browser — plus MP4 export via ffmpeg. No server. No Node.js.

Basic usage

# Open a folder of images in the browser (3s delay, dark theme) sfr slideshow --dir ./photos sfr slideshow -d ./vacation # Custom title and 5-second delay sfr slideshow --dir ./photos --title "Summer 2025" --delay 5 # Loop back to the first image sfr slideshow --dir ./photos --loop # Show thumbnail strip at bottom sfr slideshow --dir ./photos --thumbnails # Specific images (comma-separated) sfr slideshow --images a.jpg,b.png,c.webp # Light theme sfr slideshow --dir ./photos --theme light # Save HTML but don't open the browser sfr slideshow --dir ./photos --output slideshow.html --no-open # Background music (loops, 🔊 mute button in browser) sfr slideshow --dir ./photos --music bg.mp3 # Self-contained HTML with embedded music (base64) sfr slideshow --dir ./photos --music bg.mp3 --embed --output portable.html

Movie export (MP4 via ffmpeg)

Pass --movie <output.mp4> to generate a video instead of opening a browser. Each image is shown for --delay seconds. Requires ffmpeg installed (brew install ffmpeg).

# 3-second delay between frames (default) sfr slideshow --dir ./photos -m vacation.mp4 # 2-second delay sfr slideshow --dir ./photos --delay 2 --movie vacation.mp4 # Specific images → movie sfr slideshow --images slide1.png,slide2.png,slide3.png --delay 4 --movie deck.mp4
ffmpeg not installed? Run brew install ffmpeg on macOS, sudo apt install ffmpeg on Ubuntu, or download from ffmpeg.org. The browser slideshow works without ffmpeg.
