Install from source

  1. Install Rust (skip if already installed)
    curl --proto '=https' --tlsv1.2 -sSf https://sh.rustup.rs | sh source ~/.zshrc # or restart terminal
  2. Install Xcode Command Line Tools (skip if already installed)
    xcode-select --install
  3. Clone the repo
    git clone https://github.com/mchinnappan100/sf-rust.git cd sf-rust
  4. Build and install
    make install # builds release binary, copies to ~/.local/bin/, generates 230+ man pages, # generates zsh/bash/fish completions, ad-hoc codesigns the binary
  5. Add to PATH — append to ~/.zshrc (or ~/.bashrc)
    export PATH="$HOME/.local/bin:$PATH" export MANPATH="$HOME/.local/share/man:$MANPATH" alias sfr="$HOME/.local/bin/sf-rust" # For zsh completions: fpath=(~/.zfunc $fpath) autoload -Uz compinit && compinit
    Then reload: source ~/.zshrc
  6. Install shell completions
    make install-completions # writes ~/.zfunc/_sf-rust, ~/.bash_completion.d/sf-rust, # ~/.config/fish/completions/sf-rust.fish
  1. Install Rust
    curl --proto '=https' --tlsv1.2 -sSf https://sh.rustup.rs | sh source ~/.bashrc
  2. Install build dependencies (Debian/Ubuntu)
    sudo apt update && sudo apt install -y \ build-essential git pkg-config libssl-dev
    On Fedora/RHEL: sudo dnf install gcc git pkg-config openssl-devel
  3. Clone the repo
    git clone https://github.com/mchinnappan100/sf-rust.git cd sf-rust
  4. Build release binary
    cargo build --release # binary at: target/release/sf-rust
  5. Install binary and man pages
    make install # or manually: mkdir -p ~/.local/bin cp target/release/sf-rust ~/.local/bin/sf-rust chmod +x ~/.local/bin/sf-rust
  6. Add to PATH — append to ~/.bashrc (or ~/.zshrc)
    export PATH="$HOME/.local/bin:$PATH" export MANPATH="$HOME/.local/share/man:$MANPATH" alias sfr="$HOME/.local/bin/sf-rust"
    Then reload: source ~/.bashrc
  7. Install shell completions
    make install-completions # or manually for bash: mkdir -p ~/.bash_completion.d sf-rust completion bash > ~/.bash_completion.d/sf-rust echo 'source ~/.bash_completion.d/sf-rust' >> ~/.bashrc
Windows support is experimental. Most commands work; man pages and codesigning are not available. Use PowerShell or Windows Terminal.
  1. Install Rust — download rustup-init.exe from rustup.rs and run it, selecting the default toolchain.
  2. Install Visual Studio Build Tools — required by the Rust MSVC toolchain. Download from visualstudio.microsoft.com. Select "Desktop development with C++".
  3. Clone the repo (PowerShell)
    git clone https://github.com/mchinnappan100/sf-rust.git cd sf-rust
  4. Build release binary
    cargo build --release # binary at: target\release\sf-rust.exe
  5. Copy binary to a directory on PATH
    # PowerShell — copy to a local bin folder New-Item -ItemType Directory -Force "$env:USERPROFILE\.local\bin" Copy-Item target\release\sf-rust.exe "$env:USERPROFILE\.local\bin\sf-rust.exe"
  6. Add to PATH (PowerShell, persistent)
    # Add to user PATH permanently $path = [Environment]::GetEnvironmentVariable("PATH","User") [Environment]::SetEnvironmentVariable("PATH", "$path;$env:USERPROFILE\.local\bin", "User")
  7. PowerShell completions
    # Add to your PowerShell profile ($PROFILE) sf-rust completion powershell >> $PROFILE

Remote install (SSH) macOSLinux

If sf-rust is already built locally, deploy it to any remote machine in one command:

# From the sf-rust source directory on your local machine: ./scripts/move-sf-rust-to-new-machine.sh user@remotehost # Defaults to the configured mac-mini: ./scripts/move-sf-rust-to-new-machine.sh

The script does all 5 steps automatically:

StepWhat it does
1SSH connectivity check
2Copy binary → ~/sf-rust/ and ~/.local/bin/, codesign
3Copy 232 man pages → ~/.local/share/man/man1/, run mandb
4Copy zsh / bash / fish completion scripts
5Patch ~/.zshrc — PATH, sfr alias, MANPATH, fpath, compinit (all idempotent)
Safe to re-run — all ~/.zshrc patches are guarded by grep checks.

Verify installation

$ sfr --version sf-rust 0.4.0 (build 20260101-abc1234) $ sfr --help Salesforce development. Native speed. Rust reliability. # Check man page $ man sf-rust # Check completions (zsh) $ sfr <TAB><TAB> org data apex project metadata package devops rag ... # Run doctor to check full installation $ sfr doctor
sfr doctor
$ sfr doctor PASS Binary freshness sf-rust 0.4.0 (build 20260101-abc1234) PASS Man pages 232 pages in ~/.local/share/man/man1/ PASS Shell completions zsh · bash · fish PASS Config file ~/.sf-rust/config.toml INFO No default org set run: sfr org login web -o myorg Time: 12ms

Update sf-rust

# Pull latest source and rebuild cd sf-rust git pull && make install # Redeploy to remote machine make deploy-mini # or full re-migration: ./scripts/move-sf-rust-to-new-machine.sh user@host

Free disk space

The target/ build directory can grow to several GB. Clean it when space is low:

# Remove all build artifacts (safe — rebuilds from source next time) cd sf-rust cargo clean # Check size first du -sh target/
The installed binary at ~/.local/bin/sf-rust is unaffected by cargo clean.

Uninstall

# Remove binary and man pages make uninstall # Or manually: rm ~/.local/bin/sf-rust rm ~/.local/share/man/man1/sf-rust*.1 rm ~/.zfunc/_sf-rust rm ~/.bash_completion.d/sf-rust rm -rf ~/.sf-rust/ # credentials, config, RAG cache — optional
