sf-rust stock fetches live price, change, volume, 52-week range, and market cap for any list of tickers using the Yahoo Finance v8/finance/chart endpoint — free, unauthenticated, no API key, no account. Supports any equity, ETF, index, or crypto symbol tracked by Yahoo Finance.

Data is typically 15-minute delayed for US equities. The Yahoo Finance v8/finance/chart endpoint is used because v7/finance/quote now requires authentication.

How to use

Basic — table in terminal

# Comma-separated tickers sf-rust stock --tickers "AAPL,MSFT,TSLA" sfr stock -t "AAPL,MSFT,TSLA" # ETFs and indices sfr stock -t "SPY,QQQ,DIA" # International and crypto sfr stock -t "INFY.NS,TCS.NS,BTC-USD,ETH-USD"

HTML — summary cards + detail table in browser

sfr stock -t "AAPL,MSFT,GOOGL,AMZN,NVDA" --html # → opens /tmp/sf-rust-stock-{ts}.html with live data

JSON — raw data for scripting

sfr stock -t "AAPL" --json | jq '.[] | {symbol, price: .regular_market_price, change: .regular_market_change_percent}' sfr stock -t "SPY,QQQ" --json > quotes.json

CSV — pipe to file or further tools

sfr stock -t "AAPL,MSFT,TSLA,NVDA" --csv > quotes.csv sfr stock -t "AAPL,MSFT" --csv | column -t -s,

Command flags

FlagShortDescription
--tickers-tComma-separated ticker symbols: AAPL,MSFT,TSLA. Any Yahoo Finance symbol works — equities, ETFs, indices, crypto (BTC-USD), international (INFY.NS)
--html—Generate a self-contained dark-mode HTML page with summary cards + detail table; opens in browser
--json-jOutput JSON array — one object per ticker with all fields
--csv—Output CSV with headers — Ticker, Name, Currency, Price, Change, ChangePct, Open, High, Low, PrevClose, Volume, MarketCap, 52wHigh, 52wLow, MarketState

API details

EndpointBase URLAuthNotes
Yahoo Finance v8 chart query1.finance.yahoo.com/v8/finance/chart/{symbol} None Returns OHLCV + meta with 52-week range; called once per ticker

The older v7/finance/quote endpoint now requires authentication. The v8/finance/chart endpoint returns all needed fields (price, change %, high/low, volume, 52-week range) without any key.

Supported symbol formats

# US equities AAPL MSFT GOOGL AMZN NVDA META TSLA NFLX ORCL # ETFs & indices SPY QQQ DIA IWM VTI ^GSPC ^DJI ^IXIC # Indian market (NSE) INFY.NS TCS.NS RELIANCE.NS HDFCBANK.NS WIPRO.NS # Crypto (USD pair) BTC-USD ETH-USD SOL-USD BNB-USD # European (suffix by exchange) SAP.DE LVMH.PA ASML.AS
