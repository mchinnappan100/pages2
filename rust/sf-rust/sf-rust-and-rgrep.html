sf-rust & rgrep

Blazing-fast, regex-powered search for Salesforce projects — baked directly into the CLI. No grep installation required.

Pure Rust 2–3.5× faster than BSD grep Linear-time NFA/DFA regex POSIX exit codes No backtracking

⚙️ How It Works

rgrep is a standalone Rust crate at ../grep-in-rust referenced as a workspace path dependency. sf-rust links it as a library — no subprocess, no shell escaping.

Pattern + Flags
→
rgrep::build_regex()
→
collect_files()
→
grep_file() per path
→
Buffered stdout
→
exit 0/1/2
regex crateLinear-time NFA/DFA engine — no catastrophic backtracking, safe on untrusted patterns.
walkdir crateEfficient recursive directory traversal with symlink control and hidden-file awareness.
glob crateShell-glob matching for --include / --exclude / --exclude-dir.
BufWriterAll output is buffered and flushed once — no per-line syscall overhead.

🔖 Build & Version

Every sf-rust binary embeds a build date and git short hash at compile time via build.rs.

# Rich version with build ID
sf-rust version
sf-rust 0.1.0 (build 20261111-5d04d18)
Architecture: aarch64
OS: macos
No Node.js required.

# JSON output
sf-rust version --json
{"status":0,"result":{"cliVersion":"sf-rust/0.1.0","buildId":"20261111-5d04d18","architecture":"aarch64","os":"macos"}}
The build ID updates automatically on every make install. Format: YYYYMMDD-<git-hash>.

🔍 Basic Search

# Recursive search with line numbers (most common invocation)
sf-rust grep -rn 'Database\.query' force-app/
force-app/main/default/classes/AccountService.cls:14:    List<Account> results = Database.query(soql);

# Default: recursive when no path given (searches current directory)
sf-rust grep -n 'AuraEnabled'

# Case-insensitive
sf-rust grep -ri 'annualrevenue' force-app/

# Only Apex classes
sf-rust grep -rn --include='*.cls' 'AuraEnabled' force-app/

# Only metadata XML
sf-rust grep -rn --include='*.xml' 'CustomObject' force-app/

⚡ Apex Patterns

Security & governance

# Find all sharing declarations
sf-rust grep -rn --include='*.cls' '\b(WITH|WITHOUT) SHARING\b' force-app/

# Spot hardcoded Salesforce IDs (15 or 18 chars)
sf-rust grep -rn --include='*.cls' "'[0-9A-Za-z]{15,18}'" force-app/

# DML inside loops (governor limit risk)
sf-rust grep -rn --include='*.cls' 'for.*\b(insert|update|delete)\b' force-app/

# Classes missing @SuppressWarnings
sf-rust grep -rL --include='*.cls' '@SuppressWarnings' force-app/

SOQL & DML

# All inline SOQL queries
sf-rust grep -rn --include='*.cls' '\[SELECT\b' force-app/

# All DML statements
sf-rust grep -rn --include='*.cls' '\b(insert|update|delete|upsert|undelete|merge)\b' force-app/

# Database.* calls (dynamic SOQL / DML)
sf-rust grep -rn --include='*.cls' 'Database\.(query|insert|update|delete|upsert)' force-app/

# System.debug (noise in production code)
sf-rust grep -rn --include='*.cls' 'System\.debug' force-app/

Testing

# List all test classes
sf-rust grep -rl --include='*.cls' '@isTest' force-app/

# Find test methods missing Test.startTest()
sf-rust grep -rn --include='*.cls' '@isTest' force-app/ | \
  xargs grep -L 'Test\.startTest'

# Find @AuraEnabled methods
sf-rust grep -rn --include='*.cls' '@AuraEnabled' force-app/

# TODOs with 2 lines of context
sf-rust grep -rn -A 2 --include='*.cls' 'TODO' force-app/

📦 Metadata Patterns

# Find all Custom Metadata Types
sf-rust grep -rl --include='*.xml' 'CustomMetadata' force-app/

# Locate Permission Set assignments for a specific permission
sf-rust grep -rn --include='*.permissionset-meta.xml' 'Modify_All_Data' force-app/

# Find all Email Templates
sf-rust grep -rn --include='*.xml' 'EmailTemplate' force-app/

# Check which flows reference a specific object
sf-rust grep -rl --include='*.flow-meta.xml' 'Opportunity' force-app/

# Find all validation rules with a specific error message
sf-rust grep -rn --include='*.object-meta.xml' 'errorMessage' force-app/

⚡ LWC Patterns

# Find all wire adapters
sf-rust grep -rn --include='*.js' '@wire' force-app/

# Find all @api properties (public API surface)
sf-rust grep -rn --include='*.js' '@api\b' force-app/

# Find all track/reactive properties
sf-rust grep -rn --include='*.js' '@track\b' force-app/

# Find all template imports of a specific component
sf-rust grep -rl --include='*.html' 'c-my-component' force-app/

# Find all LWC console.error / console.warn calls
sf-rust grep -rn --include='*.js' 'console\.(error|warn)' force-app/

📄 Context Lines

# 3 lines around each match (like grep -C 3)
sf-rust grep -rn -C 3 --include='*.cls' 'catch\b' force-app/

# 2 lines AFTER a match (what happens after each SOQL)
sf-rust grep -rn -A 2 --include='*.cls' '\[SELECT\b' force-app/

# 2 lines BEFORE a match (what sets up each DML)
sf-rust grep -rn -B 2 --include='*.cls' '\binsert\b' force-app/

📋 Listing & Counting

# Count System.debug calls per file
sf-rust grep -c 'System\.debug' --include='*.cls' force-app/
force-app/main/default/classes/AccountService.cls:7
force-app/main/default/classes/ContactTrigger.cls:3

# List only files containing matches
sf-rust grep -rl --include='*.cls' 'WITHOUT SHARING' force-app/

# Print only the matched text (one token per line)
sf-rust grep -roh --include='*.cls' "'[0-9A-Za-z]{15,18}'" force-app/ | sort -u

# Stop after first 10 matches (fast spot-check)
sf-rust grep -rn -m 10 'TODO' force-app/

🎯 Precise Matching

# Whole word: "Account" but not "AccountId"
sf-rust grep -rn -w 'Account' --include='*.cls' force-app/

# Invert: lines that do NOT reference a namespace prefix
sf-rust grep -rn --invert-match 'myns__' --include='*.cls' force-app/

# Fixed string (no regex metacharacters)
sf-rust grep -rn -F 'Account.Name' --include='*.cls' force-app/

# Exclude test classes from search
sf-rust grep -rn --include='*.cls' --exclude='*Test*.cls' 'Database\.query' force-app/

# Skip .git and node_modules
sf-rust grep -rn --exclude-dir='.git' --exclude-dir='node_modules' 'TODO' .

🔗 Piping & Scripting

# Grep a single file from stdin
cat force-app/main/default/classes/AccountService.cls | sf-rust grep -n 'query'

# Count lines in all test files
sf-rust grep -rl --include='*.cls' '@isTest' force-app/ | xargs wc -l

# Force color even when piped (e.g. into less)
sf-rust grep -rn --color=always 'Database\.query' force-app/ | less -R

# No color for log files
sf-rust grep -rn --color=never 'ERROR' logs/ > errors.txt

🚦 Exit Codes (POSIX)

CodeMeaning
0At least one match found
1No matches found
2Error (invalid regex, I/O failure)
# CI gate: fail if hardcoded IDs found in Apex
if sf-rust grep -rq --include='*.cls' "'[0-9A-Za-z]{18}'" force-app/; then
  echo "Hardcoded IDs found — failing build"
  exit 1
fi

# Conditional: act only if WITHOUT SHARING exists
if sf-rust grep -ql 'WITHOUT SHARING' force-app/; then
  echo "Security review required"
fi

# Count files with issues, use exit code in pipelines
sf-rust grep -rl 'System\.debug' --include='*.cls' force-app/ | wc -l
Note: sf-rust's timing output is automatically suppressed when running grep — the command calls std::process::exit() directly to preserve POSIX exit codes.

🔎 Filter SOQL Results with --grep

After fetching all records via query_all(), --grep keeps only rows where any field value matches the regex. Works with every output format.

# Show only Technology accounts
sf-rust data query -q "SELECT Id, Name, Industry FROM Account" -o dev1 \
  --grep 'Technology'

# Gmail contacts (case-insensitive)
sf-rust data query -q "SELECT Id, Name, Email FROM Contact" -o dev1 \
  --grep 'gmail' --grep-ignore-case

# Filter and export to CSV
sf-rust data query -q "SELECT Id, Name, Amount, StageName FROM Opportunity" -o dev1 \
  --grep 'Closed Won' --csv > closed_won.csv

# Filter and save as Parquet for analytics
sf-rust data query -q "SELECT Id, Name, AnnualRevenue, Industry FROM Account" -o dev1 \
  --grep '^(Technology|Finance)' --parquet tech_finance.parquet

# Filter and open in browser datatable
sf-rust data query -q "SELECT Id, Name, Account.Name, Email FROM Contact" -o dev1 \
  --grep '@example\.com' --datatable

# Filter and write to Excel
sf-rust data query -q "SELECT Id, Name, Amount FROM Opportunity" -o dev1 \
  --grep '^[5-9][0-9]{5}' --xlsx big_deals.xlsx

# Filter and write to SQLite
sf-rust data query -q "SELECT Id, Name, Industry FROM Account" -o dev1 \
  --grep 'Media' --sqlite media.db --sqlite-table accounts

🏹 Filter Arrow / Parquet with --grep

No Salesforce call needed — filter an existing Arrow IPC or Parquet file on disk.

# Filter a Parquet file
sf-rust data arrow-view accounts.parquet --grep 'Technology'

# Case-insensitive + CSV export
sf-rust data arrow-view contacts.arrow --grep 'new york' --grep-ignore-case --csv

# Open filtered results in browser datatable
sf-rust data arrow-view opportunities.parquet --grep 'Closed Won' --datatable

# Filter and write to Excel
sf-rust data arrow-view accounts.parquet --grep '^A' --xlsx a_accounts.xlsx

# Filter + NDJSON for streaming pipelines
sf-rust data arrow-view accounts.parquet --grep 'Finance' --ndjson | jq '.Name'

🏗️ Full Data Pipeline Example

# 1. Fetch Technology accounts, save as Parquet
sf-rust data query -q "SELECT Id, Name, Industry, AnnualRevenue FROM Account" \
  -o dev1 --grep 'Technology' --parquet tech.parquet

# 2. Inspect schema
sf-rust data arrow-view tech.parquet --schema

# 3. Preview first 5 rows
sf-rust data arrow-view tech.parquet --limit 5

# 4. Find Apex code that references these accounts
sf-rust grep -rn --include='*.cls' 'Account' force-app/

# 5. Open filtered data in browser for ad-hoc analysis
sf-rust data arrow-view tech.parquet --datatable

🖥️ Auto-complete Setup

Shell completions are generated by clap_complete and installed to the standard locations by make install.

zsh

# Add to ~/.zshrc (if not already present)
fpath=($HOME/.zfunc $fpath)
autoload -Uz compinit && compinit

# If completions aren't showing after make install, refresh the cache:
rm -f ~/.zcompdump && compinit

bash

# Add to ~/.bashrc
source $HOME/.bash_completion.d/sf-rust

fish

# Completions are installed automatically to:
~/.config/fish/completions/sf-rust.fish
# No further setup needed — fish picks them up on next launch.
After running make install, open a new terminal or run rm -f ~/.zcompdump && compinit to activate updated completions immediately.
