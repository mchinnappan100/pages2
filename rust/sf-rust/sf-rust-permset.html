🔐 sf-rust permset

Manage Salesforce Permission Set assignments — list, inspect, assign, and unassign.

4
subcommands
REST
API
PSA
PermissionSetAssignment

Distinct from sfr perms (which is read-only inspection of object/field permissions). sfr permset manages the day-to-day task of granting and revoking permission sets.

list — Enumerate permission sets

Query all PermissionSet records. Use --custom-only to skip profile-owned sets, or --search to narrow by name.

sfr permset list -o dev1 sfr permset list -o dev1 --custom-only sfr permset list -o dev1 --search "Sales" sfr permset list -o dev1 --json sfr permset list -o dev1 --datatable
FlagDescription
--custom-onlyFilter out permission sets owned by profiles (IsOwnedByProfile = false)
--search <text>Partial match on Name (case-insensitive LIKE)
--json / -jOutput as JSON array
--datatableOpen results in browser datatable

assignments — Show who has what

Query PermissionSetAssignment records with nested PermissionSet.* fields flattened.

sfr permset assignments -o dev1 sfr permset assignments -o dev1 --json sfr permset assignments -o dev1 --datatable

assign — Grant a permission set

Creates a new PermissionSetAssignment record. The --user flag accepts a Salesforce username (e.g. john@example.com) or a 15/18-character User Id (starts with 005).

sfr permset assign "My_Permission_Set" --user "john@example.com" -o dev1 sfr permset assign "My_Permission_Set" --user "0051a000005...AAA" -o dev1 sfr permset assign "My_Permission_Set" --user "john@example.com" -o dev1 --json

unassign — Revoke a permission set

Looks up the PermissionSetAssignment record by user + permission set, then deletes it.

sfr permset unassign "My_Permission_Set" --user "john@example.com" -o dev1 sfr permset unassign "My_Permission_Set" --user "john@example.com" -o dev1 --json
Tip: Use sfr permset assignments -o dev1 --json | jq '.records[] | select(.AssigneeName == "john@example.com")' to audit all permissions for a specific user.
