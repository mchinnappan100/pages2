Phase 10: Real AdamW gradient training via candle-nn VarMap. A and B matrices are tracked Var objects — candle_nn::loss::cross_entropy computes differentiable loss, opt.backward_step(&loss) updates only the adapters while the base GPT-2 stays frozen. 6 unit tests verified.
LoRA Concepts
Logit-LoRA architecture: Two trainable matrices A [vocab, rank] and B [rank, vocab] (init: A~N(0,0.02), B=0). At each training step: adapted = frozen_logits + (frozen_logits @ A @ B) × (alpha/rank). Cross-entropy loss flows gradients through A and B only — base model weights are never updated. Trainable params = 2 × vocab × rank (e.g. GPT-2: 2 × 50257 × 8 ≈ 804K vs. 124M base = 0.65%).

Workflow

# Prepare JSONL training data ({"text": "..."} per line)
echo '{"text": "Rust is a systems language."}' > finetune.jsonl

# Fine-tune GPT-2 with LoRA adapters
rllm finetune lora --base ~/.rllm/models/gpt2 --data finetune.jsonl \
    --rank 8 --alpha 16 --epochs 3 --output gpt2-lora/

# Check status
rllm finetune status

# Merge adapter into base model
rllm finetune merge-adapter --base ~/.rllm/models/gpt2 \
    --adapter gpt2-lora/ --output gpt2-merged/
