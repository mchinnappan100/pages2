Protocol
MCP (Model Context Protocol) is Anthropic's open standard for connecting LLMs to external tools and data sources. rllm-mcp exposes the rllm toolkit (generate, embed, rag_query) as MCP tools with JSON Schema definitions so any MCP-compatible host (Claude Desktop, Claude Code, etc.) can call them.
Exposed Tools
Tool NameInput SchemaDescription
generateprompt, max_tokens, temperatureGenerate text from a prompt using the active rllm model
embedtextReturn 768-dim mean-pool embedding for input text
rag_queryquery, top_k, storeSemantic search over the rsqlite vector store (Phase 7 — real inference)

Live Output — Phase 7 (rag_query wired to rsqlite)

Phase 7 wires rag_query to the real rllm-rag rsqlite store. The tool embeds the query in-process, runs cosine similarity over all stored documents, and returns ranked JSON results.

How it works: rag_query calls InferSession::embed(query) then rllm_rag::rag_query_store(store, &emb, top_k). All in one process — no subprocess, no HTTP round-trip. Store defaults to ~/.rllm/rag.db.
