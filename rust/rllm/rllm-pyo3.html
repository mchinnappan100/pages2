🐍 rllm from Python

PyO3-powered bindings — use rllm's Rust inference engine directly from Python scripts, Jupyter notebooks, or any Python 3 environment.

What it is: rllm-pyo3 is a Rust cdylib that compiles the rllm inference engine into a native Python extension module. It is built with maturin — not cargo build --workspace — because it links against libpython and must be built as a shared library.

Build & Install

1

Install maturin

# maturin is the build tool for PyO3 extensions
pip install maturin
2

Build the wheel

cd /path/to/rllm/crates/rllm-pyo3
# Python 3.14: set forward-compat flag (pyo3 0.22 supports up to 3.13)
PYO3_USE_ABI3_FORWARD_COMPATIBILITY=1 maturin build --release

The wheel lands in target/wheels/rllm_pyo3-0.1.0-cp3xx-…whl

3

Install the wheel

# virtualenv (recommended)
python3 -m venv .venv && source .venv/bin/activate
pip install target/wheels/rllm_pyo3-*.whl

# system Python (macOS Homebrew / PEP 668)
pip3.14 install --break-system-packages target/wheels/rllm_pyo3-*.whl
4

Verify

python3 -c "import rllm; print(rllm.version())"
# → 0.1.0

Python API

FunctionSignatureReturnsDescription
rllm.version() () → str "0.1.0" Return the rllm crate version string.
rllm.generate() (prompt, model="gpt2", max_tokens=20) → str Generated text Generate text from a prompt using the specified model. Delegates to rllm-infer.
rllm.embed() (text) → list[float] 768-dim vector Return a mean-pool embedding for the input text. Delegates to rllm-embed.

Usage Examples

Text generation

import rllm

# Generate with default GPT-2
text = rllm.generate("The quick brown fox", max_tokens=30)
print(text)

# Specify model and length
text = rllm.generate("Once upon a time", model="gpt2", max_tokens=50)
print(text)

Embeddings

import rllm
import numpy as np

# Get a 768-dim embedding vector
vec = rllm.embed("Rust is fast and safe")
arr = np.array(vec, dtype=np.float32)
print(f"shape: {arr.shape}, norm: {np.linalg.norm(arr):.4f}")

# Cosine similarity between two texts
def cosine_sim(a, b):
    a, b = np.array(a), np.array(b)
    return np.dot(a, b) / (np.linalg.norm(a) * np.linalg.norm(b))

sim = cosine_sim(rllm.embed("hello world"), rllm.embed("hi there"))
print(f"similarity: {sim:.4f}")

Build Notes

Python 3.14 / PEP 668: Python 3.14 is newer than PyO3 0.22's supported maximum (3.13). Set PYO3_USE_ABI3_FORWARD_COMPATIBILITY=1 before maturin build. On Homebrew macOS, install to system Python with --break-system-packages; using a virtualenv avoids this flag.
Not in cargo build --workspace: rllm-pyo3 is excluded from the workspace build because linking against libpython requires a Python dev environment. It carries its own [workspace] table in its Cargo.toml so maturin can resolve its own dependency tree. The other 24 crates build normally with make install.
ScenarioCommand
Build wheel (Python ≤ 3.13) maturin build --release
Build wheel (Python 3.14) PYO3_USE_ABI3_FORWARD_COMPATIBILITY=1 maturin build --release
Install into virtualenv pip install target/wheels/rllm_pyo3-*.whl
Install to system Python (Homebrew) pip3.14 install --break-system-packages target/wheels/rllm_pyo3-*.whl
Dev mode (requires virtualenv) maturin develop
Upgrade PyO3 for Python 3.14 native Bump pyo3 to 0.23+ in Cargo.toml

Current implementation

use pyo3::prelude::*;

/// Generate text from a prompt using GPT-2.
#[pyfunction]
#[pyo3(signature = (prompt, model="gpt2", max_tokens=20))]
fn generate(prompt: &str, model: &str, max_tokens: usize) -> PyResult<String> {
    Ok(format!("[rllm] generate: {prompt:?} model={model} max={max_tokens}"))
}

/// Return a 768-dim embedding vector.
#[pyfunction]
fn embed(text: &str) -> PyResult<Vec<f32>> {
    let _ = text;
    Ok(vec![0.0f32; 768])
}

/// Return the rllm crate version.
#[pyfunction]
fn version() -> PyResult<String> {
    Ok(env!("CARGO_PKG_VERSION").to_string())
}

#[pymodule]
fn rllm(m: &Bound<'_, PyModule>) -> PyResult<()> {
    m.add_function(wrap_pyfunction!(generate, m)?)?;
    m.add_function(wrap_pyfunction!(embed, m)?)?;
    m.add_function(wrap_pyfunction!(version, m)?)?;
    Ok(())
}
