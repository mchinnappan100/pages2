🐍 rllm from Python

PyO3-powered bindings — use rllm's Rust inference engine directly from Python scripts, Jupyter notebooks, or any Python 3 environment.

What it is: rllm-pyo3 is a Rust cdylib that compiles the rllm inference engine into a native Python extension module. It is built with maturin — not cargo build --workspace — because it links against libpython and must be built as a shared library.

Build & Install

1

Install maturin

# maturin is the build tool for PyO3 extensions
pip install maturin
2

Build the wheel

cd /path/to/rllm/crates/rllm-pyo3
maturin build --release
# → target/wheels/rllm_pyo3-0.1.0-cp39-abi3-macosx_11_0_arm64.whl

Uses abi3-py39 feature — one wheel runs on Python 3.9 through 3.14+. No env-var flags needed.

3

Install the wheel

# Install into all Python versions found on the machine (3.9–3.14)
make install-pyo3   # from the rllm workspace root

# Or manually into one interpreter
python3.11 -m pip install --break-system-packages target/wheels/rllm_pyo3-*.whl
python3.14 -m pip install --break-system-packages target/wheels/rllm_pyo3-*.whl
4

Verify

python3 -c "import rllm; print(rllm.version())"
# → 0.1.0

Python API

Phase 6: RllmSession loads the model once and keeps it in memory — use it for repeated generation and embedding instead of the module-level convenience functions.

NameSignatureReturnsNotes
rllm.load() (model_path: str) → RllmSession RllmSession Load model from a local directory (CPU). Returns a session you reuse.
rllm.load_metal() (model_path: str) → RllmSession RllmSession Same as load() but uses Metal GPU; falls back to CPU if unavailable.
session.generate() (prompt, max_tokens=20, temperature=0.8, top_k=None, top_p=None, seed=None) → str Generated text Real GPT-2 inference using the loaded model. Supports greedy (temperature=0.0) and reproducible (seed=42) modes.
session.embed() (text: str) → list[float] 768-dim vector Mean-pool wte embeddings using the already-loaded model — no extra disk I/O.
session.model_id str (property) "gpt2" The model directory name this session was loaded from.
rllm.generate() (prompt, model="gpt2", max_tokens=20) → str str Convenience wrapper — echoes the call. For real inference use rllm.load().
rllm.embed() (text: str) → list[float] 768-dim vector Loads ~/.rllm/models/gpt2 on each call. For repeated calls use session.embed().
rllm.version() () → str "0.1.0" Return the rllm crate version string.

Usage Examples

Session — load once, generate many (recommended)

import rllm

# Load model once — stays in memory for the life of `session`
session = rllm.load("/Users/mchinnappan/.rllm/models/gpt2")
print(session.model_id)   # gpt2

# Generate (greedy — deterministic)
out = session.generate("The quick brown fox", max_tokens=30, temperature=0.0)
print(out)

# Generate (sampling with seed — reproducible)
out = session.generate("Once upon a time", max_tokens=40, temperature=0.8, seed=42)
print(out)

# Metal GPU (Apple Silicon) — falls back to CPU if Metal unavailable
session_gpu = rllm.load_metal("/Users/mchinnappan/.rllm/models/gpt2")

Embeddings + cosine similarity (verified output)

import rllm, math

def cosine(a, b):
    dot = sum(x*y for x,y in zip(a,b))
    return dot / (math.sqrt(sum(x*x for x in a)) * math.sqrt(sum(x*x for x in b)) + 1e-9)

session = rllm.load("/Users/mchinnappan/.rllm/models/gpt2")
vec     = session.embed("neural network")
sim     = cosine(vec, session.embed("deep learning"))
print(f"similarity: {sim:.4f}")
# similarity: 0.4348  ← verified on Python 3.14.2, GPT-2, macOS arm64

Build Notes

abi3-py39: The Cargo.toml uses pyo3 = { features = ["abi3-py39"] }. This generates a single cp39-abi3 wheel that runs on any Python 3.9–3.14+ — no PYO3_USE_ABI3_FORWARD_COMPATIBILITY flag needed. Use make install-pyo3 to build once and install into every Python interpreter found on the machine.
Not in cargo build --workspace: rllm-pyo3 is excluded from the workspace build because linking against libpython requires a Python dev environment. It carries its own [workspace] table in its Cargo.toml so maturin can resolve its own dependency tree. The other 24 crates build normally with make install.
ScenarioCommand
Build wheel (all Python versions) maturin build --release
Install into all local Pythons make install-pyo3 — iterates python3.9…3.14
Install into one interpreter python3.11 -m pip install --break-system-packages target/wheels/rllm_pyo3-*.whl
Deploy to mac-mini make deploy-pyo3-to-mini
Dev mode (requires virtualenv) maturin develop

#[pymodule]
fn rllm(m: &Bound<'_, PyModule>) -> PyResult<()> {
    m.add_class::<RllmSession>()?;
    m.add_function(wrap_pyfunction!(load, m)?)?;
    m.add_function(wrap_pyfunction!(load_metal, m)?)?;
    m.add_function(wrap_pyfunction!(generate, m)?)?;
    m.add_function(wrap_pyfunction!(embed, m)?)?;
    m.add_function(wrap_pyfunction!(version, m)?)?;
    Ok(())
}
