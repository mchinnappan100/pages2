rllm agent

Tool-calling agent loop with built-in tools: search (stub), calc, file, shell. Run multi-step tasks from the command line.

Commands
CommandFlagsDescription
rllm agent run <TASK>--model --tools --max-stepsRun a task with the tool-calling agent loop
rllm agent toolsList available built-in tools and their status
rllm agent history--limitShow recent agent runs from ~/.rllm/agent_history.jsonl

Phase 11: search tool wired to DuckDuckGo Instant Answer API via reqwest::blocking. Returns AbstractText → Answer → Definition → RelatedTopics in priority order. No API key required. 14 unit tests verified (arithmetic eval, DDG response parsing, tool list).
