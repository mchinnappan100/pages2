rllm quant

Quantize models to INT8 or INT4 for 2–4× memory reduction with minimal quality loss.

Phase 13 ✓INT8 absmaxINT4 group-wiseInspect · Dequantize
← Back to Portal
Commands
CommandFlagsDescription
rllm quant int8--model --outputQuantize model weights to INT8 (2× compression)
rllm quant int4--model --output --group-sizeQuantize to INT4 (4× compression, grouped quantization)
rllm quant inspect--model --jsonReport quantization statistics for a model
rllm quant dequantize--model --outputRestore quantized model to FP32
Phase 13: Pure-Rust post-training quantization. INT8: per-tensor absmax scaling → scale = absmax/127; writes safetensors + .quant.json scale sidecar. INT4: group-wise quantization (default group=32) → 4-bit nibble packing + scales sidecar. inspect: tensor name/shape/dtype/L2 norm/scale table with optional JSON output. dequantize: round-trip back to F32. 8 unit tests verified.

Examples

rllm quant int8    --model ~/.rllm/models/gpt2 --output gpt2-int8.safetensors
rllm quant int4    --model ~/.rllm/models/gpt2 --output gpt2-int4.safetensors --group-size 128
rllm quant inspect --model gpt2-int8.safetensors
rllm quant dequantize --model gpt2-int8.safetensors --output gpt2-restored.safetensors
