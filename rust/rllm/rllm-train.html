Commands
CommandFlagsDescription
rllm train run--configStart a training run from a TOML config file
rllm train status--run-dirShow status of an ongoing or completed training run
rllm train resume--run-dir --checkpointResume training from a checkpoint
rllm train config-init--outputGenerate a default train.toml template
Phase 9: TinyGPT (custom transformer, candle-nn) + AdamW optimizer end-to-end verified. Config via TOML, checkpoint save/resume via safetensors, loss history JSON, in-training sampling at each eval_interval.
Quick Start

Training workflow

# Generate a default train.toml
rllm train config-init --output train.toml

# Edit: set data_path, out_dir, model size, lr …

# Start training
rllm train run --config train.toml

# Check progress
rllm train status --run-dir runs/tinygpt

# Resume from checkpoint
rllm train resume --run-dir runs/tinygpt --checkpoint runs/tinygpt/ckpt_005000.safetensors
Default train.toml
data_path     = "data/input.txt"
out_dir       = "runs/tinygpt"
max_steps     = 5000
batch_size    = 32
learning_rate = 0.0003

n_embd        = 128
n_head        = 4
n_layer       = 4
beta1         = 0.9
beta2         = 0.95

sample_prompt = "The quick"
