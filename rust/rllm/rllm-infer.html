rllm infer

Run GPT-2 inference with generate, chat, and batch modes. Supports temperature, top-k, top-p sampling with repetition penalty.

Commands
CommandFlagsDescription
rllm infer generate <PROMPT>--model --max-tokens --temperature --top-k --top-p --seedGenerate text continuation from a prompt
rllm infer chat--model --max-tokens --temperatureInteractive chat loop (Human/Assistant template, repetition penalty 1.3)
rllm infer batch--input --output --model --max-tokensBatch inference from a text file of prompts → JSONL output
Examples

Generate

# Prompt is positional — no --prompt flag
rllm infer generate "The quick brown fox" --model gpt2 --max-tokens 50
rllm infer generate "In the beginning" --model gpt2 --temperature 0.8 --top-k 50
rllm infer generate "Once upon a time" --model gpt2 --top-p 0.9 --seed 42

Chat

rllm infer chat --model gpt2
# Formats prompt as: "Human: {input}\n\nAssistant:"
# Repetition penalty 1.3 prevents looping CSS/boilerplate

Batch

rllm infer batch --input prompts.txt --output results.jsonl --model gpt2 --max-tokens 100
# prompts.txt: one prompt per line
# results.jsonl: {"prompt": "...", "output": "..."} per line
Sampling Parameters
ParameterDefaultNotes
temperature0.80 = greedy, >1 = more random
top_kNoneKeep top K logits; None = disabled
top_pNoneNucleus sampling threshold; None = disabled
repetition_penalty1.1 (generate), 1.3 (chat)Keskar 2019: divides positive logits for seen tokens
seedrandomFix for reproducible output
