rllm tokenize

Encode, decode, count, and inspect tokens using HuggingFace BPE tokenizers.

Commands
CommandFlagsDescription
rllm tokenize encode <TEXT>--model --jsonEncode text to token IDs
rllm tokenize decode <IDS…>--modelDecode token IDs back to text
rllm tokenize count <TEXT>--modelCount tokens in a string
rllm tokenize vocab--model --limit --jsonDump vocabulary table
rllm tokenize merge-info--modelShow BPE merge rules
rllm tokenize diff <A> <B>--modelCompare tokenisation of two strings

Examples

rllm tokenize encode "Hello, Rust!" --model gpt2
# → [15496, 11, 10840, 0]

rllm tokenize count "The quick brown fox" --model gpt2
# → 4 tokens

rllm tokenize decode 15496 11 10840 0 --model gpt2
# → Hello, Rust!

rllm tokenize vocab --model gpt2 --limit 20
