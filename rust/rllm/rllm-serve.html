rllm serve

Serve LLM inference via an OpenAI-compatible HTTP API built with axum. Drop-in replacement for OpenAI API clients.

Phase 14 ✓SSE StreamingOpenAI-compataxum · InferSession

Commands
CommandFlagsDescription
rllm serve start--model --host --port --deviceStart the HTTP server (default: 127.0.0.1:8080)
rllm serve status--portCheck if server is running and show active model
rllm serve test--port --promptSend a test completion request to the running server
API Endpoints
MethodEndpointDescription
GET/healthHealth check — returns {"status":"ok"}
GET/v1/modelsList available models
POST/v1/completionsText completions (OpenAI-compatible)
POST/v1/chat/completionsChat completions (OpenAI-compatible)
POST/v1/embeddingsGet 768-dim embeddings (GPT-2 mean-pool)
Phase 14: SSE streaming added to /v1/completions and /v1/chat/completions. Send "stream": true to receive text/event-stream chunks (one word per data: event, terminated with data: [DONE]). Drop-in compatible with the OpenAI Python SDK and openai npm package. 12 unit tests (request parsing, stream defaults, SSE chunk counts).

Start & test

# Start server
rllm serve start --model gpt2 --port 8080

# Health check
curl http://localhost:8080/health

# Text completion
curl http://localhost:8080/v1/completions \
  -H 'Content-Type: application/json' \
  -d '{"prompt":"The quick brown fox","max_tokens":20}'

# Chat completion
curl http://localhost:8080/v1/chat/completions \
  -H 'Content-Type: application/json' \
  -d '{"messages":[{"role":"user","content":"What is Rust?"}],"max_tokens":60}'

# Embeddings (Phase 8: real 768-dim vectors)
curl http://localhost:8080/v1/embeddings \
  -H 'Content-Type: application/json' \
  -d '{"input":"neural network"}'

# Or use rllm serve test
rllm serve test --port 8080 --prompt "Hello world"

Streaming (Phase 14)

# SSE streaming — completions
curl http://localhost:8080/v1/completions \
  -H 'Content-Type: application/json' \
  -d '{"prompt":"The quick brown fox","max_tokens":30,"stream":true}'

# SSE streaming — chat
curl http://localhost:8080/v1/chat/completions \
  -H 'Content-Type: application/json' \
  -d '{"messages":[{"role":"user","content":"What is Rust?"}],"stream":true}'

# OpenAI Python SDK (stream=True)
from openai import OpenAI
client = OpenAI(base_url="http://localhost:8080/v1", api_key="rllm")
for chunk in client.chat.completions.create(
    model="gpt2", stream=True,
    messages=[{"role":"user","content":"What is Rust?"}]):
    print(chunk.choices[0].delta.content, end="", flush=True)
