Phase 30 ✓ — Bench, BF16, and HTTP serve added. rllm llama3 bench measures TTFT, prefill speed (ms/token), and decode throughput (tokens/sec). All model commands now accept --bf16 to load weights in BF16, halving memory (~16 GB vs 32 GB for 8B). rllm llama3 serve --port 8080 starts an OpenAI-compatible HTTP server (POST /v1/completions, POST /v1/chat/completions, SSE streaming). 121 man pages total.
Phase 27 ✓ — Streaming output and multi-turn chat REPL. rllm llama3 generate --stream prints each token to stdout as it is sampled. rllm llama3 chat is an interactive REPL using the Llama 3 chat template (<|start_header_id|>/<|eot_id|>); the KV cache is kept live across turns so each new turn only processes the new tokens — O(1) per turn after the first. 119 man pages (new: rllm-llama3-chat.1).

Phase 26 — KV Cache
ComponentFileDescription
KvCachemodel.rsPer-layer storage of past K/V tensors: Vec<Option<(Tensor, Tensor)>>. Each entry grows by concatenation along the seq dim on every decode step.
KvCache::updatemodel.rsAppends new K/V for a layer; returns the full accumulated (past + current) tensors for attention.
KvCache::seq_lenmodel.rsCurrent cached sequence length — used as the offset for RoPE on each decode step.
Prefill stagelib.rsAll prompt tokens processed in a single forward pass (offset=0). KV cache filled for [0..n_prompt) in one shot.
Decode stagelib.rsEach new token: input=[1 token], offset=cache.seq_len(). Attends over full cached K/V. O(1) compute per step.
Complexity—Phase 25: O(n²) — full sequence re-processed every step. Phase 26: O(n) — prefill once, decode in O(1) steps.

Examples

Llama 3 operations

# Show 8B architecture config
rllm llama3 info meta-llama/Meta-Llama-3-8B
rllm llama3 info meta-llama/Meta-Llama-3-8B --json

# Check local model cache
rllm llama3 load meta-llama/Meta-Llama-3-8B

# Generate — buffered (waits for all tokens, then prints)
rllm model download meta-llama/Meta-Llama-3-8B
rllm llama3 generate --prompt "The key difference between Llama 3 and GPT-2 is" \
  --max-tokens 100 --model meta-llama/Meta-Llama-3-8B

# Generate — streamed (tokens appear immediately)
rllm llama3 generate --prompt "Rust is memory-safe because" \
  --max-tokens 200 --stream

# Multi-turn chat REPL (type /quit to exit)
rllm llama3 chat
rllm llama3 chat --system "You are a Rust expert." --max-tokens 512
