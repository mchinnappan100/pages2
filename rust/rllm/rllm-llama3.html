Phase 25 ✓ — Real Candle inference wired. model.rs implements the full Llama 3 architecture: RmsNorm, RopeCache (theta=500k, split-half layout), GqaAttention (KV head expansion), SwiGluMlp, and Llama3Model with multi-shard safetensors loading. rllm llama3 generate now runs real autoregressive inference with temperature/top-k/top-p sampling and EOS detection. 13 unit tests (8 original + 5 model: rope shape, rotate_half, causal mask, config parse).

Phase 25 — model.rs Implementation
ComponentFileDescription
Llama3ModelConfigmodel.rsDeserialises HF config.json: hidden_size, num_attention_heads, num_key_value_heads, rope_theta, rms_norm_eps
RopeCachemodel.rsPrecomputes cos/sin for all positions; split-half HF layout; theta=500,000
RmsNormmodel.rsPre-norm: x / rms(x) * weight — computed in F32 for precision, cast back to weight dtype
GqaAttentionmodel.rsq/k/v/o projections (no bias); RoPE applied; KV heads expanded via reshape for GQA; causal mask
SwiGluMlpmodel.rsdown_proj(silu(gate_proj(x)) * up_proj(x))

Examples

Llama 3 operations

# Show 8B architecture config
rllm llama3 info meta-llama/Meta-Llama-3-8B
rllm llama3 info meta-llama/Meta-Llama-3-8B --json

# Check local model cache
rllm llama3 load meta-llama/Meta-Llama-3-8B

# Generate (requires model cached via rllm model download)
rllm model download meta-llama/Meta-Llama-3-8B
rllm llama3 generate --prompt "The key difference between Llama 3 and GPT-2 is" \
  --max-tokens 100 --model meta-llama/Meta-Llama-3-8B
